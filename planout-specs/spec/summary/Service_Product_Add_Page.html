1.  Frontend
1.1Overview

The Service Product Add Page is a dedicated interface within the Lumi ERP system designed to help users efficiently create and manage new service offerings. This page allows users to input essential product details, configure pricing structures, and define tax settings, ensuring that all service information is accurately captured and stored in the system.

1.2Step-by-Step Flow
1.Initialization: When the page loads, the system automatically fetches necessary configuration data (such as tax rates and units of measure) to populate the dropdown menus.
2.Data Entry: The user fills out the product details, including the name, description, and any relevant categorization (Type or Tag). If a specific type or tag does not exist, the user can create it on the fly using the provided buttons.
3.Pricing Configuration: The user enters the service price. They can toggle an "Including Tax" checkbox to specify whether the entered price already accounts for tax.
4.Automatic Calculation: The system performs a real-time calculation:

* If "Including Tax" is unchecked, the system treats the price as the base amount.

* If "Including Tax" is checked, the system automatically calculates the pre-tax price by stripping the tax amount from the total.

5.Submission: Once the user clicks "Save," the system validates the information and creates the new service product.
6.Navigation: Upon a successful save, the user is automatically redirected to the new product's detail page to review the entry.
1.3Key Concepts
–Service Product: A non-physical offering (e.g., consulting, maintenance) that can be priced and tracked within the ERP.
–Including Tax Toggle: A feature that determines how the system interprets the price input, ensuring accurate financial reporting regardless of whether the user enters a gross or net amount.
–Dynamic Pricing: The system’s ability to automatically derive the pre-tax price based on the user's tax settings, reducing manual calculation errors.
–On-the-fly Creation: The ability to add new categories (Types or Tags) directly from the product page without needing to navigate to a separate settings menu.
1.4Business Value
–Efficiency: By automating tax calculations and allowing for the creation of new categories directly within the form, the system reduces the time and effort required to add new services.
–Data Accuracy: Real-time calculation of pre-tax pricing ensures that financial data remains consistent and reliable for accounting purposes.
–User Experience: The intuitive layout and seamless navigation to the detail page after saving provide a smooth, professional workflow for staff managing the product catalog.
2.  Logic
2.1Overview

The Service Product Add Page allows you to define new service offerings within the Lumi ERP system. This feature enables you to input service details, set pricing, and manage tax configurations. The system is designed to handle pricing flexibility, automatically calculating the tax-exclusive price based on your preferences so that your financial records remain accurate.

2.2Step-by-Step Flow
1.Initialization: When you open the "Add Service Product" page, the system automatically retrieves necessary configuration data, such as available tax rates and units of measure, to populate your dropdown menus.
2.Data Entry: You enter the service name, description, and the price. You also indicate whether the price you entered already includes tax by toggling the "Including Tax" option.
3.Automated Calculation: When you click "Save," the system checks your tax setting. If the price includes tax, the system automatically strips the tax amount to determine the base (tax-exclusive) price. If the price does not include tax, the system uses your entered amount as the base price.
4.Submission: The system saves the complete service record, including the name, description, total price, and the calculated tax-exclusive price, to the database.
5.Confirmation: Upon a successful save, the system confirms the creation and directs you to the details page for the new service.
2.3Key Concepts
–Service Product: A non-physical offering (such as consulting or maintenance) that can be sold and tracked within the ERP.
–Including Tax: A setting that tells the system whether the price you provided is the final amount paid by the customer (inclusive) or the base amount before tax is applied (exclusive).
–Tax-Exclusive Price: The base price of a service before any applicable taxes are added; this is calculated automatically by the system to ensure consistent financial reporting.
–Metadata: Background information, such as tax rates, that the system loads automatically to ensure all dropdown menus and form fields are up-to-date.
2.4Business Value

This feature streamlines the product creation process by removing the need for manual tax calculations. By automating the derivation of tax-exclusive pricing, the system reduces the risk of human error, ensures compliance with tax reporting requirements, and provides a consistent, efficient workflow for managing your service catalog.

3.  Data
3.1Overview

The Service Product Add page allows users to define and save new service offerings within the Lumi ERP system. This feature ensures that service details—such as the name, description, and pricing—are accurately captured and stored. A key component of this page is its intelligent handling of tax, which automatically calculates the base price of a service based on whether the user provides a tax-inclusive or tax-exclusive amount.

3.2Step-by-Step Flow
1.Input Details: The user enters the service name, description, and the price into the form.
2.Tax Selection: The user indicates whether the entered price already includes tax by toggling the "Including Tax" option.
3.Submission: Upon clicking the "Save" button, the system processes the information.
4.Automated Calculation: The system determines the tax-exclusive price. If the price includes tax, it automatically strips the tax amount; if it does not include tax, the entered price is used as the base.
5.Record Creation: The system generates a unique identifier for the service, saves all details to the database, and confirms the creation.
6.Navigation: Once successfully saved, the application automatically redirects the user to the newly created service product's detail page.
3.3Key Concepts
–Service Product: A non-physical offering (such as consulting or maintenance) that can be sold and tracked within the ERP.
–Tax-Inclusive Pricing: A pricing method where the final amount paid by the customer already contains the tax component.
–Tax-Exclusive Pricing: A pricing method where the tax is calculated and added on top of the base price.
–Automated Tax Handling: The system's ability to derive the base price (pre-tax) regardless of how the user chooses to input the final price, ensuring consistent financial reporting.
3.4Business Value

This feature streamlines the administrative process of adding new services to the catalog. By automating the tax calculation logic, the system reduces the risk of manual entry errors and ensures that financial data remains accurate for accounting purposes. This allows staff to focus on defining service offerings quickly while maintaining high data integrity across the ERP.
