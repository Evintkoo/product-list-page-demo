1.  Logic
1.1Overview

The `GET /api/customers` feature provides a flexible way for external systems to retrieve a list of customers from the Lumi ERP database. It is designed to handle large volumes of data by allowing users to filter, search, sort, and paginate results, ensuring that applications only receive the specific information they need at any given time.

1.2Step-by-Step Flow
1.Validation: The system checks the incoming request to ensure that any sorting or customer type filters provided are valid and supported.
2.Type Filtering: The system identifies the specific category of customer requested (e.g., retail, wholesale, franchise, or consignment) based on internal business rules.
3.Specific Filtering: The system applies any additional filters provided, such as searching for a specific customer group, tax number, phone number, or active status.
4.General Search: If a general search term is provided, the system scans key fields (like name, code, or email) to find matching records.
5.Sorting: The system organizes the results based on the user's preference (e.g., by name or code). If no preference is given, it defaults to showing the most recently created customers first.
6.Pagination: To keep performance high, the system calculates the total number of matching records and returns only a specific "page" of results (a limited number of records starting from a specific point).
7.Response: The system returns the requested list of customers along with metadata, such as the total count of records found, to help the calling application manage the data display.
1.3Key Concepts
–Filtering: The ability to narrow down the customer list by specific attributes, such as their assigned store, salesperson, or active status.
–Search: A broad lookup feature that checks multiple fields (like name and phone number) simultaneously to find a customer when you don't have a specific ID.
–Pagination: A method of breaking a large list of data into smaller, manageable chunks (pages) to improve system speed and user experience.
–Sorting: The process of arranging the customer list in a specific order, such as alphabetically by name or numerically by customer code.
1.4Business Value

This feature empowers integrated applications to efficiently access customer data without overloading the system. By providing robust filtering and pagination, it ensures that sales teams, support staff, and automated systems can quickly retrieve accurate customer information, which is essential for maintaining smooth operations and high-quality customer service within the Lumi ERP ecosystem.

2.  Data
2.1Overview

The Customer API feature provides a flexible way to retrieve a list of customers from the Lumi ERP system. It is designed to help users quickly find specific customer records by allowing them to filter, search, and sort the data. The system also includes pagination to ensure that large lists of customers are delivered in manageable chunks, improving performance and usability.

2.2Step-by-Step Flow
1.Initiate Request: The system receives a request to fetch the customer list.
2.Filter by Type: The system checks if a specific customer category (Retail, Wholesale, Franchise, or Consignment) is requested and narrows the results accordingly.
3.Apply Specific Filters: The system applies any additional criteria provided, such as filtering by a specific store, salesperson, or active status.
4.Perform Search: If a general search term is provided, the system scans key fields (like name, email, or phone number) to find matching records.
5.Sort Results: The system organizes the list based on the user's preference (e.g., by name or customer code). If no preference is given, it defaults to showing the most recently created customers first.
6.Paginate and Return: The system calculates the total number of matching records and returns a specific "page" of data based on the requested limit and offset.
2.3Key Concepts
–Filtering: Narrowing down the list based on specific attributes, such as customer type or active status.
–General Search: A broad search function that looks for a keyword across multiple fields simultaneously, such as name, email, or tax number.
–Sorting: Organizing the final list in a specific order (ascending or descending) based on fields like name or group.
–Pagination: A method of breaking a large dataset into smaller, numbered pages to make the information easier to navigate and faster to load.
2.4Business Value

This feature empowers users to efficiently manage and access customer data. By providing robust search and filtering capabilities, staff can quickly locate the exact customer information they need without manually sifting through the entire database. Furthermore, the pagination and sorting features ensure that the application remains fast and responsive, even as the customer database grows over time.
