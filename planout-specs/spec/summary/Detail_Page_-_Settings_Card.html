1.  Frontend
1.1Overview

The "Settings Card" is a read-only information panel located on the Service Product detail page. Its purpose is to provide a quick, at-a-glance summary of the operational and pricing configurations for a specific service. By using clear visual indicators, it allows staff to immediately understand how a service is set up without needing to navigate through complex menus.

1.2Step-by-Step Flow
1.Header Display: The card displays a "SETTINGS" header accompanied by a gear icon to clearly identify the section.
2.Active Status: The system shows whether the service is currently active, using a green checkmark for "Yes" or a red mark for "No."
3.Open Estimated Time Status: The system indicates if the service duration is flexible ("Open") or fixed, using the same green/red visual status indicators.
4.Estimated Time Value: The system displays the specific duration of the service in minutes.
5.Open Price Status: The system indicates if the service price is flexible ("Open") or fixed, using the green/red visual status indicators.
1.3Key Concepts
–Read-Only: Information is displayed for viewing purposes only and cannot be modified directly within this specific card.
–Status Indicators: Visual cues (green checkmarks for "Yes" and red marks for "No") that allow users to instantly interpret the configuration state of a service.
–Open vs. Fixed: A distinction used for time and pricing; "Open" implies the value is flexible or variable, while "Fixed" implies a set, predetermined value.
1.4Business Value

This feature improves operational efficiency by reducing the time staff spend searching for core service details. By centralizing these key settings in a standardized, easy-to-read format, the team can quickly verify service parameters, minimize errors during customer interactions, and ensure that service delivery aligns with the current configuration.
