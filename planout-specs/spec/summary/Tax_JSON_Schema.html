1.  Data
1.1Overview

The Tax JSON Schema feature provides a structured way for the Lumi ERP system to manage, retrieve, and display tax-related records. It allows users to view detailed tax information—including associated suppliers, warehouses, and line-item breakdowns—through a flexible search and filtering system. This ensures that financial data is organized, easily accessible for reporting, and ready for use in dropdown menus or comprehensive list views.

1.2Step-by-Step Flow
1.Request Initiation: The system receives a request to either fetch a simple list of active tax options (for dropdown menus) or a detailed, paginated list of tax records.
2.Filtering: If a detailed list is requested, the system applies any provided filters, such as status (active/inactive), specific date ranges (based on creation or update dates), or a specific tax ID.
3.Pagination: The system calculates the total number of records matching the filters and divides them into pages to ensure the application remains fast and responsive.
4.Data Retrieval: The system fetches the core tax records from the database.
5.Data Enrichment: For each tax record found, the system automatically gathers related information, such as supplier details, warehouse locations, user information, journal entries, and individual tax line items.
6.Summary Calculation: The system calculates totals (such as subtotal, tax amount, and grand total) based on the retrieved line items.
7.Response Delivery: The final, enriched data set is returned to the user interface, including metadata about the total number of records and pages available.
1.3Key Concepts
–Pagination: A method of breaking large amounts of data into smaller, manageable chunks (pages) to improve system performance and user experience.
–Filtering: The ability to narrow down search results based on specific criteria like dates or status, helping users find exactly what they need.
–Data Enrichment: The process of automatically pulling in related information (like supplier or warehouse names) so that a single tax record provides a complete, "all-in-one" view of the transaction.
–Tax Line Items: Individual components of a tax record that detail specific products, quantities, prices, and discounts, which are then used to calculate the final tax summary.
–Workflow State: A status indicator that helps distinguish between active tax records and those that are no longer in use.
1.4Business Value

This feature centralizes tax data management, reducing the time spent manually cross-referencing information across different parts of the ERP. By providing automated summaries and flexible filtering, it enables finance teams to generate accurate reports quickly and ensures that tax information is consistently available for both high-level overviews and detailed audits.
