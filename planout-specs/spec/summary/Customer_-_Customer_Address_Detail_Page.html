1.  Frontend
1.1Overview

The Customer Address Detail Page provides a centralized view of all physical addresses associated with a specific customer. This page is designed to help staff quickly verify contact information, shipping details, and geographic locations for Retail, Wholesale, and Franchisee customers. It ensures that address data is presented clearly and allows for easy navigation to edit information when necessary.

1.2Step-by-Step Flow
1.Page Loading: When you navigate to the page, the system automatically retrieves the customer's profile and their complete list of registered addresses.
2.Navigation Context: The page displays the main navigation menu with the "Customers" tab highlighted, and a specific sub-menu tailored to the customer's business type (Retail vs. Wholesale/Franchisee).
3.Customer Identification: The customer’s name is displayed prominently at the top of the page for easy identification.
4.Address Display: All addresses associated with the customer are listed in individual cards. Each card includes:

* The full address (street, village, district, city, province, country, and postal code).

* Contact details (phone numbers and fax).

* Status flags (identifying if it is the main address or a shipping address).

* Geographic coordinates (latitude and longitude).

* Audit timestamps (when the address was created and last updated).

5.Editing: Each address card includes an "Edit" button that directs you to the customer's edit page to make any necessary updates.
1.3Key Concepts
–Customer Type: A classification that determines which navigation menu options are shown, ensuring the interface is relevant to the specific business relationship (Retail, Wholesale, or Franchisee).
–Address Card: A structured summary block for a single address, containing all relevant contact, location, and status information.
–Status Flags: Simple "Yes/No" indicators that clarify if an address is designated as the primary (Main) address or the designated Shipping address.
–Audit Timestamps: Read-only information showing when an address record was first created and when it was last modified, providing transparency on data freshness.
1.4Business Value
–Improved Data Accuracy: By displaying all address components (including geographic coordinates and status flags) in one place, staff can easily verify and maintain high-quality customer records.
–Operational Efficiency: The tailored navigation menus and clear address cards reduce the time spent searching for specific contact details, allowing staff to handle customer inquiries or logistics tasks faster.
–Seamless Workflow: The direct link to the edit page ensures that when discrepancies are found, staff can immediately transition to updating the information without navigating through multiple menus.
2.  Logic
2.1Overview

The Customer Address Detail feature provides a comprehensive view of all registered addresses for a specific customer within the Lumi ERP system. Whether the customer is a retail, wholesale, or franchisee account, this page consolidates their location data, contact information, and geographic coordinates into a clear, easy-to-read format.

2.2Step-by-Step Flow
1.Identify Customer: When you open a customer’s profile, the system identifies the specific customer ID to ensure the correct data is retrieved.
2.Retrieve Basic Information: The system fetches the customer's core profile details (such as name and customer type) to confirm the identity of the account being viewed.
3.Fetch Address Records: The system pulls all associated address records linked to that customer.
4.Format and Display: The system combines individual address components—such as street, village, district, city, province, country, and postal code—into a single, readable address string. It then maps all relevant contact details (phones, fax, and address type) and location markers (latitude/longitude) to the screen for the user to review.
2.3Key Concepts
–Address Consolidation: The process of taking separate data fields (like village, district, and city) and merging them into one complete, comma-separated address line for better readability.
–Address Categorization: The system distinguishes between different types of addresses, specifically identifying which entries are designated as the "Main Address" or the "Shipping Address."
–Geographic Tagging: The inclusion of latitude and longitude data, which allows the system to support mapping or location-based services for each address.
–Audit Timestamps: Every address record includes "Created At" and "Updated At" information, providing transparency on when the address data was first added or last modified.
2.4Business Value
–Improved Data Accuracy: By automatically formatting address components, the system ensures that location data is presented consistently, reducing confusion for staff.
–Operational Efficiency: Users can quickly distinguish between billing, shipping, and main office locations, which is critical for managing logistics and communication for retail, wholesale, and franchisee accounts.
–Enhanced Customer Insight: Having all contact methods (multiple phone lines and fax) and precise geographic coordinates in one place allows for better coordination of deliveries and field services.
3.  Data
3.1Overview

The Customer Address Detail page is designed to provide a comprehensive view of location-specific information for any customer within the Lumi ERP system. Whether the customer is a retail shopper, a wholesale partner, or a franchisee, this feature ensures that all contact and geographical details are easily accessible and clearly presented in one place.

3.2Step-by-Step Flow
1.Page Initialization: When you navigate to a customer's profile, the system automatically triggers a request to retrieve the specific address records associated with that customer.
2.Data Retrieval: The system searches the database for the address linked to that unique customer ID. If no address is found, the system will notify the user that the information is unavailable.
3.Data Formatting: Once the raw data is retrieved, the system organizes it into a user-friendly format. This includes combining the street address with the village, district, city, province, country, and postal code into a single, readable address line.
4.Display: The final, formatted information—including contact numbers, address type, and geographical coordinates—is displayed on the screen for the user to review.
3.3Key Concepts
–Address Detail: A complete record containing not just the street address, but also the full regional hierarchy (village, district, city, etc.) and contact methods like phone and fax numbers.
–Address Classification: Indicators that define the purpose of the address, specifically identifying if it is the "Main Address" or the "Shipping Address" for the customer.
–Geographical Coordinates: Latitude and longitude data included to support mapping or location-based services.
–Audit Timestamps: Information showing when the address record was first created and when it was last updated, ensuring data transparency.
3.4Business Value

This feature streamlines operations by providing a centralized, accurate source of truth for customer locations. By automatically formatting complex address data into a clean, readable layout, it reduces manual data entry errors and helps staff quickly verify shipping and contact details. This is essential for maintaining efficient logistics and communication across all customer types, including retail, wholesale, and franchise accounts.
