1.  Logic
1.1Overview

This feature allows the system to officially record a new purchase order initiated by a franchise. It acts as a digital bridge between a warehouse, a specific store, and a supplier, ensuring that inventory movement requests are captured accurately within the Lumi ERP system.

1.2Step-by-Step Flow
1.Security Verification: The system first checks if the user is logged in and possesses the necessary permissions to create purchase orders. If not, the request is blocked.
2.Data Validation: The system verifies that the request includes all essential information: where the goods are coming from (warehouse), where they are going (store), and which supplier is involved.
3.Order Creation: Once validated, the system generates a unique identifier for the order, sets the initial status to "Pending," and records the timestamp and the user who created it.
4.Database Storage: The completed order details are saved into the system’s permanent records.
5.Confirmation: The system returns the full details of the newly created order to the user as confirmation that the process was successful.
1.3Key Concepts
–Franchise Purchase Order: A formal request document that tracks the movement of inventory from a central warehouse to a specific franchise store.
–Authentication: The process of verifying the identity of the user to ensure they are a recognized member of the system.
–Authorization: The process of checking if a verified user has the specific "permission" required to perform the action of creating an order.
–Pending Status: The default state assigned to a new order, indicating that it has been successfully created but has not yet been processed or fulfilled.
1.4Business Value
–Operational Efficiency: Automates the manual entry of franchise orders, reducing the risk of human error and speeding up the supply chain process.
–Inventory Accuracy: By requiring specific warehouse and store identifiers, the system ensures that inventory levels are tracked correctly across all locations.
–Accountability: Every order is linked to the user who created it and includes a precise timestamp, providing a clear audit trail for management.
–Standardization: Enforces a consistent process for all franchise locations, ensuring that no order is created without the necessary supplier and location details.
2.  Data
2.1Overview

This feature enables the system to officially record a new franchise purchase order. It acts as a digital bridge between a warehouse, a specific store, and a supplier, ensuring that all inventory movement requests are tracked accurately within the Lumi ERP system.

2.2Step-by-Step Flow
1.Validation: The system first checks that the warehouse, store, and supplier identified in the request actually exist in our records. If any of these are missing or invalid, the request is rejected.
2.Order Creation: Once validated, the system generates a unique identifier for the order and assigns it a "Pending" status.
3.Data Logging: The system automatically records the exact time the order was created and identifies which authorized user initiated the request.
4.Persistence: The completed order details are saved into the central database.
5.Confirmation: The system returns the finalized order record to the user as confirmation that the process was successful.
2.3Key Concepts
–Franchise Purchase Order: A formal request document that tracks inventory being moved from a warehouse to a specific franchise store via a designated supplier.
–Validation: A safety check performed by the system to ensure that all parties involved (warehouse, store, and supplier) are recognized entities before an order is processed.
–Pending Status: The initial state of a new order, indicating that it has been successfully created but has not yet been fulfilled or completed.
–Audit Trail: The automatic recording of "who" created the order and "when," which ensures accountability and transparency for all inventory transactions.
2.4Business Value
–Data Integrity: By validating references before saving, the system prevents "orphan" orders or errors caused by incorrect store or warehouse information.
–Operational Efficiency: Automating the creation of these records reduces manual data entry and ensures that all franchise locations have a standardized way to request stock.
–Accountability: Every order is linked to an authenticated user and a timestamp, providing a clear history for inventory audits and troubleshooting.
