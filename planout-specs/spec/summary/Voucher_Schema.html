1.1Overview

The Voucher Schema feature provides a structured way to manage vouchers within the Lumi ERP system. It defines how vouchers are created, stored, and retrieved, ensuring that each voucher is correctly linked to a product and configured with specific rules regarding where it can be sold and redeemed. This feature also includes logic to automatically determine the current status of a voucher based on its validity dates.

1.2Step-by-Step Flow
1.Voucher Definition: A voucher is defined by its core settings, including its type (standard, batch, or flexible), pricing, and whether it is restricted to members.
2.Product Association: Every voucher is linked to a specific product, allowing the system to pull in relevant product details like the SKU and name for reporting and display.
3.Location Configuration: The system determines the "scope" for selling and redeeming the voucher. If the scope is set to "all," the voucher is valid at every store. If set to "specific," the system references a list of authorized stores.
4.Data Retrieval: When a user requests a list of vouchers, the system gathers the voucher details, joins them with the associated product information, and aggregates the list of authorized stores (if applicable).
5.Status Calculation: As the list is generated, the system checks the current date against the voucher's expiration date to automatically flag the status as "active," "inactive," or "expired."
1.3Key Concepts
–Voucher Scope: A setting that defines whether a voucher is available at all locations or restricted to a specific subset of stores.
–Product Linkage: The connection between a voucher and a product, ensuring that voucher data is always associated with a recognized item in the inventory.
–Dynamic Status: An automated check that updates a voucher's status to "expired" if the current date has passed the defined validity period.
–Aggregated Location Data: A feature that combines multiple store names into a single, readable list for the user, rather than showing individual database records.
1.4Business Value
–Operational Efficiency: By automating the status calculation and location aggregation, staff no longer need to manually track which vouchers are expired or where they can be used.
–Improved Accuracy: Centralizing the voucher configuration ensures that pricing, member restrictions, and location rules are applied consistently across the entire organization.
–Better Reporting: Linking vouchers to products allows for clearer insights into sales performance and redemption trends, helping the business make data-driven decisions about future promotions.
