1.  Frontend
1.1Overview

The Products Sub Menu is a navigation component designed to help users easily switch between different product-related views within the Lumi ERP system. It functions as an accordion-style menu, providing a clear and organized way to access the main product lists. By default, the system highlights the "Products" section when a user first accesses the menu, ensuring they land on the primary product list immediately.

1.2Step-by-Step Flow
1.Upon loading the Products section, the system automatically sets "Products" as the active view and displays the Products List Page.
2.The user is presented with an accordion menu containing two options: "Products" and "Service Products."
3.When the user clicks on "Products," the system updates the active state to "Products" and navigates the user to the Products List Page.
4.When the user clicks on "Service Products," the system updates the active state to "Service Products" and navigates the user to the Service Products List Page.
1.3Key Concepts
–Accordion Menu: A vertical navigation style that organizes links into a compact, expandable list, keeping the interface clean.
–Active State: A visual indicator that highlights which menu item the user is currently viewing, helping them maintain context while navigating.
–Default State: The pre-selected setting that ensures the user sees the most relevant information (in this case, the main Products list) as soon as they arrive.
–Navigation Routing: The mechanism that directs the user to the correct page within the ERP system based on their menu selection.
1.4Business Value

This feature improves the user experience by providing a predictable and intuitive way to navigate product categories. By standardizing the menu layout and ensuring a consistent "active" state, users can move between standard products and service products without losing their place. This reduces navigation friction and helps staff manage inventory and service offerings more efficiently within the ERP.
