1.  Frontend
1.1Overview

The Products Sub Menu is a navigation component designed to help users easily switch between different product-related views within the ERP system. It functions as an accordion-style menu, providing a clean and organized way to access the main "Products" list and the "Service Products" list. By default, the system highlights the "Products" section when the user first arrives, ensuring they are immediately directed to the primary product view.

1.2Step-by-Step Flow
1.Initialization: When the component loads, the system automatically sets "Products" as the active tab, ensuring the user sees the standard Product List Page by default.
2.User Interaction: The user selects either "Products" or "Service Products" from the navigation menu.
3.State Update: The system updates the visual interface to highlight the selected menu item, providing clear feedback on which section is currently active.
4.Navigation: The system redirects the user to the corresponding page (either the Product List or the Service Products List) based on their selection.
1.3Key Concepts
–Accordion Menu: A compact navigation style that organizes links into a vertical list, allowing users to switch between related categories efficiently.
–Active Tab State: A background mechanism that tracks which menu item the user is currently viewing, allowing the system to highlight that item visually.
–Default Routing: The automatic behavior that ensures the user is placed on the most relevant page (the main Products list) as soon as the component is accessed.
1.4Business Value

This feature improves the user experience by providing a predictable and intuitive way to navigate the ERP’s product catalog. By centralizing these navigation options, users can switch between standard products and service-based products without leaving the context of the product management area. This reduces navigation time and helps users maintain focus on their tasks within the ERP system.
