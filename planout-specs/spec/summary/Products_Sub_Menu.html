1.  Frontend
1.1Overview

This feature is a small navigation menu that appears in the header of the ERP system, under the "Products" section. It works like a dropdown or accordion list that lets users switch between two views: a general "Products" list and a "Service Products" list. Everything happens instantly on the user's screen — there's no waiting, no server requests, and no data entry involved. It's purely about helping users move between two related pages quickly and clearly.

1.2Step-by-Step Flow
1.The user sees a "Products Menu" heading in the header, which acts as an expandable/collapsible section (an accordion).
2.When the user clicks on this heading, the section opens or closes, revealing (or hiding) two navigation options: "Products" and "Service Products."
3.By default, when the page first loads, the menu is already open and "Products" is automatically selected and highlighted — so the Products List Page is shown right away without the user needing to click anything.
4.If the user clicks "Products," the system highlights that option and displays the Products List Page.
5.If the user clicks "Service Products," the system highlights that option instead and displays the Service Products List Page.
6.Whichever option is selected, the visual highlight and the page shown update immediately and stay in sync with each other — clicking a menu item always shows the matching page right away.
7.Users can also navigate this menu using a keyboard (not just a mouse), ensuring accessibility for all users.
1.3Key Concepts
–Accordion menu: A collapsible section that expands to show more options and collapses to hide them, used here for the "Products Menu."
–Active state: A visual indicator (like a highlight or bold text) showing which menu option is currently selected.
–Default selection: The "Products" option is automatically chosen when the page loads, so users immediately see the Products List Page without extra clicks.
–Synchronized navigation: The menu selection and the displayed page are always kept in sync — selecting an item and seeing its matching page happen together, instantly.
–Client-side behavior: All actions (opening the menu, switching pages) happen directly on the user's screen with no delay, since there's no data being fetched from a server for this menu itself.
1.4Business Value

This feature gives users a fast, intuitive way to move between related product views without confusion or delay. By automatically showing the most relevant page (Products) by default, it reduces extra clicks and helps users get to what they need faster. Because the menu responds instantly and works well with keyboards, it also improves accessibility and overall user experience, reflecting well on the professionalism and usability of the ERP system's interface.
