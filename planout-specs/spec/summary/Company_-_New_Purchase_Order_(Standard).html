1.  Frontend
1.1Overview

The "New Purchase Order (Standard)" feature provides a structured digital form for creating purchase orders within the Lumi ERP system. This interface allows users to input supplier details, delivery information, and a list of products to be ordered. It includes built-in tools for managing itemized discounts and bulk importing product lists, ensuring that purchase orders are accurate and consistent before they are submitted for processing.

1.2Step-by-Step Flow
1.Initialization: The user opens the form, where a unique reference code is automatically generated.
2.Header Setup: The user selects the supplier and warehouse, sets the delivery due date, and provides any necessary delivery addresses or internal notes.
3.Adding Items: The user can either manually add items to the order table or use the "Import Items" feature to upload a list via a template.
4.Discount Management: For each item, the user can open a dedicated discount modal to specify a discount by either a fixed amount or a percentage, and toggle tax inclusion.
5.Validation & Calculation: The system automatically calculates the final prices and taxes based on the inputs provided.
6.Submission: Once all details are confirmed, the user saves the form, which validates the required fields and submits the order to the system, redirecting the user to the main purchase order list.
1.3Key Concepts
–Reference Code: A unique, system-generated identifier for the purchase order that cannot be manually edited.
–Discount Modal: A pop-up tool that allows for precise, item-level discount adjustments (either by currency amount or percentage) with real-time tax calculation.
–Import/Export Template: A feature that allows users to download a standard file format to bulk-upload product lists, reducing manual data entry.
–Dynamic Delivery Address: A field that defaults to the selected warehouse's address but allows for manual overrides if the delivery location differs.
–Workflow Status: A visual tracker that displays the lifecycle of the order (Draft, Sent, or Received) to keep stakeholders informed of the document's progress.
1.4Business Value
–Efficiency: The ability to import items via a template significantly reduces the time spent on manual data entry for large orders.
–Accuracy: Automated calculations for discounts and taxes minimize human error, ensuring that financial data on purchase orders is reliable.
–Standardization: By enforcing required fields and providing a structured layout, the system ensures that all purchase orders contain the necessary information for procurement and warehouse teams to operate effectively.
–Flexibility: The discount modal provides granular control over pricing, allowing the business to apply specific terms to individual products as needed.
