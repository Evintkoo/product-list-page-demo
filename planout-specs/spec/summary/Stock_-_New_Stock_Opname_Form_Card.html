1.  Frontend
1.1Overview

The New Stock Opname Form Card is a dedicated interface designed to help inventory managers record stock counts efficiently. This form allows users to specify the location, product categories, and brands being audited, while providing tools to quickly populate product lists to save time during the data entry process.

1.2Step-by-Step Flow
1.Select Store: The user begins by selecting the relevant store from a dropdown menu. This selection is mandatory and acts as the foundation for the rest of the form.
2.Define Scope: The user selects the specific Product Type and Product Brand they wish to audit.
3.Set Date and Notes: The user enters the completion date for the audit and adds any necessary context in the required notes field.
4.Reference Code: A unique reference code is automatically generated by the system once the form is created; this field is read-only and cannot be manually edited.
5.Populate Data: The user can click the "Autofill" button to automatically pull in the relevant product list for the selected store. If the store has not been selected, the system will prompt the user to do so first.
6.Advanced Options: For more complex requirements, the user can click the "Advanced" button to open a modal with additional configuration options.
7.Submission: Once all required fields are filled, the user submits the form to save the stock opname record. The system validates the input and alerts the user if any required information is missing.
1.3Key Concepts
–Stock Opname: The process of verifying the physical inventory count against the system records.
–Autofill: A time-saving feature that automatically populates the form with a list of products based on the selected store, reducing manual data entry.
–Reference Code: A unique identifier assigned to each stock audit record for tracking and reporting purposes.
–Validation: A built-in check that ensures all mandatory fields (Store, Product Type, Product Brand, Date, and Notes) are completed before the record can be saved.
1.4Business Value
–Increased Accuracy: By requiring specific store and product details, the form ensures that inventory data is categorized correctly, reducing errors in stock reporting.
–Operational Efficiency: The "Autofill" functionality significantly reduces the time spent manually adding products to an audit, allowing staff to focus on the physical count.
–Standardized Record Keeping: The mandatory fields and automated reference codes ensure that every stock audit is documented consistently, making it easier to track inventory history and audit trails across different store locations.
2.  Logic
2.1Overview

The "New Stock Opname Form Card" is a feature designed to help staff initiate a new inventory count session. By selecting specific criteria—such as the store location, product category, and brand—users can create a structured "draft" session. This ensures that the stock-taking process is organized and targeted, allowing for accurate tracking of inventory levels within the Lumi ERP system.

2.2Step-by-Step Flow
1.Selection: The user selects the specific store, product type, and product brand from the provided dropdown menus on the form card.
2.Validation: The system checks that all three fields have been filled out. If any information is missing, the system will prompt the user to complete the selection.
3.Initialization: Once the criteria are confirmed, the system records the current date and time to create a new inventory session.
4.Session Creation: The system saves this new session as a "Draft" in the database, establishing the foundation for the upcoming stock count.
2.3Key Concepts
–Stock Opname: The formal process of counting physical inventory to ensure it matches the records in the system.
–Draft Status: A temporary state for a new inventory session, indicating that the count has been initialized but is not yet finalized or submitted.
–Filter Criteria: The specific parameters (Store, Product Type, and Brand) used to narrow down the scope of the inventory count, ensuring staff only count the items relevant to their current task.
2.4Business Value

This feature streamlines the inventory management process by reducing manual errors and providing a clear starting point for stock-taking. By requiring users to define the scope of the count (store, type, and brand) before they begin, the business ensures that inventory data remains organized, traceable, and consistent across all locations. This leads to more reliable stock reports and better-informed purchasing decisions.
