1.  Frontend
1.1Overview

The "Company" sub-menu is a new navigation component designed to help users easily manage their organizational information within the Lumi ERP system. It functions as an accordion-style menu, providing a clean and organized way to switch between core company management tasks. By default, the system directs users to the Company Data view, ensuring they land on the most relevant information immediately upon accessing this section.

1.2Step-by-Step Flow
1.Initial Load: When a user accesses the "Company" section, the sub-menu defaults to the "Company Data" view, which is automatically highlighted to show it is the active page.
2.Selecting Company Data: If the user is on a different screen and clicks "Company Data," the system updates the menu highlight and navigates the user to the Company List page.
3.Selecting Company Settings: If the user clicks "Company Settings," the system updates the menu highlight to reflect this choice and navigates the user to the Company Settings page.
4.Visual Feedback: As the user switches between these options, the menu provides clear visual cues (such as bold text and a side border) to indicate which section is currently active.
1.3Key Concepts
–Accordion Menu: A vertical navigation list that keeps related links grouped together, helping to save screen space while keeping options accessible.
–Active State: A visual indicator that tells the user exactly which page or section they are currently viewing.
–Navigation Routing: The behind-the-scenes process that ensures clicking a menu item instantly loads the correct page without requiring a full page refresh.
1.4Business Value

This feature improves the user experience by providing a predictable and intuitive way to navigate the ERP system. By grouping "Company Data" and "Company Settings" together, users can switch between operational tasks and configuration settings with a single click. This reduces navigation time and helps users maintain focus on their work by providing clear, persistent visual feedback on their current location within the application.
