1.  Frontend
1.1Overview

The Customer Vehicles page provides a centralized view for managing and searching the fleet of vehicles associated with your customers. This feature allows users to quickly locate specific vehicles using various search criteria and status filters, ensuring that information regarding vehicle ownership, service contracts, and registration details is easily accessible.

1.2Step-by-Step Flow
1.Page Initialization: When the page loads, the system automatically retrieves and displays all "Active" vehicles.
2.Status Filtering: Users can toggle between "Active" and "Inactive" tabs to instantly update the list based on the vehicle's current status.
3.Advanced Search: Users can narrow down the list by entering specific details such as Customer name, Hull Number, Registration Number, or VIN.
4.Categorical Filtering: Users can further refine results by selecting a specific Vehicle Type (e.g., Car, Motorcycle, Heavy Equipment) or a specific Store location.
5.Date Range Filtering: Users can select a date type (Created Date or Registration Date) and define a "From" and "To" date range to isolate records within a specific timeframe.
6.Applying Filters: After setting the desired criteria, clicking the "Search" button refreshes the table to show only the matching records.
7.Data Export: A "Download" button is available to export the currently filtered list for external reporting or record-keeping.
8.Navigation: Clicking on any row in the vehicle table will navigate the user directly to the details page for that specific customer.
1.3Key Concepts
–Active/Inactive Status: A toggle that filters the list to show only currently operational vehicles or those that have been archived/deactivated.
–Search Filters: A set of input fields and dropdowns that allow users to query the database for specific vehicles based on unique identifiers or categories.
–Date Range: A flexible filter that allows users to search for vehicles based on when they were created or registered.
–Data Table: The main display area that organizes vehicle information into columns, such as Make, Model, Year, and Service Contract, for easy comparison.
–Row Redirection: A navigation feature where clicking a vehicle record takes the user to the associated customer's profile.
1.4Business Value

This feature streamlines customer management by reducing the time spent searching for vehicle records. By providing granular filtering options, staff can quickly verify service contracts, check registration details, or identify vehicle ownership, leading to more efficient customer service and improved operational oversight of the fleet.

2.  Logic
2.1Overview

The Customer Vehicles page provides a centralized view of all vehicle records within the Lumi ERP system. To help users manage their fleet efficiently, the page includes a status-based filtering system that allows you to toggle between active and inactive vehicles. By default, the page loads with the "Active" filter applied, ensuring you see the most relevant information immediately upon arrival.

2.2Step-by-Step Flow
1.Initial Load: When you first open the page, the system automatically retrieves and displays all vehicles currently marked as "Active."
2.Filtering: You can switch between "Active" and "Inactive" views using the status tabs provided above the vehicle table.
3.Data Retrieval: Whenever you select a tab, the system sends a request to the database to fetch only the vehicles matching that specific status.
4.Display: The table updates to show the relevant vehicle details, including registration numbers, make, model, customer association, and service contract information.
2.3Key Concepts
–Status Filter: A toggle mechanism that restricts the list of vehicles based on their current operational status (Active vs. Inactive).
–Vehicle Details: The comprehensive set of information displayed for each record, such as identification numbers (VIN/FIN), physical descriptions (make/model/year), and business context (assigned customer, store location, and service contract).
–Default View: The pre-configured state of the page that prioritizes active records to streamline daily operations.
2.4Business Value

This feature improves operational efficiency by allowing staff to quickly isolate active fleet assets from inactive ones. By providing a clean, filtered view, users can reduce clutter, focus on current service contracts and customer assignments, and easily manage the lifecycle of vehicles within the ERP without manually sorting through historical or retired data.

3.  Data
3.1Overview

The Customer Vehicles feature provides a centralized view within the Lumi ERP system to manage and track vehicle information. This page allows users to see a comprehensive list of vehicles associated with customers, including key identification details, service contract information, and the store location. To help users focus on relevant information, the page includes a filtering capability to display only vehicles with a specific status.

3.2Step-by-Step Flow
1.Request: The user accesses the vehicle list page, optionally selecting a specific status filter (e.g., "Active").
2.Data Retrieval: The system gathers vehicle records, automatically linking each vehicle to its corresponding customer, service contract, and store location.
3.Filtering: If a status filter was selected, the system narrows the list to show only those vehicles; otherwise, it displays the full list.
4.Sorting: The system organizes the final list by the date the vehicle record was created, showing the most recently added vehicles at the top.
5.Display: The information is presented in a clear table format, showing details such as registration number, make, model, year, and associated business entities.
3.3Key Concepts
–Vehicle Status: A label assigned to a vehicle that allows users to categorize them (e.g., Active, Inactive) and filter the list accordingly.
–Linked Entities: The system automatically connects vehicle records to other important business data, such as the assigned Customer, the active Service Contract, and the responsible Store.
–Identification Details: Specific identifiers—such as Registration Number, VIN (Vehicle Identification Number), and FIN (Fleet Identification Number)—that ensure each vehicle is uniquely and accurately tracked.
3.4Business Value

This feature improves operational efficiency by providing a single source of truth for the vehicle fleet. By allowing users to filter by status, staff can quickly identify active assets, reducing the time spent searching through records. Furthermore, by linking vehicles directly to customers, service contracts, and stores, the system ensures that support teams and managers have immediate access to the context needed to provide better customer service and manage maintenance agreements effectively.
