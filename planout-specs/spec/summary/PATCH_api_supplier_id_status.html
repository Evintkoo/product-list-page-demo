1.  Logic
1.1Overview

This feature provides a simple way to toggle a supplier's status between "active" and "inactive" within the Lumi ERP system. By using this update tool, you can quickly manage your supplier list, ensuring that only currently relevant partners are marked as active in your records.

1.2Step-by-Step Flow
1.Request Submission: You provide the unique ID of the supplier you wish to update and specify the new status (active or inactive).
2.Validation: The system checks that the request is formatted correctly and that the status provided is a valid "on/off" choice.
3.Verification: The system searches for the supplier. It confirms the supplier exists and ensures that the supplier belongs to your company, preventing unauthorized access to other companies' data.
4.Update: If everything is correct, the system updates the supplier's status and records the exact time the change was made.
5.Confirmation: The system returns a success message containing the supplier's ID, their new status, and the timestamp of the update. If any errors occur (such as an invalid request or a missing supplier), the system will provide an appropriate error message.
1.3Key Concepts
–Supplier Status: A simple toggle (active/inactive) that determines if a supplier is currently available for business operations.
–Ownership Verification: A security measure that ensures you can only modify suppliers associated with your specific company account.
–Timestamping: An automatic record of when the status was last changed, providing an audit trail for your supplier management.
1.4Business Value

This feature streamlines supplier management by allowing for real-time updates to your vendor database. It reduces manual administrative work and helps maintain data integrity by ensuring that your active supplier list is always up-to-date, which is critical for accurate procurement and reporting.

2.  Data
2.1Overview

This feature provides a secure way to update the status of a supplier (e.g., marking them as "active" or "inactive") within the Lumi ERP system. It allows authorized users to toggle a supplier's availability, ensuring that only companies with the correct permissions can modify their own supplier records.

2.2Step-by-Step Flow
1.Request Initiation: The system receives a request to update a specific supplier's status, identifying the supplier by their unique ID and providing the new status (active or inactive).
2.Security & Ownership Check: The system attempts to update the record, but it strictly limits this action to suppliers that belong to the company currently making the request.
3.Validation:

* If the update is successful, the system confirms the change and provides the updated status and timestamp.

* If the update fails, the system checks if the supplier exists at all. If the supplier does not exist, it reports that the record could not be found. If the supplier exists but belongs to a different company, the system denies the request to protect data privacy.

2.3Key Concepts
–Data Isolation: A security measure that ensures a company can only view or modify its own supplier data, preventing unauthorized access to other companies' information.
–Status Toggle: The ability to switch a supplier between "active" and "inactive" states, which helps manage procurement workflows and supplier relationships.
–Authentication Context: The system automatically recognizes which company is making the request, ensuring that the "ownership" check happens seamlessly in the background.
2.4Business Value

This feature improves operational control and data security. By allowing businesses to easily deactivate suppliers, companies can maintain accurate records and prevent accidental transactions with inactive partners. Furthermore, the built-in ownership checks ensure that sensitive supplier information remains private and protected from unauthorized access by other organizations using the platform.
