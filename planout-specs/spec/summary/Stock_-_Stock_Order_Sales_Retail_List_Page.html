1.  Frontend
1.1Overview

The "Stock Order Sales Retail List Page" is a dedicated view within the Lumi ERP system designed to help staff manage and track stock orders specifically related to retail sales. This page provides a clear, organized list of orders, allowing users to monitor the status of inventory moving between warehouses and stores to fulfill customer demand.

1.2Step-by-Step Flow
1.Initial Loading: When you navigate to the page, the system automatically fetches the most recent retail stock orders.
2.Data Retrieval: The system pulls relevant order information, such as order codes, dates, store/warehouse locations, and current status.
3.Display: The information is presented in a structured table, making it easy to compare order amounts against what has actually been received.
4.Filtering: You can use the search toolbar to narrow down the list. You can filter by specific order numbers, date ranges, store or warehouse locations, and current workflow status to find exactly what you need.
5.Refining Results: Once you apply your filters and click "Search," the table updates to show only the records that match your criteria.
1.3Key Concepts
–Stock Order: A formal request for inventory movement, specifically triggered by retail sales or e-commerce activity.
–Workflow State: The current stage of an order (e.g., pending, in-transit, or received), which helps staff understand if an order requires immediate attention.
–Search Toolbar: A set of controls that allows users to filter the list of orders by various criteria, such as date, location, or status, to improve visibility.
–Order vs. Received Amount: A comparison feature that shows the total quantity requested versus the quantity that has arrived, helping to identify discrepancies or partial shipments.
1.4Business Value

This feature centralizes retail-related inventory management, reducing the time staff spend searching for order information. By providing real-time visibility into the status of stock orders—from the moment they are created until they are received—the system helps prevent stockouts, improves the accuracy of inventory records, and ensures that retail stores are properly stocked to meet customer demand.

2.  Logic
2.1Overview

The Sales Retail Stock Order List page provides a centralized view for tracking inventory movements specifically related to retail sales. This feature automatically retrieves and displays relevant stock orders, allowing staff to monitor the status of orders originating from retail sales or shipping-related sales activities.

2.2Step-by-Step Flow
1.Initialization: When the page loads, the system automatically triggers a request to fetch the latest stock order data.
2.Data Retrieval: The system requests only "sales_retail" type orders from the database, retrieving them in batches of 20 to ensure optimal performance.
3.Filtering: The system automatically filters the retrieved list to include only orders specifically marked as "sale" or "shipping_sale," ensuring that unrelated stock movements are excluded.
4.Data Mapping: The system organizes the filtered data into a clear, readable format, matching specific order details (such as reference codes, dates, store/warehouse locations, and current status) to the corresponding columns in the user interface.
5.Display: The final, organized list is presented to the user in the Sales Retail Stock Order table.
2.3Key Concepts
–Stock Order: A formal request to move inventory between locations, in this case, triggered by retail sales activity.
–Source Type: A classification that identifies the origin of the order (e.g., a standard sale or a shipping-based sale), used here to ensure only relevant retail data is shown.
–Workflow State: The current status of an order (e.g., pending, in-transit, or completed), which helps users understand where an order is in the fulfillment process.
–Pagination: The practice of loading data in smaller chunks (20 items at a time) to keep the page responsive and easy to navigate.
2.4Business Value

This feature streamlines retail inventory management by providing a dedicated, filtered view of sales-related stock orders. By automating the retrieval and organization of this data, it reduces manual effort for staff, minimizes the risk of viewing irrelevant information, and provides real-time visibility into the status of retail-driven inventory movements, ultimately supporting more efficient order fulfillment.

3.  Data
3.1Overview

The Sales Retail Stock Order List page provides a centralized view for tracking inventory movements specifically related to retail sales. This feature automatically retrieves and displays a list of stock orders that originated from retail sales or shipping sales, allowing staff to monitor the status, timing, and quantities of these orders in one place.

3.2Step-by-Step Flow
1.Page Initialization: When you open the Sales Retail Stock Order page, the system automatically triggers a request to fetch the relevant order data.
2.Data Retrieval: The system filters the inventory database to find only "sales retail" stock orders that originated from a sale or shipping sale. It retrieves these in batches of 20 records at a time.
3.Data Processing: The system takes the raw order information and organizes it into a clear, readable format suitable for the table view.
4.Display: The processed information—including order references, store and warehouse locations, dates, current status, and quantities—is populated into the table for your review.
3.3Key Concepts
–Sales Retail Stock Order: A specific type of inventory request created to fulfill a retail sale or a shipping-based sale.
–Workflow State: The current status of the order (e.g., pending, in progress, or completed), which helps you track where the order is in the fulfillment process.
–Order vs. Received Amount: A comparison of the quantity originally requested versus the quantity actually received, helping you identify discrepancies or partial shipments.
–Reference Codes: Unique identifiers for both the stock order itself and the original sale, allowing you to easily cross-reference the inventory movement with the actual customer transaction.
3.4Business Value

This feature improves operational efficiency by providing a dedicated workspace for retail inventory management. By filtering out irrelevant data and presenting only retail-specific sales orders, staff can quickly identify which orders are due, track their progress through the workflow, and verify that the correct amount of stock has been received. This reduces manual searching and helps ensure that retail sales are fulfilled accurately and on time.
