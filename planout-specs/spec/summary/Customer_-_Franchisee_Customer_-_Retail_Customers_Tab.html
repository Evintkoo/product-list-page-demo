1.1Overview

The "Retail Customers" tab is a dedicated view within the Franchisee Customer Details page. Its purpose is to provide a clear, organized list of all retail customers associated with a specific franchisee, allowing users to quickly reference key contact and identification information for those customers.

1.2Step-by-Step Flow
1.Navigation Context: When viewing a franchisee's profile, the system highlights the "Customers" section in both the main and sub-menus to ensure the user knows their current location.
2.Page Identification: The page displays the specific name of the franchisee at the top, confirming which profile is currently being viewed.
3.Tab Selection: Within the franchisee details, the user selects the "Retail Customers" tab from the navigation bar.
4.Data Retrieval: The system automatically fetches the list of retail customers linked to that specific franchisee. A loading indicator is shown while this data is being retrieved.
5.Data Display: Once loaded, the information is presented in a table format containing the following details for each customer:

* A sequential row number.

* The unique customer code.

* The customer's full name.

* The customer's phone number.

1.3Key Concepts
–Franchisee: A business partner or entity that manages a specific set of retail customers within the Lumi ERP system.
–Retail Customer: An individual or entity that purchases goods or services from a franchisee.
–Loading State: A temporary visual indicator that informs the user that the system is currently fetching data from the database.
–Navigation Tabs: A set of links that allow users to switch between different categories of information (such as general details, financial data, or retail customers) without leaving the franchisee's profile page.
1.4Business Value

This feature improves operational efficiency by centralizing customer data. By providing a clean, readable list of retail customers directly within the franchisee's profile, staff can quickly verify customer identities and contact information without needing to navigate to separate, disconnected reports. This ensures that franchisee management is streamlined and data-driven.
