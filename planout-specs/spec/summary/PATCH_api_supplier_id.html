1.  Logic
1.1Overview

This feature allows users to update the details of an existing supplier within the Lumi ERP system. It provides a secure way to modify contact information—such as the supplier's name, email, phone number, or internal supplier code—while ensuring that sensitive system-generated data remains protected and that updates are restricted to the user's own company records.

1.2Step-by-Step Flow
1.Identification: The system identifies the specific supplier to be updated using a unique ID provided in the request.
2.Authentication Check: The system verifies that the user is logged in and confirms that the supplier record belongs to their specific company.
3.Validation: The system checks the incoming data to ensure only allowed fields (like name or contact details) are being changed. If a user attempts to modify protected fields (such as the creation date or company ID), the request is rejected.
4.Conflict Check: If the user is updating the "supplier code," the system verifies that the new code is not already in use by another supplier within the same company.
5.Update: Once all checks pass, the system saves the changes to the database and returns the updated supplier profile.
1.3Key Concepts
–Editable Fields: Specific pieces of information, such as contact details and supplier codes, that a user is permitted to change.
–System-Managed Fields: Critical data points (like creation timestamps or internal IDs) that are automatically handled by the software and cannot be altered by users.
–Ownership Validation: A security measure that ensures users can only view or modify suppliers associated with their own company.
–Conflict Resolution: A safeguard that prevents duplicate supplier codes, ensuring each supplier remains uniquely identifiable within the company's records.
1.4Business Value

This feature streamlines supplier management by allowing for quick, self-service updates to contact information. By enforcing strict validation and ownership rules, it maintains data integrity and prevents accidental or unauthorized changes to critical system records. Additionally, the conflict check prevents operational errors that could arise from duplicate supplier identification codes.

2.  Data
2.1Overview

This feature allows users to update existing supplier information within the Lumi ERP system. It provides a secure way to modify contact details or other editable fields for a specific supplier while ensuring that data integrity is maintained and that users only modify records belonging to their own company.

2.2Step-by-Step Flow
1.Authentication Check: The system verifies that the user is logged in and authorized to perform the update.
2.Supplier Identification: The system locates the specific supplier record using the unique ID provided in the request.
3.Ownership Verification: The system confirms that the supplier record belongs to the same company as the user making the request. If the supplier cannot be found or belongs to a different company, the request is rejected.
4.Data Validation: The system checks the incoming update information. It ensures that any new "supplier code" provided is not already being used by another supplier within the same company.
5.Record Update: If all checks pass, the system updates the supplier’s information with the new details provided.
6.Confirmation: The system returns a success message confirming the update is complete.
2.3Key Concepts
–Supplier: A business entity or partner stored in the system that provides goods or services.
–Unique Identifier (ID): A specific, permanent reference code used to ensure the system is updating the correct supplier record.
–Supplier Code: A unique reference label for a supplier within a company; the system prevents two different suppliers from sharing the same code.
–Data Integrity: The process of ensuring that updates are valid, authorized, and do not create conflicts (like duplicate codes) within the database.
2.4Business Value
–Data Accuracy: Allows teams to keep supplier contact information and records up-to-date without needing to delete and recreate entries.
–Security and Privacy: Prevents unauthorized access by ensuring users can only view or modify suppliers associated with their specific company.
–Conflict Prevention: Automatically prevents errors by checking for duplicate supplier codes, ensuring that the company's internal filing system remains organized and reliable.
