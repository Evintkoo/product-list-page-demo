1.  Data
1.1Overview

This feature provides a structured way to retrieve and display a list of ecommerce sales within the Lumi ERP system. It allows users to search, filter, and view sales data specifically originating from online channels, ensuring that the information is organized, paginated, and easy to navigate.

1.2Step-by-Step Flow
1.Request Initiation: The system receives a request for a list of ecommerce sales, which may include specific search filters (such as customer name, store, or date range) and pagination settings.
2.Data Retrieval: The system queries the sales database, specifically isolating records marked as "ecommerce" and excluding any that have been voided.
3.Information Enrichment: During the search, the system links each sale to its corresponding store name to provide a complete view of the transaction.
4.Dynamic Filtering: The system applies the user's search criteria. Notably, if a user filters by "completed" status, the system automatically uses the completion date for the search; otherwise, it uses the creation date.
5.Formatting: The retrieved data is organized into a standardized format, ensuring fields like customer details, vehicle information, and transaction totals are clearly presented.
6.Response Delivery: The final list is returned to the user, accompanied by pagination details (total count, current page, and limit) to help manage large volumes of data.
1.3Key Concepts
–Pagination: A method of breaking a large list of records into smaller, manageable pages to improve system performance and user experience.
–Filtering: The ability to narrow down the list of sales based on specific criteria, such as date, store location, or customer name.
–Data Enrichment: The process of combining information from different sources (in this case, linking a sale to a store name) to provide a more meaningful report.
–Workflow State: The current status of a sale (e.g., pending, completed), which dictates how the system processes and displays the record.
1.4Business Value

This feature centralizes ecommerce sales data, allowing staff to efficiently track online orders. By providing robust filtering and pagination, it enables users to quickly locate specific transactions, monitor store performance, and manage customer inquiries without being overwhelmed by large datasets. This ensures that the sales team has accurate, real-time visibility into online revenue and order fulfillment status.
