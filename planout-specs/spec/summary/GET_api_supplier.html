1.  Logic
1.1Overview

This feature provides a secure way for users to retrieve a complete list of suppliers associated with their specific company. By using this tool, authorized users can view essential supplier details—such as names and contact information—directly within the Lumi ERP system. The system automatically ensures that users only see suppliers relevant to their own organization, maintaining data privacy and security.

1.2Step-by-Step Flow
1.Authentication Check: The system verifies the user's identity. If the user is not logged in or their session is invalid, the request is denied.
2.Data Retrieval: Once verified, the system identifies the user's company and automatically fetches all associated suppliers from the database.
3.Display: The system presents the list of suppliers, organized alphabetically by name, to the user. If no suppliers are found or a system error occurs, the user receives a clear notification regarding the status of their request.
1.3Key Concepts
–Authentication: A security step that confirms who is making the request to ensure only authorized personnel can access company data.
–Data Scoping: A privacy feature that automatically filters information so that users only see data belonging to their own company, preventing access to other organizations' records.
–Alphabetical Sorting: The list is automatically arranged from A to Z by supplier name to ensure the information is easy to read and navigate.
1.4Business Value
–Efficiency: Provides instant access to supplier contact information without requiring manual searches or external reports.
–Security: Ensures that sensitive supplier data is protected by strictly limiting access to authenticated users and restricting visibility to their own company’s records.
–Consistency: By standardizing how supplier information is retrieved and displayed, the system ensures that all team members are working with the same accurate, up-to-date information.
2.  Data
2.1Overview

This feature provides a secure way for authorized users to retrieve a list of suppliers associated with their company. The system automatically identifies which company the user belongs to, ensuring they only see relevant supplier data, which is presented in alphabetical order by name.

2.2Step-by-Step Flow
1.Authentication Check: The system verifies that the user is logged in and authorized to access the data. If the user is not authenticated, the request is rejected.
2.Company Identification: The system identifies the user's company automatically based on their account credentials.
3.Data Retrieval: The system searches the database for all suppliers linked to that specific company.
4.Sorting: The retrieved list is organized alphabetically by the supplier's name.
5.Delivery: The final list is returned to the user. If the list cannot be found or an unexpected system error occurs, the user receives an appropriate error notification.
2.3Key Concepts
–Authentication: The process of verifying the user's identity to ensure they have permission to view company-specific information.
–Data Scoping: A security measure that automatically filters information so that users only see data belonging to their own organization, preventing unauthorized access to other companies' records.
–Alphabetical Ordering: A standard display format where the supplier list is automatically sorted from A to Z by name for easier navigation.
2.4Business Value
–Security and Privacy: By automatically scoping data to the user's company, we ensure that sensitive supplier information remains private and is only accessible to the correct personnel.
–Efficiency: Users do not need to manually search or filter for their company's suppliers; the system handles this automatically, providing a clean, ready-to-use list.
–Consistency: Standardizing the list order (alphabetical) ensures a predictable and professional user experience across the platform.
