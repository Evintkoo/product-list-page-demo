1.  Data
1.1Overview

The "Create Customer" feature allows the system to register a new customer record along with their associated addresses in a single, unified action. This process is designed to be "atomic," meaning that the customer and their addresses are saved together as one complete unit. If any part of the process fails, the system ensures that no partial or incomplete data is saved, keeping your database clean and reliable.

1.2Step-by-Step Flow
1.Receive Request: The system accepts a request containing the customer's core details (such as name, store, and company) and an optional list of addresses.
2.Categorize Customer: The system automatically identifies the customer type (Retail, Wholesale, Franchise, or Consignment) and sets the appropriate internal flags to ensure they are categorized correctly in the system.
3.Create Customer Record: A new customer profile is created in the database. The system automatically assigns a unique ID, sets the status to "active," and records the user who created the entry.
4.Add Addresses: If addresses are provided, the system links each one to the newly created customer.
5.Set Primary Address: If one of the provided addresses is marked as the "main address," the system automatically updates the customer's main profile record with that specific address information.
6.Finalize: Once all steps are successfully completed, the system confirms the creation and returns the full customer record.
1.3Key Concepts
–Atomic Transaction: A safety feature that ensures all parts of the creation process (customer profile + addresses) succeed together. If one part fails, the entire operation is canceled to prevent data errors.
–Discriminator Flags: Internal settings that classify a customer (e.g., Wholesale vs. Retail) based on the type provided, allowing the system to apply the correct business rules to that customer.
–Main Address: A specific designation for an address that the system uses to populate the primary contact location on the main customer profile.
1.4Business Value
–Data Integrity: By using an atomic process, you avoid "orphan" records where a customer might be created without their necessary address information, or vice versa.
–Efficiency: Users can input a customer and all their relevant locations in one go, reducing the time spent on manual data entry.
–Consistency: Automated categorization and address handling ensure that customer data is standardized across the entire ERP, making reporting and operations more reliable.
