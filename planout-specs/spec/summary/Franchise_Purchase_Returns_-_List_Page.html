1.  Frontend
1.1Overview

The Franchise Purchase Returns list page provides a centralized dashboard for users to view, search, and manage all returns related to franchise purchases. This page acts as a hub where staff can monitor the status of returns, quickly locate specific documents, and initiate the creation of new return requests.

1.2Step-by-Step Flow
1.Accessing the Page: Users navigate to the page via the Inventory menu.
2.Filtering Results: Users can narrow down the list of returns using search criteria such as the Return Number, Order Number, Store, Supplier, Warehouse, Status, or specific date ranges.
3.Applying Filters: After entering search criteria, the user clicks the "Search" button to refresh the list with relevant data.
4.Viewing Data: The system displays a table containing key details for each return, including dates, associated stores/suppliers, and the current workflow status.
5.Navigating Details: Users can click on a specific "Return No" or "Order No" to jump directly to the detailed view of that specific document.
6.Pagination: If there are many returns, users can move through the list page-by-page using the pagination controls at the bottom.
7.Creating New Returns: Users can click the "New Franchise Purchase Return" button to open a menu of options for starting a new return process.
1.3Key Concepts
–Workflow Status: A visual indicator (badge) that shows the current stage of a return (e.g., Draft, Sent, or Approved), helping users track progress at a glance.
–Pagination: A tool that breaks the list into smaller, manageable pages to ensure the system remains fast and easy to read.
–Source Order Reference: A link between the return and the original purchase order, allowing users to trace a return back to its origin.
–Filters: Search tools that allow users to isolate specific records based on business-relevant data like dates or locations.
1.4Business Value

This feature streamlines inventory management by providing a single, organized view of all franchise returns. By enabling quick searching and direct navigation to order details, it reduces the time staff spend manually tracking down return documentation. The clear status tracking ensures that teams can easily identify which returns are pending action, improving overall operational efficiency and accountability in the supply chain.

2.  Logic
2.1Overview

The Franchise Purchase Returns list page provides a centralized view for users to browse, search, and manage returns made by franchises. This feature ensures that users can easily locate specific return records using filters and navigate through large volumes of data using pagination, all while maintaining secure access to the system.

2.2Step-by-Step Flow
1.Authentication Check: When the page loads, the system verifies that the user is logged in. If the user is not authenticated, they are automatically redirected to the login page.
2.Data Retrieval: Once authenticated, the system collects the current search filters (such as reference codes or status) and the requested page number. It then requests the relevant list of purchase returns from the database.
3.Data Formatting: The system receives the raw return data and translates it into a user-friendly table format.
4.Display: The formatted information—including return numbers, dates, store locations, and current status—is displayed in the table for the user to review.
5.Interaction: If the user updates a filter or clicks to a different page, the system repeats the data retrieval and formatting steps to refresh the table with the new results.
2.3Key Concepts
–Authentication: A security check that ensures only logged-in users can view sensitive inventory return data.
–Filters: Search tools that allow users to narrow down the list by specific criteria, such as a return reference code or the current workflow status.
–Pagination: A navigation feature that breaks the list into smaller, manageable pages to improve performance and readability.
–Workflow State: The current status of a return (e.g., pending, approved, or sent), which helps users track the progress of each transaction.
2.4Business Value

This feature improves operational efficiency by allowing staff to quickly audit and manage franchise returns. By providing a searchable, paginated list, users can spend less time hunting for specific records and more time processing inventory adjustments. The inclusion of clear status tracking and user attribution ensures accountability and transparency across the franchise supply chain.

3.  Data
3.1Overview

The Franchise Purchase Returns list page provides a centralized dashboard for your team to view and manage all items returned by franchises. This feature allows users to quickly locate specific returns, monitor their progress through the approval workflow, and see key details such as which store initiated the return, the associated supplier, and the current status of the request.

3.2Step-by-Step Flow
1.Access the List: When you open the Franchise Purchase Returns page, the system automatically displays a list of all returns, sorted by the most recently created items first.
2.Apply Filters: You can narrow down the list by entering a specific return reference code, selecting a particular workflow status (e.g., pending or approved), or choosing a specific date range.
3.System Processing: The system processes your filters and retrieves the relevant records from the database.
4.Pagination: To keep the page easy to navigate, the system displays the results in manageable chunks, allowing you to browse through large volumes of data without performance issues.
5.View Details: The final list presents clear, readable information for each return, including the Return and Order numbers, dates of creation and approval, the store and supplier involved, and the current user responsible for the record.
3.3Key Concepts
–Workflow State: The current stage of the return process, indicating whether a return is in progress, awaiting approval, or finalized.
–Reference Code: A unique identifier assigned to each return, used to easily track and cross-reference specific transactions.
–Pagination: A method of breaking down a long list of records into smaller, separate pages to ensure the screen remains organized and fast to load.
–Filtering: The ability to narrow down the displayed list based on specific criteria, such as dates or status, to find exactly what you need.
3.4Business Value

This feature improves operational efficiency by providing a clear, searchable overview of all franchise returns. By enabling staff to quickly filter and locate specific return records, the system reduces the time spent on administrative tasks and helps ensure that returns are processed and approved in a timely manner. This transparency helps maintain accurate inventory records and strengthens the relationship between the franchise stores and the central warehouse.
