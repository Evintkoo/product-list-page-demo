1.  Frontend
1.1Overview

The Suppliers Sub Menu is a navigation component designed to help users manage supplier-related tasks within the Lumi ERP system. It provides a clear, organized way to switch between viewing the existing list of suppliers and initiating the creation of a new supplier record. By default, the system directs users to the main supplier list, ensuring a consistent starting point for daily operations.

1.2Step-by-Step Flow
1.Initial Load: When the user accesses the Suppliers module, the system automatically selects the "Suppliers" view as the default, displaying the list of existing suppliers.
2.Navigation Selection: The user interacts with the accordion-style menu to choose between "Suppliers" (the list view) or "New Supplier" (the creation form).
3.State Update: Upon clicking an option, the system highlights the selected item to provide visual feedback on the user's current location.
4.Page Transition: The system updates the main content area to show the requested page (either the list or the creation form).
5.Alternative Access: Users can also trigger the creation of a new supplier directly via a dedicated "New Supplier" button, which bypasses the menu to take them straight to the entry form.
1.3Key Concepts
–Accordion Menu: A compact navigation style that organizes links into a collapsible list, keeping the interface clean.
–Active State: A visual indicator (highlighting) that shows the user which section of the module they are currently viewing.
–Default View: The pre-selected page that appears automatically when the module is first opened, reducing the number of clicks required to start work.
–Navigation Routing: The underlying mechanism that ensures the correct page content is displayed based on the user's selection.
1.4Business Value
–Improved Efficiency: By providing a dedicated sub-menu, users can quickly toggle between viewing data and performing data entry without navigating back to the main dashboard.
–Enhanced Usability: The clear visual feedback (active state) and intuitive navigation structure reduce user error and help staff find the information they need faster.
–Streamlined Workflow: Standardizing the entry point to the "Suppliers List" ensures that users always begin their tasks from a consistent, familiar screen.
