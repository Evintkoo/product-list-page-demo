1.  Data
1.1Overview

The User Schema feature establishes the foundation for how the Lumi ERP system manages user identities, authentication, and security. It defines the structure for storing user profiles, tracking active login sessions, monitoring login attempts for security, and maintaining an audit trail of important actions. This ensures that user data is handled consistently, securely, and in compliance with modern authentication standards.

1.2Step-by-Step Flow
1.User Identification: When a user attempts to log in, the system retrieves their profile using their email address to verify their credentials.
2.Security Monitoring: Every login attempt is recorded, regardless of whether it succeeds or fails. This allows the system to track patterns, such as multiple failed attempts, to prevent unauthorized access.
3.Session Management: Upon a successful login, the system creates a secure session. This session is validated on every subsequent request to ensure the user is still active and their access has not expired.
4.Audit Logging: Significant security events—such as logging in, changing a password, or updating a user role—are recorded in an immutable audit log to provide a clear history of system activity.
5.User Retrieval: Authorized users can view lists of system users, filtered by criteria like name, role, or account status, to help administrators manage the user base effectively.
1.3Key Concepts
–User Profile: The core record containing essential information like name, email, role, and account status (e.g., whether the account is active or requires a password change).
–Session: A temporary, secure link between the user and the system that tracks how long they remain logged in before needing to re-authenticate.
–Login Attempt Tracking: A security mechanism that logs sign-in activity to help the system identify and block suspicious behavior or brute-force attacks.
–Audit Log: A permanent, unchangeable record of security-sensitive actions, providing transparency and accountability for administrative and user-driven changes.
–Role-Based Access: A system that assigns specific roles (such as Admin or Staff) to users to control what they can see and do within the ERP.
1.4Business Value
–Enhanced Security: By tracking login attempts and maintaining detailed audit logs, the system proactively protects against unauthorized access and provides a clear trail for security investigations.
–Operational Efficiency: Administrators can easily search, filter, and manage user accounts, reducing the time spent on routine user administration tasks.
–Reliable Access Control: The robust session management ensures that users are only granted access when their credentials are valid and their accounts are active, maintaining the integrity of the ERP system.
–Compliance Readiness: The built-in audit trail supports organizational requirements for tracking sensitive changes, which is critical for internal oversight and regulatory compliance.
