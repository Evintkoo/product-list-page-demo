1.  Frontend
1.1Overview

The "Add Vehicle" feature allows users to register a new vehicle to a specific customer profile within the Lumi ERP system. This feature provides a structured form to capture essential vehicle details—such as make, model, year, and service history—ensuring that all necessary information is accurately recorded and linked to the correct customer account.

1.2Step-by-Step Flow
1.Initialization: When the page loads, the system automatically retrieves a list of available vehicle makes and models to populate the selection menus.
2.Data Entry: The user fills out the form with vehicle details. The system identifies the customer by reading the ID from the current web address.
3.Dynamic Selection: The user selects a "Vehicle Type" (Car, Motorcycle, or Heavy Equipment). If "Heavy Equipment" is selected, additional specialized fields appear to capture specific machinery data.
4.Validation: The system ensures that mandatory fields (such as Make, Model, Year, and Odometer) are completed before allowing the user to proceed.
5.Submission: Upon clicking "Save," the system sends the collected information to the database.
6.Completion: If the save is successful, the user is automatically redirected to the customer’s vehicle list. If an error occurs, an alert notifies the user.
1.3Key Concepts
–Vehicle Metadata: The background data (makes and models) that ensures users can only select valid, pre-defined options for their vehicle.
–Conditional Fields: Form sections that only appear based on the user's previous choices (e.g., showing extra fields only for "Heavy Equipment").
–Required vs. Optional Fields: A distinction between data that must be provided to create a record (like the Year or Odometer) and supplementary information that can be added later (like Notes or Color).
–Customer Association: The process of linking a vehicle to a specific customer using a hidden identifier, ensuring the vehicle is correctly filed under the right account.
1.4Business Value

This feature streamlines the customer management process by centralizing vehicle data entry. By enforcing standardized inputs and mandatory fields, it reduces data entry errors and ensures that service teams have consistent, reliable information for every vehicle. This ultimately improves operational efficiency and supports better maintenance tracking for the customer.

2.  Logic
2.1Overview

The "Add Vehicle" feature allows users to register a new vehicle to a specific customer profile within the Lumi ERP system. This feature provides a structured form to capture comprehensive vehicle details—ranging from basic identification like the VIN and registration number to maintenance-related information like service dates and engine specifications.

2.2Step-by-Step Flow
1.Initialization: When the "Add Vehicle" page loads, the system automatically retrieves the latest list of vehicle makes and models to populate the selection menus, ensuring users can only choose from valid, pre-defined options.
2.Data Entry: The user fills out the form with the vehicle's details, including identification (VIN, registration), technical specifications (engine capacity, transmission), and maintenance history (last/next service dates).
3.Submission: Upon clicking the "Save" button, the system validates the information and sends it to the database to create the new record.
4.Confirmation & Navigation: If the save is successful, the system automatically redirects the user to the customer’s "Vehicles" tab to view the updated list. If an error occurs during submission, the system displays an alert message to inform the user.
2.3Key Concepts
–Metadata: The background data (such as lists of makes and models) that ensures the form is accurate and easy to use.
–Validation: The process of checking that the information entered into the form meets the system's requirements before it is saved.
–Record Creation: The action of permanently adding the new vehicle details to the customer's profile in the ERP.
–Redirect: The automatic movement of the user to a different page (the customer's vehicle list) once a task is successfully completed.
2.4Business Value
–Data Accuracy: By using standardized dropdowns for vehicle makes and models, the system prevents manual entry errors and ensures consistent data across the platform.
–Operational Efficiency: Centralizing vehicle information—including service history and technical specs—allows staff to manage customer assets more effectively and reduces the time spent searching for vehicle details.
–Improved User Experience: The seamless transition from adding a vehicle back to the customer's profile ensures a smooth workflow, allowing users to immediately verify that the new record was created correctly.
3.  Data
3.1Overview

The "Add Vehicle" feature allows you to register a new vehicle within the Lumi ERP system and associate it directly with a specific customer. This functionality captures comprehensive details about the vehicle—ranging from basic identification like the registration number and VIN to maintenance-related information like service history—ensuring that all relevant data is stored in one centralized location for easy management.

3.2Step-by-Step Flow
1.Customer Verification: The system first checks to ensure the customer you are assigning the vehicle to exists in our records. If the customer cannot be found, the process will not proceed.
2.Data Collection: The system gathers all provided vehicle details, including identification numbers (VIN, registration, engine number), physical characteristics (make, model, color, year), and operational status (odometer reading, service dates, and active status).
3.Record Creation: The system generates a unique digital identifier for the new vehicle record.
4.Data Storage: All collected information is securely saved into the system database, linking the vehicle to the selected customer.
5.Confirmation: Once saved, the system confirms the successful creation of the vehicle record.
3.3Key Concepts
–Customer Association: Every vehicle must be linked to a valid customer profile to ensure accurate billing, service tracking, and ownership records.
–Unique Identification: The system requires specific identifiers, such as the registration number and VIN, to prevent duplicate entries and ensure each vehicle is uniquely tracked.
–Maintenance Tracking: The feature includes fields for service dates and odometer readings, which help the system keep track of the vehicle's health and upcoming maintenance needs.
–Active Status: A toggle that allows you to mark a vehicle as "active" or "inactive," helping you manage your fleet or customer assets effectively without deleting historical data.
3.4Business Value
–Centralized Data Management: By keeping all vehicle information within the ERP, your team has a "single source of truth," reducing the need for manual spreadsheets or disconnected records.
–Improved Service Planning: Capturing "last service" and "next service" dates enables proactive customer communication, allowing you to reach out for maintenance appointments at the right time.
–Operational Accuracy: Validating customer IDs and requiring unique identifiers like VINs minimizes data entry errors and ensures that service history is always attributed to the correct vehicle and owner.
–Enhanced Customer Insights: Having a detailed history of a customer's vehicle fleet allows for better-informed sales and service recommendations.
