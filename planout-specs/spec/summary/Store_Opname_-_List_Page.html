1.  Frontend
1.1Overview

The Stock Opname List page is a centralized dashboard within the Inventory module that allows users to view, search, and manage stock-taking records. It provides a clear overview of all stock-taking activities across different stores, enabling users to track the progress of inventory audits from initial draft to final completion.

1.2Step-by-Step Flow
1.Initial Load: When the user navigates to the page, the system automatically fetches the most recent stock-taking records to display in the table.
2.Filtering: Users can narrow down the list by entering a specific document number, selecting a date range, choosing a specific store, or filtering by the current status (e.g., Draft, Completed, Approved, or Cancelled).
3.Search: After setting the desired filters, the user clicks the "Search" button to refresh the table with the relevant results.
4.Sorting: Users can click on column headers (such as Date, Store, or Status) to sort the list in ascending or descending order to better organize the data.
5.Navigation:
–Users can click on a specific Document Number to view the full details of that particular stock-taking record.
–Users can click the "New Stock Opname" button to be redirected to a page where they can create a new inventory audit.
6.Pagination: If there are many records, the system breaks them into pages. Users can navigate through these pages to view older or additional records without cluttering the screen.
1.3Key Concepts
–Stock Opname: The formal process of counting and verifying physical inventory against system records.
–Workflow Status: The current stage of an inventory record, which helps track progress (e.g., a "Draft" is still in progress, while "Completed" or "Approved" indicates the audit is finished).
–Filter Controls: Tools that allow users to isolate specific data based on criteria like time, location, or status.
–Pagination: A navigation feature that splits large lists into smaller, manageable pages to improve performance and readability.
–Sorting: The ability to reorder the list by clicking column headers, making it easier to find the most recent or relevant entries.
1.4Business Value

This feature improves inventory accuracy and operational transparency by providing a single source of truth for all stock-taking activities. By allowing staff to quickly filter and locate specific audit records, the system reduces the time spent on administrative tasks and helps managers monitor the status of inventory audits across multiple store locations in real-time.

2.  Logic
2.1Overview

The Stock Opname List page is a centralized dashboard within the Lumi ERP system designed to help users manage and track inventory stock-taking activities. This feature allows users to view, search, and filter a list of stock opname records, providing clear visibility into the status and history of inventory audits across different store locations.

2.2Step-by-Step Flow
1.Initial Load: When the user navigates to the Stock Opname page, the system automatically triggers a request to fetch the latest inventory audit records.
2.Applying Filters: Users can narrow down the list by entering specific criteria, such as a reference number, a date range, a specific store location, or the current status of the audit (e.g., draft, approved, or completed).
3.Data Retrieval: Upon clicking the "Search" button, the system queries the database, joins the relevant store information, and retrieves the matching records.
4.Displaying Results: The system presents the data in a clear table format, showing key details like the document number, date, store name, current status, and the user who last updated the record.
5.Pagination: If there are many records, the system breaks them into pages. Users can navigate through these pages to view additional results without losing their current search filters.
2.3Key Concepts
–Stock Opname: The formal process of counting and verifying physical inventory against system records.
–Reference Number: A unique identifier assigned to each stock-taking document for easy tracking and retrieval.
–Workflow State: The current stage of the audit process, which helps users identify if a record is still in progress (Draft) or finalized (Completed).
–Filtering: The ability to refine the list of records based on specific parameters, ensuring users only see the information relevant to their current task.
–Pagination: A navigation method that displays a limited number of records per page to keep the interface clean and improve system performance.
2.4Business Value
–Improved Operational Efficiency: By providing a searchable and filterable list, staff can quickly locate specific audit documents, saving time during busy inventory cycles.
–Enhanced Transparency: The inclusion of "Status" and "Updated By" fields ensures accountability and provides clear insight into the progress of inventory audits across the organization.
–Better Decision Making: With easy access to historical audit data and current statuses, managers can better monitor store performance and identify discrepancies in inventory management more effectively.
3.  Data
3.1Overview

The Stock Opname List page is a centralized dashboard within the Lumi ERP system designed to help warehouse managers track and manage inventory audit processes. This feature allows users to view all existing stock-taking records, search for specific audits by their reference number or current status, and see which warehouse each audit is associated with.

3.2Step-by-Step Flow
1.Initiate Search: The user enters a search term (such as a reference number or a status like "Pending" or "Completed") into the search bar and clicks the Search button.
2.Filter and Retrieve: The system processes the request by scanning the inventory audit records to find matches based on the provided search term.
3.Data Consolidation: The system gathers the relevant audit details, including the specific warehouse name linked to each record.
4.Display Results: The system presents the filtered list to the user, sorted by the most recently created audits first, along with a total count of the records found.
3.3Key Concepts
–Stock Opname: A formal inventory audit process used to verify that the physical stock in the warehouse matches the records in the system.
–Reference Number: A unique identifier assigned to each specific stock-taking session, making it easy to track and locate individual audit records.
–Status: The current stage of an audit (e.g., scheduled, in-progress, or finalized), which helps users understand the progress of their inventory checks.
–Warehouse Context: The specific location or facility where the stock-taking activity is taking place, ensuring clarity when managing multiple storage sites.
3.4Business Value

This feature improves operational efficiency by providing a clear, searchable overview of all inventory audit activities. By allowing users to quickly filter by status or reference number, warehouse managers can spend less time searching for information and more time addressing inventory discrepancies. Sorting by the most recent records ensures that the team is always focused on the most current and relevant audit tasks.
