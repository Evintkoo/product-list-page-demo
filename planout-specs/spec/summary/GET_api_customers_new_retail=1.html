1.  Logic
1.1Overview

This feature provides the necessary data to populate the "New Retail Customer" and "Edit Retail Customer" forms within the Lumi ERP system. When a user opens one of these pages, the system automatically retrieves all the lists required for dropdown menus (such as store locations, occupations, and tax settings) and identifies the standard default tax rate to ensure the form is ready for immediate use.

1.2Step-by-Step Flow
1.Security Check: The system verifies that the user is currently logged in. If the user is not authenticated, the request is denied.
2.Data Retrieval: The system gathers all the necessary information to populate the form’s dropdown menus, including available store locations, customer occupations, customer groups, and tax options.
3.Default Selection: The system identifies the specific tax configuration that should be pre-selected by default for new retail customers.
4.Form Preparation: The system bundles all the gathered lists and the default tax setting into a single package and sends it to the web page so the form can be displayed correctly.
5.Error Handling: If any part of this process fails, the system logs the issue and notifies the user that an error occurred.
1.3Key Concepts
–Dropdown Options: The pre-defined lists (like stores or occupations) that allow users to select values from a menu rather than typing them manually, ensuring data consistency.
–Default Values: Pre-filled information that appears automatically on a form to save the user time and reduce manual data entry.
–Authentication: The security process that ensures only authorized users can access or modify customer records.
–Retail Context: A specific configuration setting that ensures the form displays only the options and rules relevant to retail customers, keeping the interface clean and relevant.
1.4Business Value

This feature streamlines the customer onboarding and management process by automating the setup of retail forms. By providing pre-populated dropdowns and automatic defaults, it reduces the time staff spend on manual data entry, minimizes the risk of human error, and ensures that every new retail customer is categorized and taxed correctly from the moment they are added to the system.

2.  Data
2.1Overview

This feature provides the necessary data to populate the "New Retail Customer" and "Edit Retail Customer" forms in the Lumi ERP system. When a user opens one of these pages, the system automatically fetches the required default settings and the complete lists of options for all dropdown menus, ensuring the form is ready for immediate use.

2.2Step-by-Step Flow
1.Authentication Check: The system verifies that the user is currently logged in. If not, the request is denied.
2.Data Retrieval: The system gathers all necessary information from the database, including available stores, sales staff, occupations, wholesale customer associations, customer groups, and tax options.
3.Setting Defaults: The system automatically selects the user's current store as the default location and identifies the primary "Always Use" tax rate to pre-fill the form.
4.Response Construction: The system packages the default values and the full lists of dropdown options into a single response, which is then sent to the user's browser.
5.Error Handling: If any part of the process fails unexpectedly, the system returns a standard error message to prevent the application from crashing.
2.3Key Concepts
–Default Values: Pre-selected information (such as the user's store or standard tax rate) that saves the user time by reducing manual data entry.
–Dropdown Options: The complete lists of choices (e.g., list of salespersons or customer groups) that the system fetches to ensure the user always sees the most up-to-date information.
–Contextual Scoping: The system ensures that all data retrieved is relevant specifically to the user's company, preventing cross-contamination of data between different business entities.
2.4Business Value

This feature streamlines the customer onboarding process by automating form preparation. By pre-filling common fields and providing accurate, real-time dropdown options, it reduces manual effort for staff, minimizes data entry errors, and ensures that new retail customers are categorized and taxed correctly from the moment they are added to the system.
