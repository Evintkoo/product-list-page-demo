1.  Frontend
1.1Overview

The Sales Company Sub Menu is a navigation component designed to help users quickly access key areas of the Sales module within the ERP system. It provides a centralized, easy-to-use list of links that allows staff to jump directly to essential sales-related tasks without navigating through complex menus.

1.2Step-by-Step Flow
1.The user views the Sales Company Sub Menu, which displays three primary options: Sales Orders, Sales Order Returns, and Sales Deliveries.
2.When the user clicks "Sales Orders," the system immediately redirects them to the Sales Order list page.
3.When the user clicks "Sales Order Returns," the system redirects them to the list of processed returns.
4.When the user clicks "Sales Deliveries," the system redirects them to the list of outgoing sales deliveries.
1.3Key Concepts
–Navigation Menu: A dedicated sidebar or header section that acts as a shortcut hub for specific functional areas.
–Redirect: The automatic action of moving the user from their current screen to a new page based on their selection.
–Interaction States: Visual cues (such as highlighting when hovering or selecting) that confirm to the user that a menu item is clickable and active.
1.4Business Value

This feature improves operational efficiency by reducing the number of clicks required to perform daily sales tasks. By providing a clear, consistent navigation path, users can switch between managing orders, returns, and deliveries more fluidly, which minimizes time spent searching for screens and helps maintain focus on core sales activities.
