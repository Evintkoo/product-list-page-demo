1.  Logic
1.1Overview

The "Approve Stock Outgoing" feature is the final step in the inventory removal process. It transitions a "confirmed" stock outgoing document into an "approved" state. This action serves as the official trigger to permanently deduct items from your inventory and automatically generate the necessary financial accounting records (journal entries) to reflect the value of the goods removed.

1.2Step-by-Step Flow
1.Verification: The system checks that the document exists and is currently in a "confirmed" status. If the document has already been approved or is not yet confirmed, the request is rejected to prevent duplicate processing.
2.Data Preparation: The system verifies that every line item in the outgoing request includes a designated reversal account code.
3.Inventory & Financial Processing: In a single, unified action, the system performs the following:

* Calculates the current average cost for each product.

* Deducts the items from the physical inventory.

* Creates a financial journal entry that debits the appropriate expense accounts and credits the inventory clearing account.

4.Finalization: The document is marked as "approved," the current date is recorded, the generated journal ID is linked to the document, and any provided notes are saved.
1.3Key Concepts
–Stock Outgoing: A document representing a planned removal of items from inventory.
–Journal Entry: An automated accounting record that balances the books by debiting the specific expense account for the items removed and crediting the inventory value account.
–Atomicity: A safety feature ensuring that the inventory deduction and the financial journal posting happen together; if one part fails, the entire process is cancelled to prevent data mismatches.
–Reversal Account: A specific accounting code required to correctly categorize the financial impact of the stock removal.
1.4Business Value

This feature ensures accuracy and consistency between your physical warehouse stock and your financial records. By automating the journal entry creation at the moment of approval, it eliminates manual data entry errors and provides real-time visibility into inventory costs. Because the process is "atomic," you are guaranteed that your inventory levels will never be out of sync with your financial ledger.

2.  Data
2.1Overview

This feature provides a way to finalize a "Stock Outgoing" document in the Lumi ERP system. When a user approves a stock outgoing, the system performs a series of automated checks and updates to ensure that inventory levels are accurate and that the financial impact of the stock movement is correctly recorded in the company's journals. This process is designed to be "all-or-nothing," meaning if any part of the approval fails, the entire process is canceled to prevent data inconsistencies.

2.2Step-by-Step Flow
1.Validation: The system checks if the document exists, is currently in a "Confirmed" state, and has not already been approved.
2.Inventory Check: The system verifies that there is enough stock available for every item listed in the outgoing request. It also ensures that every line item has the required accounting information (reversal accounts) attached.
3.Cost Calculation: The system updates each line item with the most current average cost to ensure financial accuracy.
4.Journal Posting: A new financial journal is created. For every item, the system records a debit to the specific account associated with that item and a corresponding credit to the general income account.
5.Finalization: The document status is updated to "Approved," the approval timestamp is recorded, and the stock is officially marked as moved out of inventory.
2.3Key Concepts
–Transaction: A safety mechanism that ensures all steps (updating stock, creating journal entries, and finalizing the document) happen together. If one step fails, the system rolls back to the original state to prevent errors.
–Stock Outgoing: A document representing items leaving the inventory, which must be approved before it is considered final.
–Journal Entry: A record of the financial movement caused by the stock outgoing, ensuring that the inventory reduction is reflected in the company's accounting books.
–Average Cost: The current valuation of the inventory items, used to calculate the financial value of the stock being removed.
2.4Business Value

This feature automates the transition from a "confirmed" request to a "finalized" inventory movement. By integrating stock verification with automatic journal posting, it eliminates manual data entry errors and ensures that the company's financial records are always in sync with physical inventory levels. This provides management with real-time visibility into both stock availability and the financial impact of outgoing goods.
