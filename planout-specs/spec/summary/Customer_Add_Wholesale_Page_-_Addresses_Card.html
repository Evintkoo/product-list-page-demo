1.1Overview

The "Addresses Card" is a component within the wholesale customer profile page that allows users to manage multiple contact and location details. It provides a clean, organized table to view all saved addresses and a dedicated interface to add new ones, ensuring that customer contact information is accurate and easily accessible.

1.2Step-by-Step Flow
1.View Addresses: When a user visits the wholesale customer page, they see an "Addresses" section containing a table. If no addresses have been added yet, the table displays a message indicating that it is currently empty.
2.Initiate Addition: To add a new location, the user clicks the "Add Address" button.
3.Enter Details: A pop-up window (modal) appears, allowing the user to input the address type, primary and secondary phone numbers, fax number, and specify if the location serves as the "Main" or "Shipping" address.
4.Validation: As the user types, the system checks the information in real-time. For example, it ensures the primary phone number meets the minimum length requirement.
5.Save and Update: Once the user saves the information, the pop-up closes, and the new address immediately appears as a new row in the main table on the customer page.
1.3Key Concepts
–Addresses Table: A structured list that displays all saved locations, including contact numbers and specific designations like "Main" or "Shipping."
–Address Modal: A focused input form that appears over the main page, keeping the user's workflow contained and preventing navigation away from the customer profile.
–Real-time Validation: A feature that checks data quality (such as phone number length) while the user is typing, providing immediate feedback to prevent errors before the information is saved.
–Address Designation: Simple checkboxes that allow users to quickly flag an address for specific business purposes, such as identifying it as the primary contact point or the default shipping destination.
1.4Business Value
–Data Accuracy: By using real-time validation, the system prevents incomplete or incorrectly formatted contact information from entering the database.
–Operational Efficiency: Staff can quickly manage multiple customer locations in one place without needing to navigate to different screens or complex menus.
–Improved Customer Service: Having clear, categorized address information (Main vs. Shipping) ensures that orders and communications are directed to the correct locations, reducing shipping errors and communication delays.
