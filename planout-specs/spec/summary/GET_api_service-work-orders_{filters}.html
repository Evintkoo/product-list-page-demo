1.  Logic
1.1Overview

This feature provides a search tool for the "Work Order Picker" used within the New Stock Outgoing form. It allows users to quickly find specific service work orders by typing a reference code. To ensure data security and performance, the search is restricted to the specific store location selected by the user and requires a minimum of three characters to initiate a search.

1.2Step-by-Step Flow
1.Validation: The system checks that both the store location and a search term (at least three characters long) have been provided. If these are missing or too short, the request is rejected.
2.Authorization: The system verifies that the user has the necessary permissions to access work orders for the specific store requested.
3.Query Execution: The system searches the database for work orders that match the provided reference code within the user's company and the selected store. It retrieves a limited list of results (defaulting to 20 items).
4.Response: The system returns the matching work orders, including their unique ID, reference code, and current status, allowing the picker to display the information to the user.
1.3Key Concepts
–Reference Code: The unique identifier or document number used to track a specific service work order.
–Store Scoping: A security and organizational measure that ensures users only see work orders associated with the specific store they are currently working in.
–Pagination: A method of breaking large lists of data into smaller, manageable chunks (using "limit" and "offset") to keep the application fast and responsive.
–Status (aasm_state): The current lifecycle stage of a work order (e.g., pending, completed, or cancelled). This information is provided so the system can eventually determine if a work order is eligible to be picked.
1.4Business Value

This feature streamlines the inventory process by enabling staff to accurately and quickly locate the correct service work order when preparing outgoing stock. By enforcing store-level access and requiring specific search criteria, it reduces manual errors, prevents unauthorized access to data, and ensures that the picker interface remains performant and easy to navigate.

2.  Data
2.1Overview

This feature provides a search tool for the "Service Work Order" picker used within the New Stock Outgoing form. It allows users to quickly find specific work orders by typing a reference code. To ensure data security and performance, the search is restricted to the user's company and a specific store location, and it only triggers once a meaningful search term (at least three characters) is provided.

2.2Step-by-Step Flow
1.Authentication: The system verifies the user's identity. If the user is not logged in, the request is rejected.
2.Parameter Validation: The system checks that a store ID is provided and that the search term (reference code) contains at least three characters. If these requirements aren't met, the request is rejected.
3.Authorization: The system confirms the user has permission to access the specific store requested. If not, the request is denied.
4.Data Retrieval: The system searches the database for work orders that match the provided reference code within the specified store and company.
5.Response: The system returns a list of matching work orders, including their unique ID, reference code, and current status, allowing the user to select the correct job.
2.3Key Concepts
–Reference Code: The unique identifier or document number used to track a specific service work order.
–Store Scoping: A security and organizational measure that ensures users only see work orders associated with the specific location they are currently working in.
–Status (AASM State): The current lifecycle stage of a work order (e.g., "completed"). This is included in the search results so the system can verify if a job is in a valid state to be picked.
–Search Threshold: A performance optimization that prevents the system from searching until the user has typed at least three characters, avoiding unnecessary database load.
2.4Business Value

This feature streamlines the inventory process by enabling staff to quickly locate relevant service work orders directly within the "Stock Outgoing" workflow. By enforcing store-level and company-level security, it ensures that users only interact with data they are authorized to see, while the status-aware search helps prevent errors by ensuring only valid, pickable jobs are selected for outgoing stock.
