1.1Overview

The Wholesale Customer Edit page allows users to update existing customer information within the Lumi ERP system. This page provides a centralized interface to modify customer profiles, contact details, tax identification numbers, financial settings, and accounting preferences. Additionally, it includes a dedicated management section for handling multiple customer addresses.

1.2Step-by-Step Flow
1.Accessing the Page: The user navigates to the Wholesale Customer Edit page, where all existing customer data is automatically loaded and displayed in the relevant fields.
2.Updating General Information: The user can modify primary details such as the customer's name, contact information, bank details, and tax IDs (NPWP, NPPKP, NITKU).
3.Managing Addresses:

* To update an existing address, the user clicks the "Edit" icon in the address table to open the Address Modal.

* To add a new location, the user clicks the "Add Address" button.

* Within the Address Modal, the user selects location details (Country, Province, District, etc.) and enters contact numbers. The system validates phone numbers in real-time to ensure they only contain allowed characters.

* The user saves or cancels the address changes to return to the main edit page.

4.Configuring Financials & Accounting: The user can update credit terms, limits, currency, and specific accounting accounts (such as invoice or deposit accounts).
5.Finalizing Changes: Once all updates are complete, the user clicks "Save" to commit the changes to the system or "Cancel" to discard all modifications.
1.3Key Concepts
–Address Modal: A pop-up window used to manage specific location data, ensuring that address entry is structured and validated.
–Real-time Validation: A safety feature that checks phone number formats as the user types, preventing invalid data from being saved.
–Defaulting Logic: For certain financial and accounting fields, if the user leaves them blank, the system automatically applies pre-configured default settings (e.g., standard tax rates or default accounts).
–Data Mapping: The section of the page that links specific customer records to internal entities, such as the assigned Salesperson.
1.4Business Value
–Data Accuracy: By providing structured fields and real-time validation for contact information, the system reduces human error and ensures high-quality customer data.
–Operational Efficiency: The ability to manage multiple addresses and financial settings in one place streamlines the workflow for wholesale account managers.
–Flexibility: The system supports specific business requirements by allowing overrides for tax and accounting settings while providing sensible defaults to save time during data entry.
