1.  Frontend
1.1Overview

The "New Service Product Type" modal is a user-friendly pop-up window designed to help staff quickly categorize service offerings within the Lumi ERP system. By providing a dedicated space to define new service types, this feature ensures that users can maintain an organized service catalog without leaving their current workflow.

1.2Step-by-Step Flow
1.Open the Modal: The user initiates the process from the main service product page, triggering the "New Service Product Type" window.
2.Enter Details: The user provides a name for the new service type (which is mandatory) and an optional description to provide further context.
3.Real-time Validation: As the user types, the system checks that the name field is not left empty. If the name is missing, the system alerts the user immediately.
4.Submission: Once the required information is entered, the user clicks the "Save" button to finalize the creation of the new service type.
5.Completion or Cancellation: Upon a successful save, the modal closes automatically. Alternatively, the user can click "Cancel" or the "X" icon at any time to discard their changes and close the window without saving.
1.3Key Concepts
–Service Product Type: A classification label used to group similar services together, making it easier to manage and report on service offerings.
–Validation: An automated check that ensures essential information (the name) is provided before the system accepts the new entry.
–Modal: A focused window that appears on top of the main screen, allowing users to complete a specific task without navigating away from their current page.
–Active Status: By default, all new service types are set to "active," meaning they are immediately available for use in the system upon creation.
1.4Business Value

This feature streamlines the administrative process of managing service catalogs. By allowing users to create new categories on the fly, it reduces manual data entry friction and ensures that the service product list remains accurate and up-to-date. This consistency helps improve reporting accuracy and ensures that all services are properly categorized for better business insights.

2.  Logic
2.1Overview

The "New Service Product Type" modal is a streamlined tool designed to help users quickly define and categorize new service offerings within the Lumi ERP system. By providing a dedicated interface for this task, users can add new service types directly from the service product page without navigating away from their current workflow.

2.2Step-by-Step Flow
1.Input Entry: The user opens the modal and enters the required details, specifically the name of the service type, an optional description, and its active status.
2.Validation: Upon clicking "Save," the system checks to ensure the mandatory name field is filled out.
3.Submission: If the information is valid, the system securely sends the data to the database to create the new entry.
4.Confirmation: Once the system successfully saves the new service type, the modal automatically closes, and the application updates to reflect the new addition.
5.Error Handling: If the submission fails (e.g., due to missing information or a system error), the modal remains open and displays a clear message explaining what went wrong so the user can correct it.
2.3Key Concepts
–Service Product Type: A category or classification used to organize different types of services offered by the business.
–Modal: A pop-up window that allows users to perform a specific task (like creating a new item) without leaving the main page they are currently viewing.
–Validation: A safety check performed by the system to ensure that all required information is provided before attempting to save data.
–Active Status: A setting that determines whether a service type is currently available for use within the system.
2.4Business Value

This feature improves operational efficiency by reducing the time and effort required to manage service catalogs. By allowing users to create new service types on the fly, the system ensures that the ERP remains up-to-date with the latest service offerings, leading to more accurate reporting and smoother service management processes.
