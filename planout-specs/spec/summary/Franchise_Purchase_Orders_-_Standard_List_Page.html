1.  Frontend
1.1Overview

The "Franchise Purchase Orders - Standard List Page" provides a centralized view for managing standard external purchase orders within the Lumi ERP system. This page allows users to browse, search, and filter purchase orders, providing clear visibility into order status, financial amounts, and key dates. It is designed to help inventory managers efficiently track the lifecycle of standard franchise orders from creation to receipt.

1.2Step-by-Step Flow
1.Accessing the Page: Upon loading the page, the system automatically retrieves and displays the most recent standard purchase orders.
2.Filtering and Searching: Users can narrow down the list by entering a specific Document Number or by using various filters, such as date ranges, store, supplier, status, or source. Clicking the "Search" button updates the table to show only the matching records.
3.Browsing the List: The table displays key details for each order, including reference numbers, store and supplier names, order/receive amounts, and current workflow status.
4.Sorting: Users can click on column headers (such as Document Number, Created At, or Status) to sort the list in ascending or descending order to better organize their view.
5.Navigation: Users can move through the list using the pagination controls at the bottom of the page.
6.Viewing Details: Clicking on a specific Document Number link will take the user to a dedicated detail page for that specific purchase order.
7.Switching Views: Users can toggle between "Standard" and "Internal" purchase order lists using the navigation tabs at the top of the page.
1.3Key Concepts
–Standard Purchase Order: An external order placed with a supplier, distinct from internal warehouse transfers.
–Filter Bar: A set of search and selection tools that allow users to find specific orders based on criteria like date, store, or supplier.
–Workflow Status: A visual indicator (badge) that shows the current stage of an order (e.g., "Ordered") and highlights if an order has been only partially received.
–Pagination: A navigation feature that breaks the list into manageable pages, ensuring the system remains fast and easy to read.
–Sorting: The ability to reorder the list by clicking column headers, making it easier to find the oldest, newest, or most urgent orders.
1.4Business Value

This feature streamlines inventory management by providing a single, organized source of truth for all standard franchise purchase orders. By enabling quick searching and filtering, it reduces the time staff spend looking for order information. Furthermore, the clear display of order amounts and status updates helps teams maintain better financial oversight and ensures that store supply needs are tracked accurately and transparently.

2.  Logic
2.1Overview

The Franchise Purchase Order Standard List Page provides a centralized view for users to browse and manage standard purchase orders. This feature allows users to efficiently locate specific orders using search and pagination tools, ensuring that all relevant information—such as order status, supplier details, and financial amounts—is clearly visible in a structured table format.

2.2Step-by-Step Flow
1.Request Data: When you open the page or apply a search filter, the system requests a list of purchase orders specifically categorized as "standard" orders.
2.Pagination: The system retrieves the data in manageable chunks (pages) to ensure the list remains easy to navigate.
3.Data Processing: The system takes the raw order information and organizes it into a clean, readable table format.
4.Formatting: Dates are converted into a standard readable format, and financial figures are displayed as currency.
5.Status Mapping: Internal system status codes (like "placed") are translated into user-friendly labels (like "Ordered") to make the current state of an order immediately clear.
6.Display: The final table is rendered, showing key details such as the document number, supplier, store, and current order status.
2.3Key Concepts
–Standard Purchase Orders: A specific category of orders (external standard) that this page is dedicated to tracking.
–Document Number: A unique identifier for each order that acts as a clickable link, allowing you to navigate directly to the full details of that specific purchase order.
–Status Badge: A visual indicator that shows the current progress of an order (e.g., "Ordered"). If an order has been partially received, a distinct badge will highlight this status.
–Pagination: A navigation feature that breaks the list of orders into smaller pages, preventing the need to scroll through an excessively long list.
–Search: A tool that allows you to quickly filter the list to find specific orders by entering keywords.
2.4Business Value

This feature streamlines inventory management by providing a dedicated, high-visibility workspace for standard franchise orders. By offering clear status tracking, easy searchability, and direct links to order details, it reduces the time spent searching for information and helps staff quickly identify which orders are pending, completed, or partially received. This improves operational efficiency and ensures better oversight of the procurement process.

3.  Data
3.1Overview

The Franchise Purchase Order List Page provides a centralized view for managing standard purchase orders within the Lumi ERP system. This feature allows users to browse, search, and filter through all standard franchise orders, ensuring that store managers and procurement teams have clear visibility into the status, financial details, and timelines of their orders.

3.2Step-by-Step Flow
1.Data Retrieval: The system fetches the complete list of franchise purchase orders from the database.
2.Filtering: The system automatically filters the list to display only "Standard" purchase orders, ensuring the view remains focused on the relevant order type.
3.Data Mapping: Each order is processed to translate raw system data into a user-friendly format, including formatting dates, currency values, and status labels.
4.Display: The processed data is presented in a table format, where each row represents a single purchase order.
5.Interaction: Users can click on the Document Number to navigate to the specific details of any order, or use search and filter tools to narrow down the list as needed.
3.3Key Concepts
–Standard Purchase Order: A specific category of order used for external procurement, which is the primary focus of this list view.
–Status Badge: A visual indicator (such as "Ordered") that provides an immediate update on the current stage of the purchase order.
–Partial Receipt: A status indicator used when an order has been delivered in multiple shipments, helping users track incomplete deliveries.
–Currency Formatting: Financial figures (Order Amount and Receive Amount) are automatically formatted to ensure they are easy to read and compare.
–Document Number: A unique identifier for each order that serves as a direct link to the full order details.
3.4Business Value
–Improved Efficiency: By providing a dedicated list page for standard orders, users can quickly locate specific documents without navigating through unrelated order types.
–Enhanced Visibility: Clear status badges and receipt tracking (including partial shipments) allow teams to proactively manage inventory and address potential supply delays.
–Data Accuracy: Automated formatting of currency and dates reduces manual interpretation errors, ensuring that financial reporting and order tracking remain consistent across the organization.
