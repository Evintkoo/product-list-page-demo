1.1Overview

The New Address Modal is a user-friendly interface designed to help staff easily add new location details to a customer's profile within the Lumi ERP system. This pop-up window provides a structured form to capture essential contact and location information, ensuring that address data is consistent and accurate across the platform.

1.2Step-by-Step Flow
1.Open the Modal: The user initiates the process, opening the "Address" modal.
2.Enter Basic Details: The user provides the address type (e.g., home, office) and geographic details like country and province.
3.Select Location Hierarchy: The user selects the specific regency, district, village, and postal code from provided dropdown menus to ensure precise location mapping.
4.Provide Street Address: The user enters the full street address in a dedicated multi-line text area.
5.Add Coordinates: The user inputs the latitude and longitude for precise digital mapping.
6.Enter Contact Information: The user provides primary and secondary phone numbers, as well as a fax number. The system automatically validates the phone numbers to ensure they follow the correct format.
7.Finalize: The user clicks "Save" to submit the data and close the modal, or clicks "Cancel" (or the "X" icon) to discard the entry and close the window without saving.
1.3Key Concepts
–Form Validation: An automated check that ensures phone numbers are entered in a valid format before the system allows the information to be saved.
–Modal: A pop-up window that allows users to complete a specific task (like adding an address) without leaving their current page.
–Hierarchical Dropdowns: A series of selection menus (Regency, District, Village, Postal Code) that guide the user to select accurate location data step-by-step.
–Data Persistence: The process of saving the entered information into the customer's profile so it is available for future use.
1.4Business Value
–Data Accuracy: By using dropdowns for location details and format validation for phone numbers, the system reduces human error and ensures high-quality, standardized address data.
–Operational Efficiency: The intuitive, guided form allows staff to quickly update customer profiles, reducing the time spent on manual data entry.
–Improved Customer Service: Maintaining precise location and contact information enables better logistics, accurate shipping, and reliable communication with customers.
