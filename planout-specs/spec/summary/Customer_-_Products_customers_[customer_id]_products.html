1.  Frontend
1.1Overview

The "Customer Products" feature provides a dedicated view within the Lumi ERP system to manage and view products associated with a specific customer. This page allows users to see a detailed list of products, apply customer-specific pricing or naming overrides, and perform administrative tasks like searching, filtering, and exporting data.

1.2Step-by-Step Flow
1.Page Initialization: When a user navigates to the customer products page, the system automatically loads the specific customer's details to display their name in the page banner.
2.Filtering: The user uses the "Search and Filter" bar to narrow down the product list. The system requires selections for Membership, Vehicle, and Source before the search can be executed.
3.Data Retrieval: Once the search criteria are met and the button is clicked, the system fetches the relevant product list from the database based on the selected filters.
4.Table Display: The product list is rendered in a table, showing key details such as the standard SKU, product name, customer-specific aliases (name and SKU), and the specific discount percentage applied to that customer.
5.Interaction: Users can interact with the table by clicking on a SKU to view full product details, or by using the toolbar to add new products or export the current list to an Excel file.
6.Management: For individual items in the list, users have the option to edit or delete specific product associations as needed.
1.3Key Concepts
–Alias Name/SKU: Customer-specific overrides that replace the standard product name or SKU on official documents like invoices, ensuring the customer sees terminology they recognize.
–Customer Discount (%): A specialized pricing rule that applies only to the selected customer, overriding standard catalog pricing.
–Search Filter Bar: A validation-controlled tool that ensures all required criteria (Membership, Vehicle, Source) are selected before the system performs a data lookup.
–Row Selector: A checkbox feature that allows users to select one or more products to perform bulk actions, such as removing multiple items at once.
1.4Business Value

This feature streamlines account management by providing a clear, centralized view of customer-specific product catalogs. By allowing for "Alias" names and SKUs, the system reduces confusion for the customer during the invoicing process. Furthermore, the ability to apply unique discount percentages directly within this view ensures accurate pricing and simplifies the management of complex wholesale or franchisee agreements.
