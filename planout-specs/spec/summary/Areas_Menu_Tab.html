1.  Frontend
1.1Overview

The Areas Menu Tab is a navigation component designed to help users easily move between different administrative levels within the Lumi ERP system. It acts as a central control bar on the Areas page, allowing users to quickly switch their view between Provinces, Regencies/Municipalities, Districts, and Villages.

1.2Step-by-Step Flow
1.The user accesses the Areas page, where the menu tab is displayed.
2.The user selects one of the four available administrative categories: Province, Regency/Municipality, District, or Village.
3.Upon clicking the desired category, the system immediately redirects the user to the corresponding list page for that specific administrative level.
1.3Key Concepts
–Administrative Levels: The hierarchical structure of geographic or political regions (Province, Regency/Municipality, District, and Village) managed within the ERP.
–Navigation Menu: A persistent interface element that allows users to jump between related sections of the application without needing to return to a main dashboard.
–Context Switching: The ability for a user to change their current focus area (e.g., moving from viewing a list of Provinces to a list of Districts) with a single click.
1.4Business Value

This feature improves user efficiency by providing a clear, consistent, and accessible way to navigate complex geographic data. By grouping these administrative levels into a single menu, we reduce the number of clicks required to perform tasks, minimize navigation errors, and ensure that users can quickly find the specific administrative data they need to manage.
