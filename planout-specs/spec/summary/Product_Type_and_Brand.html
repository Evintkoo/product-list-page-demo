1.  Frontend
1.1Overview

This feature introduces a dynamic selection tool within the Lumi ERP voucher configuration. It allows users to precisely target vouchers by specifying a particular product category and brand. To keep the interface clean and intuitive, these options only appear when the user explicitly chooses to apply a voucher based on product type and brand.

1.2Step-by-Step Flow
1.Triggering the Fields: The user selects "By Product Type and Brand" from the main Product Condition dropdown.
2.Displaying Options: Once the condition is selected, the system automatically reveals the "Product Type" and "Product Brand" dropdown menus.
3.Making Selections: The user chooses the desired product type and brand from the available lists.
4.Real-time Validation: As the user makes their selections, the system immediately checks that both fields are filled. If a field is left blank, an error message appears to prompt the user to complete the information.
1.3Key Concepts
–Conditional Visibility: A design approach where specific input fields are hidden by default and only appear when they are relevant to the user's current task.
–Immediate Validation: A feedback mechanism that alerts the user to missing information as soon as they interact with the form, rather than waiting until they try to save the entire voucher.
–Voucher Targeting: The process of defining specific criteria (in this case, type and brand) to ensure a voucher is only applied to the intended products.
1.4Business Value

This feature enhances the precision of your promotional and discount strategies. By allowing users to restrict vouchers to specific product types and brands, the business can run more targeted marketing campaigns, manage inventory promotions more effectively, and reduce the risk of vouchers being applied to unintended items. The real-time validation ensures that all voucher configurations are complete and accurate before they are finalized, preventing errors in the sales process.
