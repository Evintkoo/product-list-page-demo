1.  Frontend
1.1Overview

The Payment Type Mapping feature provides a centralized dashboard within the Lumi ERP system to manage how different payment methods (such as Cash, Credit, or QRIS) are assigned to specific store locations. This tool allows finance administrators to view, filter, and maintain the status of these payment configurations to ensure accurate financial reporting and operational consistency across all store branches.

1.2Step-by-Step Flow
1.Initial Loading: When you open the page, the system automatically retrieves the full list of existing payment mappings, along with the complete lists of available stores and payment types to populate your filter options.
2.Filtering: You can narrow down the list of mappings by selecting a specific store, a particular payment method, or by filtering for only "Active" or "Inactive" configurations.
3.Applying Filters: Once you have selected your criteria, clicking the "Show" button updates the table to display only the records that match your search.
4.Reviewing Data: The table displays the results in a clear list, showing the store name, the associated payment type, and a visual indicator (a green checkmark) if the mapping is currently active.
5.Editing: Each row includes an "Edit" button, allowing you to quickly access and modify the details of a specific payment mapping.
1.3Key Concepts
–Payment Type Mapping: The association between a specific store and a payment method, defining which payment options are valid for that location.
–Filter Bar: A set of dropdown menus that allow you to search for specific mappings based on store, payment type, or status without having to scroll through the entire list.
–Active Status: A toggle-like indicator that shows whether a payment method is currently enabled for use at a specific store.
–Pagination: A feature that organizes large lists of data into manageable pages, ensuring the interface remains clean and easy to navigate.
1.4Business Value

This feature streamlines financial setup by providing a single source of truth for payment configurations. By allowing users to easily filter and verify which payment methods are active at which stores, the system reduces the risk of configuration errors, simplifies the onboarding of new payment methods, and ensures that store-level financial data remains accurate and consistent across the organization.

2.  Logic
2.1Overview

The Payment Type Mapping feature allows users to manage and view how specific payment methods are assigned to different store locations within the Lumi ERP system. This feature provides a centralized interface to see which payment types are active for each store, ensuring that financial transactions are correctly categorized and controlled across the organization.

2.2Step-by-Step Flow
1.Initial Page Load: When the user opens the page, the system automatically retrieves the full list of existing payment mappings and populates the "Store" and "Payment Type" dropdown menus with available options.
2.Data Display: The system presents the mapping data in a clear table format, showing the store name, the associated payment type, and whether that specific configuration is currently active.
3.Applying Filters: Users can narrow down the list by selecting specific stores, payment types, or active statuses from the dropdown menus.
4.Dynamic Updates: As soon as a filter is applied, the system instantly refreshes the table to display only the records that match the user's selected criteria.
2.3Key Concepts
–Payment Type Mapping: The relationship between a specific store location and a payment method (e.g., Credit Card, Cash, or Digital Wallet) that is permitted for use at that location.
–Filtering: A tool that allows users to search or sort through large lists of data by selecting specific categories, such as viewing only "Active" payment types for a single "Store."
–Dropdown Options: Pre-defined lists of stores and payment types that ensure data consistency and make it easier for users to select valid criteria without manual entry.
2.4Business Value

This feature streamlines financial setup by providing a clear, searchable view of payment configurations. By allowing users to easily filter and verify which payment methods are active at which stores, the business can reduce configuration errors, ensure compliance with store-specific payment policies, and simplify the administrative overhead of managing multi-store financial operations.

3.  Data
3.1Overview

The Payment Type Mapping feature allows the Lumi ERP system to organize and manage how different payment methods are associated with specific store locations. This tool provides a centralized view to track, enable, or disable these payment configurations, ensuring that the system correctly recognizes and processes payments based on the rules defined for each store.

3.2Step-by-Step Flow
1.Data Retrieval: The system gathers all existing payment mapping rules and organizes them alphabetically by store name and payment type, making it easy for you to find specific records.
2.Information Display: These records are presented in a clear list view, showing which payment types are currently active for each store.
3.Status Management: If a payment method needs to be updated—such as toggling its active status or changing its details—you can modify the record directly.
4.System Synchronization: When updates are made, the system automatically records the time of the change, ensuring your audit trail is always up to date.
5.Data Translation: The system automatically translates incoming payment data from external sources into the internal format, ensuring that store names and payment types are correctly categorized without manual intervention.
3.3Key Concepts
–Payment Type Mapping: A rule that links a specific payment method (like credit card or cash) to a particular store location.
–Active Status: A toggle that determines whether a specific payment method is currently available or "live" for a store.
–Data Transformation: The automated process of converting external information into the system's standard format to ensure consistency across all records.
3.4Business Value

This feature simplifies financial administration by providing a single source of truth for payment configurations. By automating the mapping of payment types to stores, it reduces the risk of manual entry errors, ensures that financial reporting is accurate, and allows managers to quickly enable or disable payment methods across different locations as business needs change.
