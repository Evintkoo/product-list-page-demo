1.  Frontend
1.1Overview

The Supplier Details Page provides a centralized, read-only view of all information related to a specific supplier within the Lumi ERP system. This page allows users to quickly review contact information, credit terms, operational settings, pricing, and historical audit logs for a selected supplier. It also includes navigation tools to return to the main supplier list or transition to an edit mode if updates are required.

1.2Step-by-Step Flow
1.Loading Data: When a user selects a supplier, the system retrieves all relevant records from the database. A loading indicator is shown while this data is being fetched.
2.Header Display: The page displays the supplier's name at the top, along with a "Back" button to return to the supplier list and an "Edit" button to modify the record.
3.Navigation: A tabbed menu allows the user to switch between the current "Suppliers" view, "Products," and "History."
4.Information Sections: The page organizes data into logical groups:

* Details: Contact information, identification codes, and address.

* Credit Terms: Financial limits and payment conditions.

* Settings: Operational flags (e.g., active status, internal supplier status) and tax settings.

* Prices: The specific price list assigned to the supplier.

* Notes: Bank account details and any additional free-text notes.

* Changes: An audit trail showing when the record was created or updated and by whom.

5.Error Handling: If the system cannot find the requested supplier, a "Supplier not found" message is displayed.
1.3Key Concepts
–Supplier Record: The complete profile of a business partner, containing all necessary data for procurement and accounting.
–Audit Trail: A record of "Changes" (created/updated timestamps and user names) that ensures accountability and transparency for data modifications.
–Operational Flags: Settings that define how the system interacts with the supplier, such as whether they are currently active or if they are permitted to use store purchase orders.
–Read-Only View: The primary state of the page, designed for safe data review without the risk of accidental changes.
1.4Business Value

This feature improves operational efficiency by providing procurement and finance teams with a "single source of truth" for supplier data. By consolidating contact, financial, and audit information into one organized view, users can make faster, more informed decisions regarding purchasing and vendor management without needing to navigate through multiple screens or external documents.

2.  Logic
2.1Overview

The Supplier Details Page is a secure view within the Lumi ERP system that provides a comprehensive summary of a specific supplier's information. When a user navigates to this page, the system automatically verifies their identity and retrieves the relevant supplier data to display in an organized, easy-to-read format.

2.2Step-by-Step Flow
1.Authentication Check: Upon loading the page, the system verifies that the user is currently logged in. If the user is not authenticated, they are automatically redirected to the Login Page.
2.Data Retrieval: Once authenticated, the system requests the specific details for the supplier identified in the web address.
3.Error Handling: If the requested supplier cannot be found in the system, the page will display a "not found" state to inform the user.
4.Information Mapping: If the data is successfully retrieved, the system organizes the information into specific sections on the page, such as contact details, credit terms, administrative notes, and account settings.
2.3Key Concepts
–Authentication: A security check that ensures only logged-in users can view sensitive supplier information.
–Data Mapping: The process of taking raw information from the system database and placing it into the correct, labeled sections on the user interface.
–Supplier Record: The complete profile of a supplier, including contact info, financial terms (like credit limits), and internal administrative notes.
–Not Found State: A user-friendly message displayed when a user attempts to access a supplier record that does not exist or has been removed.
2.4Business Value

This feature ensures that staff members have quick, reliable access to critical supplier information—such as payment terms, contact details, and account status—in one centralized location. By automating the retrieval and organization of this data, the system reduces manual lookup time and ensures that users are always viewing the most up-to-date information, which supports better decision-making and more efficient supplier management.

3.  Data
3.1Overview

The Supplier Details Page is a centralized dashboard within the Lumi ERP system designed to provide a comprehensive view of a specific supplier's profile. This page aggregates all relevant information—ranging from contact details and financial terms to internal settings and administrative history—into a single, organized interface, allowing users to quickly access and verify supplier data.

3.2Step-by-Step Flow
1.Request Initiation: When a user selects a specific supplier, the system retrieves the complete profile information for that supplier from the database.
2.Data Organization: The system processes the raw supplier data and categorizes it into logical groups to ensure the information is easy to read.
3.Display Generation: The organized data is presented on the Supplier Details Page, structured into the following sections:

* Header: Displays the primary name of the supplier.

* Details Section: Shows contact information, including email, phone number, and physical address.

* Credit Terms Section: Outlines the financial agreements, such as credit limits and payment terms.

* Changes Section: Provides an audit trail showing when the record was created or updated, and by whom.

* Note Section: Displays internal bank account details and any additional notes regarding the supplier.

* Settings Section: Shows operational flags, such as whether the supplier is active, if they are an internal partner, and if they are authorized for store purchase orders, along with tax information.

* Prices Section: Identifies the specific price list assigned to the supplier.

3.3Key Concepts
–Supplier Profile: A complete digital record containing all contact, financial, and operational information for a business partner.
–Audit Trail: A record of administrative changes that tracks when information was last modified and which user performed the update.
–Operational Flags: Status indicators that determine how the system interacts with a supplier, such as whether they are currently active or permitted to receive purchase orders.
–Financial Terms: The agreed-upon credit limits and payment schedules that govern the business relationship with the supplier.
3.4Business Value

This feature improves operational efficiency by eliminating the need to search through multiple screens or documents to find supplier information. By providing a structured, "single source of truth" for each supplier, the page helps staff make faster, more informed decisions regarding procurement, payments, and account management. Additionally, the inclusion of an audit trail and clear operational settings ensures better data accuracy and accountability across the organization.
