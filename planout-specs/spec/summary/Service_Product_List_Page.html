1.  Frontend
1.1Overview

The Service Product List Page is a centralized dashboard within the Lumi ERP system designed to help users manage their service-based offerings. This page provides a clear, organized view of all services, allowing users to quickly search, filter by status (Active or Inactive), and navigate to specific service details or create new entries.

1.2Step-by-Step Flow
1.Page Initialization: When the page loads, the system automatically retrieves the list of active service products and displays them in a structured table.
2.Navigation: Users can orient themselves using the main menu (set to "Products") and the sub-menu (set to "Product").
3.Filtering: Users can toggle between "Active" and "Inactive" tabs to view different subsets of services.
4.Searching: A search bar allows users to type keywords to instantly narrow down the list of services displayed in the table.
5.Viewing Details: Users can click on the blue SKU or Name of any service in the table to be redirected to that specific service's detail page.
6.Adding New Services: A dedicated button at the top right allows users to navigate to a form to create a new service product.
7.Pagination: If the list of services is long, users can use the pagination controls at the bottom to browse through multiple pages of results.
1.3Key Concepts
–Service Product: A specific type of offering in the ERP system that represents a service rather than a physical good.
–Status Filter: A toggle mechanism that allows users to view only currently "Active" services or review previously "Inactive" ones.
–Search Filter: A real-time search tool that updates the table results as the user types, making it easier to find specific items.
–Pagination: A navigation feature that breaks large lists into smaller, manageable pages to improve performance and readability.
–SKU: A unique identifier for each service product, used here as a primary link to access detailed information.
1.4Business Value

This feature streamlines the management of service offerings by providing a single, efficient interface. By enabling quick searching and status-based filtering, staff can spend less time looking for information and more time managing their service catalog. The ability to easily jump to detailed records or create new services ensures that the product database remains accurate and up-to-date, directly supporting smooth operational workflows.

2.  Logic
2.1Overview

The Service Product List Page is a centralized hub within the Lumi ERP system designed to help users efficiently manage and browse service-based offerings. This feature provides a clear, organized view of all services, allowing users to quickly locate specific items using search tools and status-based filtering.

2.2Step-by-Step Flow
1.Initial Load: When the page opens, the system automatically retrieves all "Active" service products to display in the main table.
2.Status Filtering: Users can toggle between "Active" and "Inactive" tabs. Selecting a tab updates the list to show only the services relevant to that lifecycle state.
3.Keyword Search: Users can enter text into the search bar to find specific services. The system scans the service name, unique identification code (SKU), and description to return matching results.
4.Data Presentation: The system compiles the relevant service details—including the service type, category tag, estimated duration, and pricing—and presents them in a clean, readable table format for the user.
2.3Key Concepts
–Service Product: A non-physical offering (such as a consultation or maintenance task) managed within the ERP system.
–Status Filter: A toggle mechanism that separates services based on their current operational state (Active vs. Inactive), helping to reduce clutter.
–Search Logic: A flexible search tool that looks across multiple fields (name, SKU, and description) simultaneously to ensure users find what they need regardless of how they search.
–Service Details: The specific attributes displayed for each item, such as the time required to perform the service and the price before tax.
2.4Business Value

This feature streamlines administrative workflows by providing a single source of truth for all service offerings. By enabling quick searching and status-based filtering, staff can spend less time hunting for information and more time managing service delivery. This improves operational efficiency and ensures that pricing and service duration data remain easily accessible for accurate quoting and scheduling.

3.  Data
3.1Overview

The Service Product List Page is a centralized dashboard within the Lumi ERP system designed to help users efficiently browse, manage, and view details for all service-based offerings. This feature provides a structured table view that displays key information—such as pricing, tax details, and service duration—for every service product in the system.

3.2Step-by-Step Flow
1.Page Initialization: When a user navigates to the Service Product List page, the system automatically requests the first set of service products from the database.
2.Data Retrieval: The system fetches the list of services, organizing them alphabetically by name to ensure a consistent and predictable layout.
3.Pagination Handling: To keep the page performant and easy to read, the system displays a specific number of items at a time. Users can navigate through the full list using pagination controls (such as "Next," "Previous," and specific page numbers).
4.Data Display: The retrieved information is mapped into a clean, readable table format, showing details like the SKU, service name, description, pricing, and tax configurations.
5.User Interaction: As the user clicks through different pages, the system repeats the retrieval process to load the next set of records dynamically.
3.3Key Concepts
–Service Product: A specific type of offering in the ERP system that represents a service rather than a physical good, characterized by attributes like estimated time and specific tax accounts.
–Pagination: A method of dividing a large list of items into smaller, manageable pages to improve loading speed and user experience.
–SKU (Stock Keeping Unit): A unique identifier assigned to each service product to ensure accurate tracking and reporting.
–Open Price: A setting that indicates whether a service allows for flexible or variable pricing at the time of sale.
–Tax Configuration: Specific fields identifying which tax rules and accounting codes apply to a particular service.
3.4Business Value

This feature streamlines administrative tasks by providing a single source of truth for all service offerings. By organizing services into a searchable, paginated list, staff can quickly verify pricing, tax settings, and service durations without needing to open individual records. This improves operational efficiency, reduces manual lookup time, and ensures that service-related data remains consistent across the organization.
