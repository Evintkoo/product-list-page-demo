1.  Frontend
1.1Overview

The "Add Wholesale Customer" feature provides a dedicated interface for staff to register new wholesale clients into the Lumi ERP system. This page ensures that all necessary business information—such as contact details, tax identification, and credit settings—is captured accurately and consistently. The system is designed to streamline data entry by automatically loading default settings and providing organized sections for managing complex customer information.

1.2Step-by-Step Flow
1.Access & Authentication: When a user navigates to the page, the system verifies their login status. If the user is not logged in, they are automatically redirected to the login screen.
2.Initialization: Once authenticated, the system fetches default settings and dropdown options (such as customer groups, tax settings, and currency) to ensure the form is pre-filled with standard business values.
3.Data Entry: The user completes the customer profile across several organized sections:

* User Details: Basic identity and contact information.

* Tax Information: Required tax identification numbers.

* Customer Grouping: Categorizing the customer for reporting and pricing.

* Settings: Financial configurations like credit limits and payment terms.

* Addresses: Managing multiple shipping or billing locations via a dedicated pop-up window.

4.Validation & Saving: Upon clicking "Save," the system validates the entered information. If any required data is missing or incorrect, the system alerts the user.
5.Completion: Once successfully saved, the new customer is added to the system, and the user is returned to the main customer list.
1.3Key Concepts
–Default Settings: Pre-configured values that appear automatically when creating a new customer, reducing manual typing and ensuring consistency.
–Wholesale Type: A specific customer classification that triggers the system to load relevant wholesale-specific fields and business rules.
–Validation: A background check performed by the system to ensure that all mandatory fields are filled correctly before the data is permanently saved.
–Data Mapping: The process of linking the system's background data (like tax rates or account types) to the dropdown menus on the screen, ensuring the user always sees the most current options.
1.4Business Value
–Operational Efficiency: By pre-filling default values and organizing fields into logical cards, the system reduces the time and effort required to onboard new wholesale partners.
–Data Accuracy: Centralized validation prevents incomplete or invalid customer records from entering the database, which is critical for accurate financial reporting and tax compliance.
–Scalability: The structured approach to managing addresses and financial settings allows the business to handle complex wholesale relationships without increasing administrative overhead.
2.  Logic
2.1Overview

The "Add Wholesale Customer" feature provides a dedicated page for users to register new wholesale clients within the Lumi ERP system. The page is designed to be smart and efficient, automatically pre-filling standard settings and dropdown options to save time. It includes robust error handling to ensure that if any information is missing or incorrect, the user can easily fix it without losing the data they have already entered.

2.2Step-by-Step Flow
1.Authentication Check: When the page loads, the system verifies that the user is logged in. If the user is not authenticated, they are automatically redirected to the login screen.
2.Form Initialization: Once verified, the system fetches default settings and list options (such as currencies, tax rates, and sales groups) specifically tailored for wholesale customers to pre-populate the form.
3.Data Entry: The user fills out the customer’s details. If the customer has multiple locations, the user can use the "Add Address" button to open a pop-up window, add address details, and see them appear in a summary table.
4.Submission: When the user clicks "Save," the system bundles all the information—including the customer profile and the list of addresses—and sends it to the server.
5.Outcome:

* Success: If the data is valid, the system saves the new customer and redirects the user to the newly created customer's profile page.

* Error: If there is an issue (e.g., a missing required field), the system displays the specific errors while keeping all entered information on the screen so the user can make corrections and try again.

2.3Key Concepts
–Pre-population: The system automatically fills in common fields and dropdown menus based on wholesale-specific defaults, reducing manual data entry.
–Form Persistence: If a submission fails due to an error, the system retains the user's input, preventing the frustration of having to re-type information.
–Address Management: A dedicated table allows users to manage multiple addresses for a single customer, which are saved as part of the overall customer record.
–Wholesale Categorization: The system automatically tags these entries as "wholesale" to ensure they are processed correctly within the ERP.
2.4Business Value

This feature streamlines the onboarding process for new wholesale partners by automating repetitive data entry and providing a clear, guided interface. By ensuring that all necessary wholesale-specific settings are applied by default, the system reduces the likelihood of human error and ensures that customer data is consistent and ready for immediate use in sales and accounting workflows.

3.  Data
3.1Overview

The "Add Wholesale Customer" feature provides a dedicated interface for your team to onboard new wholesale partners into the Lumi ERP system. This feature ensures that all necessary business information—including contact details, tax identification, and physical addresses—is captured accurately and stored in a structured format, allowing for seamless management of wholesale accounts.

3.2Step-by-Step Flow
1.Data Entry: The user fills out the wholesale customer form, providing the customer's name, email, tax identification number, and one or more physical addresses.
2.Submission: Upon clicking "Save," the system gathers all entered information and automatically categorizes the entry as a "wholesale" customer.
3.Processing: The system sends this information to the database to create the new customer record.
4.Confirmation:
–If the information is valid and successfully saved, the system automatically redirects the user to the new customer's profile page.
–If an error occurs (such as a missing field or duplicate email), the system keeps the user on the form and retains all previously entered data, allowing the user to make corrections and try again without losing their work.
3.3Key Concepts
–Wholesale Customer: A specific category of client within the ERP that requires additional documentation, such as tax identification, for business-to-business transactions.
–Customer Record: The central profile that stores essential contact and identification information for a business partner.
–Address Management: The ability to associate multiple physical locations with a single customer record, ensuring accurate shipping and billing.
–Form Persistence: A safety feature that ensures data is not cleared if a submission fails, preventing the need for the user to re-type information.
3.4Business Value
–Operational Efficiency: By standardizing the intake process for wholesale customers, the team can onboard new partners faster and with fewer errors.
–Data Integrity: Categorizing customers as "wholesale" and requiring specific fields like tax IDs ensures that your financial and shipping data remains clean and compliant.
–Improved User Experience: The error-handling logic reduces frustration by allowing users to fix mistakes quickly without having to restart the data entry process.
