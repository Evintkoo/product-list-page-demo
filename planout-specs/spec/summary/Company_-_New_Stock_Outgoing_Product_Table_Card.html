1.  Frontend
1.1Overview

The "New Stock Outgoing Product Table" is the central component used to manage the list of products being removed from inventory. It provides a structured way for users to input product details, specify quantities, and assign expense accounts for each item. The table is designed to be user-friendly, offering both manual entry and bulk file upload capabilities, while ensuring data accuracy through automated calculations and validation checks.

1.2Step-by-Step Flow
1.Initiation: The user begins with an empty table and can either click "Add Product" to create a new row manually or use the "Upload Outgoing File" button to import multiple products at once.
2.Product Selection: When a product is selected via the search bar, the system automatically populates the "Stock Qty" (current availability) and "Average Cost" fields for reference.
3.Data Entry: The user enters the "Order Qty" (the amount to be removed) and selects the appropriate "Expense Account" from a dropdown menu.
4.Automatic Calculation: As the user enters the quantity, the system instantly calculates the "Amount" (Quantity × Average Cost) and updates the "Total" row at the bottom of the table.
5.Validation: Before saving the document, the system verifies that:

* At least one product line has been added.

* All required fields (Product, Quantity, Expense Account) are filled.

* The "Order Qty" does not exceed the available "Stock Qty."

1.3Key Concepts
–Computed Fields: Values like "Amount" and "Total" are automatically calculated by the system based on user input, reducing manual errors.
–Read-Only Data: Information such as "Stock Qty" and "Average Cost" is pulled directly from the system to guide the user, but cannot be manually edited.
–Bulk Upload: A feature that allows users to download a template, fill it out offline, and upload it to populate the table instantly.
–Validation Rules: Built-in safeguards that prevent the document from being saved if the data is incomplete or if the requested quantity exceeds current stock levels.
1.4Business Value
–Efficiency: The bulk upload feature and automatic calculations significantly reduce the time required to prepare stock outgoing documents.
–Accuracy: By displaying real-time stock availability and automating cost calculations, the system prevents common data entry mistakes.
–Compliance: The requirement to assign an "Expense Account" to every line ensures that inventory movements are correctly categorized for accounting and reporting purposes.
–Reliability: The validation logic ensures that inventory levels remain accurate by preventing the removal of more stock than is currently available.
