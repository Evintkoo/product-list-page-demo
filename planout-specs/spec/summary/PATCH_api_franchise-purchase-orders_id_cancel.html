1.  Logic
1.1Overview

This feature allows authorized users to cancel a franchise purchase order within the Lumi ERP system. By triggering this action, an order that is currently in the early stages of the procurement process can be officially marked as "cancelled," ensuring that inventory records accurately reflect the status of the request.

1.2Step-by-Step Flow
1.Validation: The system checks that the provided order ID is formatted correctly.
2.Authorization: The system verifies that the person making the request is logged in and holds an "admin" or "manager" role.
3.Retrieval: The system searches for the specific purchase order in the database.
4.Ownership Check: The system confirms that the order belongs to the user's company. If the order cannot be found or belongs to a different company, the request is denied.
5.Status Check: The system ensures the order is in a state that allows for cancellation (specifically, it must be in "draft" or "store_confirmed" status). If the order has already progressed further, the cancellation is blocked.
6.Finalization: If all checks pass, the system updates the order status to "cancelled," records the time of the update, and confirms the change.
1.3Key Concepts
–Franchise Purchase Order: A formal request for goods or services initiated by a franchise location.
–Workflow State: The current stage of an order (e.g., draft, confirmed, or cancelled). This ensures orders can only be modified when appropriate.
–Authorization: A security measure that restricts the ability to cancel orders to specific management roles to prevent unauthorized changes.
–Ownership Validation: A safeguard that ensures users can only interact with purchase orders associated with their own company.
1.4Business Value

This feature provides operational flexibility by allowing managers to correct mistakes or respond to changes in demand by cancelling orders that have not yet been fully processed. It maintains data integrity by preventing the cancellation of orders that are already too far along in the fulfillment cycle, while ensuring that only authorized personnel can modify financial or inventory-related documents.

2.  Data
2.1Overview

This feature allows authorized users to cancel a franchise purchase order within the Lumi ERP system. The system ensures that only orders in specific early stages (Draft or Store Confirmed) can be cancelled, preventing the cancellation of orders that have already progressed too far in the fulfillment process.

2.2Step-by-Step Flow
1.Verification: The system confirms the user has the necessary permissions and that the requested order exists and belongs to their company.
2.Status Check: The system checks the current status of the order.
3.Validation: If the order is in a "Draft" or "Store Confirmed" state, the system proceeds. If the order is in any other state, the cancellation is blocked.
4.Cancellation: The system updates the order status to "Cancelled" and records the time of the update.
2.3Key Concepts
–Workflow State: The current stage of an order in its lifecycle (e.g., Draft, Store Confirmed, or Cancelled).
–Transition Validation: A safety check that ensures an order only moves to a "Cancelled" state if it is logically appropriate to do so.
–Data Ownership: A security measure that ensures users can only view or modify orders associated with their specific company.
2.4Business Value
–Operational Control: Prevents accidental or unauthorized cancellation of orders that are already being processed or shipped.
–Data Integrity: Ensures that order statuses remain accurate and consistent throughout the procurement lifecycle.
–Security: Protects sensitive company data by enforcing strict access rules, ensuring users can only manage orders within their own organization.
