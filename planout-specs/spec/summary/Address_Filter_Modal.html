1.  Frontend
1.1Overview

The Address Filter Modal is a popup tool designed to help users quickly narrow down customer lists based on specific location details. By providing a centralized interface to input address-related criteria, users can efficiently find customers located in specific regions, cities, or neighborhoods without needing to search through the entire database manually.

1.2Step-by-Step Flow
1.Open the Modal: The user triggers the address filter popup from the main customer page.
2.Input Criteria: The user enters location details into the available fields, including Country (via dropdown), Province, Regency/Municipality, District, Village, Postal Code, and specific street address details.
3.Data Validation: As the user types, the system ensures the Postal Code field only accepts numeric characters to maintain data accuracy.
4.Refine or Reset:

* If the user wants to start over, they can click "Clear All" to instantly empty all fields.

* If the user decides not to filter, they can click "Close" to exit without saving changes.

5.Apply Filter: Once the desired criteria are entered, the user clicks "Apply." The system then uses these specific location values to filter the customer list and display the relevant results.
1.3Key Concepts
–Filter Criteria: The specific data points (such as country, province, or postal code) used to narrow down a large list of customers to a smaller, more relevant group.
–Data Validation: A built-in safety check that prevents users from entering incorrect information—specifically, ensuring the Postal Code field only contains numbers.
–Clear All: A convenience function that resets the form, allowing the user to quickly discard current filters and begin a new search.
–Apply: The action that confirms the user's selections and triggers the system to update the customer view based on the provided address parameters.
1.4Business Value

This feature significantly improves user productivity by reducing the time spent searching for specific customer records. By allowing for granular filtering—from broad country-level searches down to specific village or street addresses—the system enables staff to manage regional data more effectively, improve reporting accuracy, and streamline daily operations within the Lumi ERP platform.
