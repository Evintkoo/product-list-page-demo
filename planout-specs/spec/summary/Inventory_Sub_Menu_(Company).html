1.  Frontend
1.1Overview

The Inventory Sub-Menu is a navigation component designed for the company-level dashboard of the Lumi ERP system. It provides users with a quick and intuitive way to jump between key inventory management areas, ensuring that essential tasks like tracking orders and managing stock movements are easily accessible.

1.2Step-by-Step Flow
1.The user views the Inventory sub-menu within the company dashboard.
2.The system checks the user's permissions to determine which menu items should be visible.
3.The user selects one of the available options:

* Purchase Orders: Navigates the user to the list of standard purchase orders.

* Purchase Returns: Navigates the user to the list of company purchase returns.

* Stock Outgoings: Navigates the user to the list of stock outgoing records.

4.Upon clicking an item, the system immediately redirects the user to the corresponding page.
1.3Key Concepts
–Sub-Menu: A secondary navigation bar that helps organize specific tasks under a broader category (Inventory) to keep the interface clean.
–Permission-Based Access: A security feature that ensures users only see menu options for the specific modules they are authorized to use.
–Immediate Navigation: A design approach where clicking a menu item takes the user directly to their destination without requiring extra steps or form submissions.
1.4Business Value

This feature improves operational efficiency by centralizing inventory-related workflows. By providing a clear, permission-aware navigation path, it reduces the time users spend searching for specific inventory pages and ensures that sensitive or restricted modules remain hidden from unauthorized personnel, maintaining both productivity and system security.
