1.  Data
1.1Overview

The Franchise Purchase Order feature provides a structured way for franchise stores to manage their procurement process. It allows stores to create and track orders for products sourced from either external suppliers or the franchisor. The system handles both the high-level order information (the "header") and the specific product details (the "line items") separately, ensuring that the application remains responsive even when orders contain many items.

1.2Step-by-Step Flow
1.Order Creation & Management: A user initiates a purchase order, which is stored as a header record. This record tracks essential details like the store, supplier, order type, and the current workflow status (e.g., draft, sent, received).
2.Adding Items: Individual products are added to the order as line items. Each item tracks the quantity ordered, the price, and any applicable discounts.
3.Dynamic Calculations: The system does not store total order amounts in the database. Instead, it calculates subtotals, discounts, taxes, and final totals in real-time based on the current line items. This ensures that financial data is always accurate and reflects the most recent updates.
4.Retrieving Lists: When viewing a list of orders, the system provides a summary that includes calculated totals and status information, allowing users to filter by criteria such as store, supplier, or workflow state.
5.Viewing Details: When a user selects a specific order, the system fetches the header information and the associated line items. The line items are retrieved separately, allowing the system to handle large orders efficiently through pagination.
1.3Key Concepts
–Header Record: The main purchase order document that contains general information like the store, supplier, and overall status.
–Line Items: The individual product rows within an order, which track specific quantities, prices, and discounts for each item.
–Workflow State: The current stage of the order in the procurement lifecycle, such as "Draft," "Sent," or "Received."
–Real-time Calculation: The process of computing financial totals (like subtotal and tax) on-the-fly whenever an order is viewed, rather than saving these values permanently.
–Pagination: A method used to break large lists of orders or line items into smaller, manageable pages to improve system performance.
1.4Business Value
–Operational Efficiency: By separating the order header from the line items, the system remains fast and responsive, even for complex orders with many products.
–Data Accuracy: Because financial totals are calculated dynamically from the line items, the risk of discrepancies between the order summary and the individual items is eliminated.
–Flexibility: The system supports different procurement scenarios—such as internal orders from a warehouse or external orders from third-party suppliers—within a single, unified interface.
–Improved Visibility: With robust filtering and status tracking, franchise managers can easily monitor the progress of their orders from creation to final receipt.
