1.  Frontend
1.1Overview

The New Product Tag Modal is a user-friendly pop-up window designed to help staff quickly create and categorize products within the Lumi ERP system. This feature allows users to define a new tag name and an optional description directly from the product management screens, ensuring that product organization remains consistent and efficient without needing to navigate away from their current task.

1.2Step-by-Step Flow
1.Open the Modal: The user initiates the process from the product page, triggering the "New Product Tag" window.
2.Enter Details: The user provides a name for the tag (required) and an optional description.
3.Validation: As the user types, the system checks that the required "Name" field is filled. If the user attempts to save without a name, the system will highlight the error.
4.Save or Cancel:

* Save: The system verifies the input, creates the new tag in the database, and closes the window upon success.

* Cancel: The user can close the window at any time using the "Cancel" button or the close icon, which discards any unsaved information.

1.3Key Concepts
–Modal: A pop-up window that appears over the main screen, allowing users to complete a specific task without leaving their current page.
–Validation: An automated check that ensures essential information (like the tag name) is provided before the system accepts the data.
–Mutation: The background process that sends the new tag information to the system's database to be permanently stored.
1.4Business Value

This feature streamlines the product management workflow by reducing the number of clicks and page transitions required to organize inventory. By allowing users to create tags on the fly, the system promotes better data hygiene and more accurate product categorization, which ultimately leads to improved searchability and reporting capabilities within the ERP.

2.  Logic
2.1Overview

The New Product Tag Modal is a feature designed to streamline the product management process. It allows users to create new product tags directly from the "Add" or "Edit" product pages without needing to navigate away to a separate settings screen. This ensures that users can categorize their products efficiently while maintaining their current workflow.

2.2Step-by-Step Flow
1.Input Validation: When you click the "Save" button, the system first checks that a name has been entered for the tag. If the name field is empty, the system will display an error message and keep the modal open so you can correct it.
2.Submission: If the name is valid, the system sends the tag name and its optional description to the database to be created.
3.Success Handling: Once the tag is successfully created, the system automatically adds it to your existing list of tags, selects it for the product you are currently editing, and refreshes the list to ensure everything is up to date.
4.Closing: After the tag is successfully processed and selected, the modal closes automatically, returning you to the main product page.
5.Error Handling: If an unexpected issue occurs during the process, the system will display an error message to inform you that the action could not be completed.
2.3Key Concepts
–Product Tag: A label used to categorize products, making them easier to organize and search within the system.
–Validation: A safety check that ensures required information (like the tag name) is provided before the system attempts to save data.
–Modal: A pop-up window that allows you to perform a specific task (like creating a tag) without leaving the page you are currently working on.
–State Management: The system's ability to automatically update the background page (the tag list and selector) so that your new tag is immediately available for use without requiring a manual page refresh.
2.4Business Value

This feature improves user productivity by reducing the number of clicks and page transitions required to manage product metadata. By allowing users to create tags "in the moment," it minimizes workflow interruptions and ensures that product categorization remains consistent and up-to-date, ultimately leading to better-organized inventory data.
