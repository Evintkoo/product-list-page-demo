1.  Logic
1.1Overview

This feature allows users to modify existing "draft" stock outgoing records. It provides a flexible way to update the source location or adjust the list of items being sent out. The system automatically handles the addition, modification, or removal of individual items within the request and ensures that all changes are validated against current inventory levels before saving.

1.2Step-by-Step Flow
1.Verification: The system locates the requested stock outgoing record and confirms it is currently in "draft" status. If the record is already finalized, the update is rejected.
2.Header Update: If a new source location is provided, the system updates the record to reflect this change.
3.Item Processing: The system iterates through the list of items provided in the request:

* If an item is marked for removal, it is deleted from the record.

* If an item already exists, its details (such as product type or quantity) are updated.

* If an item is new, it is added to the record.

4.Validation: For every item, the system checks the current inventory at the selected source location. It confirms that the requested quantity is greater than zero and that sufficient stock is available.
5.Pricing: The system automatically calculates the unit cost for each item based on the current average cost found in the inventory.
6.Finalization: Once all items are validated and priced, the updated record is saved, and the system returns the complete, updated document.
1.3Key Concepts
–Draft Status: A protective state that ensures only records that have not yet been finalized can be modified.
–Stock Outgoing Lines: The individual items or products included in a specific outgoing shipment.
–Inventory Validation: A safety check performed during the update to ensure you cannot ship more items than are currently available in your warehouse.
–Automated Pricing: The system automatically pulls the most recent cost data for products, removing the need for manual entry and ensuring financial accuracy.
1.4Business Value

This feature streamlines inventory management by allowing users to correct or adjust outgoing shipments without having to delete and recreate them. By automating the validation of stock levels and the calculation of costs, the system reduces the risk of human error, prevents shipments that exceed available inventory, and ensures that financial records remain accurate and up-to-date.

2.  Data
2.1Overview

This feature provides a way to modify "Stock Outgoing" documents that are currently in a draft state. It allows users to update general information about the outgoing stock request and manage the list of items (products) included in that request. The system ensures data integrity by validating that the requested items are available in stock and automatically calculating the correct costs based on current inventory data.

2.2Step-by-Step Flow
1.Locate Document: The system searches for the specific draft document using the provided ID. If it cannot be found, the request is rejected.
2.Verify Status: The system checks if the document is still in "Draft" status. If it has already been processed or finalized, the update is blocked.
3.Apply Changes: The system processes the updates in a single batch:

* Updates the main document details (excluding the reference code).

* Adds new items, updates existing items, or removes items marked for deletion.

4.Validate and Price: The system performs a final check on all items:

* Confirms that all products exist and quantities are greater than zero.

* Verifies that the source location has enough stock to cover the requested quantities.

* Automatically updates the cost of each item based on the current average cost at the source location.

5.Finalize: If all checks pass, the changes are saved permanently, and the updated document is returned. If any check fails, the entire update is canceled to prevent errors.
2.3Key Concepts
–Draft Status: A protective state that allows for editing; once a document moves out of this state, it can no longer be modified via this process.
–Stock Outgoing: A record representing a planned removal of inventory from a specific location.
–Transactional Update: A "all-or-nothing" approach where the system ensures that if any part of the update fails (e.g., insufficient stock), none of the changes are saved, keeping the data consistent.
–Inventory Validation: A safety check that ensures you cannot request more items than are currently available at the chosen location.
–Automated Pricing: The system ignores manual cost inputs and instead pulls the most current average cost from the inventory records to ensure financial accuracy.
2.4Business Value

This feature streamlines inventory management by allowing users to correct or adjust outgoing stock requests before they are finalized. By automating the cost calculation and enforcing strict stock availability checks, it reduces the risk of human error, prevents overselling of inventory, and ensures that financial reporting remains accurate and up-to-date.
