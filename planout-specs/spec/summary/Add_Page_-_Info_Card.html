1.  Frontend
1.1Overview

The "Info Card" is the primary data entry component for the Add Service Product page. It allows users to define the core identity of a service, including its name, unique identifier (SKU), classification, and descriptive details. The component is designed to ensure data quality by providing immediate feedback if required fields are left blank.

1.2Step-by-Step Flow
1.Enter Basic Details: The user fills in the Service Name and SKU. The system validates these fields in real-time; if they are left empty, an error message appears to prompt the user.
2.Select Classification: The user selects a service type from a dropdown menu. If the desired type does not exist, the user can click the "+ New Type" button to open a pop-up window to create a new one.
3.Apply Tags: The user selects relevant tags from a list. If a new tag is needed, the user can click the "+ New Tag" button to open a pop-up window to create it.
4.Add Description: The user provides any additional context or details about the service in the description text area.
5.Save Auxiliary Data: When creating a new Type or Tag via the pop-up windows, the user enters the necessary details and saves, which updates the available options in the main form.
1.3Key Concepts
–SKU (Stock Keeping Unit): A unique alphanumeric code used to identify and track a specific service product.
–Validation: An automated check that ensures essential information (like Name and SKU) is provided before the user proceeds, preventing incomplete data entry.
–Auxiliary Entities: Supporting categories (Types and Tags) that help organize and filter services.
–Modal: A pop-up window that allows the user to perform a secondary task (like creating a new tag) without leaving the main page or losing their current progress.
1.4Business Value

This feature streamlines the service creation process by centralizing all essential information in one place. By including real-time validation, it reduces data entry errors, ensuring that every service is properly identified and categorized from the start. Furthermore, the ability to create new Types and Tags on the fly prevents workflow interruptions, allowing users to maintain productivity without needing to navigate to separate administrative settings pages.
