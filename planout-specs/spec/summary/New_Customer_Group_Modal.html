1.1Overview

The New Customer Group modal is a focused interface within the Lumi ERP designed to help users quickly categorize customers. By providing a simple, dedicated form, this feature allows you to define and save new customer groups without navigating away from your current workspace.

1.2Step-by-Step Flow
1.Initiation: The user opens the "New Customer Group" modal, which displays a clear title identifying its purpose.
2.Data Entry: The user enters the desired name for the new customer group into the required text field.
3.Validation: As the user types, the system automatically checks that the name field is not empty. If the field is left blank, an error message appears to guide the user.
4.Submission: Once a valid name is entered, the user clicks the "Save" button. The system processes the request and automatically closes the modal upon a successful save.
5.Cancellation: At any point before saving, the user can dismiss the modal using either the "Cancel" button or the "X" icon in the header, which will discard any unsaved changes.
1.3Key Concepts
–Modal: A pop-up window that appears over the main application screen, allowing you to complete a specific task without leaving your current page.
–Validation: An automated check that ensures required information—in this case, the group name—is provided before the system allows the data to be saved.
–Mutation: The technical process of sending your new group information to the system's database to create the record.
1.4Business Value

This feature streamlines the customer management process by reducing the time and effort required to organize your client base. By providing an intuitive, error-resistant interface, it ensures that customer data is categorized consistently and accurately, which helps maintain clean records and improves reporting capabilities within the Lumi ERP.
