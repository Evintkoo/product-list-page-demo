1.1Overview

The Customers Menu is a sidebar navigation component designed for the Lumi ERP system. It provides a structured way for users to access key areas of the platform, specifically focusing on Customers, Vehicles, and Vouchers. The menu uses an "accordion" style, allowing users to expand or collapse specific sections to keep the interface clean and focused on the task at hand.

1.2Step-by-Step Flow
1.Initial Load: When the user first accesses the system, the "Customers" menu is expanded by default, and the "Customers" category is highlighted as the active section.
2.Interaction: The user clicks on a main navigation item (Customers, Vehicles, or Vouchers).
3.State Update: The system updates the "active" highlight to the selected item and triggers the accordion logic.
4.Accordion Toggle: If the clicked section is closed, it expands to reveal specific sub-options (e.g., "Add New Customer" or "View All Vehicles"). If it is already open, clicking it again will collapse the sub-menu.
5.Navigation: Selecting a sub-option directs the user to the corresponding page within the ERP.
1.3Key Concepts
–Accordion Menu: A design pattern where clicking a main header expands or collapses a list of sub-items, helping to save screen space.
–Active State: A visual indicator (highlighting) that shows the user which main category they are currently viewing.
–Navigation Item: The primary buttons in the sidebar that act as the entry points for the different modules (Customers, Vehicles, Vouchers).
–Sub-menu: The secondary list of specific actions or pages that appear once a main category is expanded.
1.4Business Value
–Improved Usability: By organizing features into collapsible categories, users can navigate the ERP more intuitively without being overwhelmed by too many options at once.
–Efficiency: The default "Customers" view ensures that the most frequently used module is immediately accessible upon login, reducing the number of clicks required to start work.
–Consistency: The standardized accordion behavior across all menu items provides a predictable experience, making it easier for staff to learn and navigate the system quickly.
