1.  Frontend
1.1Overview

The "Franchise Purchase Return Details" feature provides a comprehensive view of a specific return transaction within the Lumi ERP system. It allows users to review the internal details, status, and itemized breakdown of a return initiated by a franchise, ensuring full visibility into the lifecycle of the document from creation to approval.

1.2Step-by-Step Flow
1.Navigation: The user accesses the page via the Inventory module, which provides context-specific menus to ensure they remain within the correct workflow.
2.Data Retrieval: Upon loading, the system automatically fetches the full record for the selected purchase return.
3.Status Monitoring: A visual status bar displays the current stage of the return (e.g., Draft, Confirmed, Sent, or Approved), allowing the user to quickly identify where the document sits in the approval process.
4.Metadata Review: The "Details" panel presents core administrative information, such as document numbers, store/warehouse locations, and audit timestamps (created/updated by).
5.Itemized Breakdown: A detailed table lists every product included in the return, showing specific quantities (store, order, and return quantities), supply pricing, and the reason for the return.
6.Return Navigation: A dedicated back button allows the user to return to the main list of franchise purchase orders at any time.
1.3Key Concepts
–Workflow Status: A visual indicator that tracks the progression of a document through its lifecycle, helping users understand if a return is still in progress or finalized.
–Metadata: The high-level administrative data associated with the return, such as reference numbers, involved parties (store/supplier/warehouse), and system timestamps.
–Itemized Return Data: A granular view of the products being returned, which includes specific quantity metrics and the justification for the return, providing transparency for inventory adjustments.
1.4Business Value
–Operational Transparency: By centralizing all internal details and status updates in one view, staff can quickly verify the accuracy of a return without needing to cross-reference multiple documents.
–Improved Auditability: The inclusion of "Created By," "Updated By," and timestamp information ensures that every return has a clear trail of accountability.
–Efficient Decision Making: Providing clear visibility into return reasons and quantity discrepancies allows managers to make informed decisions regarding inventory management and franchise relations.
