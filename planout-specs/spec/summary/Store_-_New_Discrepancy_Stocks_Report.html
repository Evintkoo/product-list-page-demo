1.  Frontend
1.1Overview

The "New Discrepancy Stocks Report" feature provides a dedicated page within the Inventory module for staff to record stock discrepancies. This tool allows users to select a specific store, identify products with stock mismatches, specify the quantity involved, and add explanatory notes. The system ensures data integrity by validating entries before saving them as a new "Draft" report.

1.2Step-by-Step Flow
1.Initialization: When the page loads, the system verifies the user's login status and automatically populates the "Entity" dropdown with a list of available stores.
2.Adding Items: The page starts with one empty row. Users can add more rows as needed by clicking the "Add Item" button.
3.Product Selection: Within each row, users search for products by typing their name, SKU, or code. The system provides real-time search results to ensure the correct item is selected.
4.Data Entry: For each selected product, the user enters the discrepancy quantity (which must be greater than zero) and any relevant notes.
5.Managing Rows: If a user adds a row by mistake, they can remove it using the delete icon.
6.Saving: Once the form is complete, the user clicks "Save." The system validates that a store is selected, all rows have valid products and quantities, and no duplicate products are listed.
7.Completion: Upon successful validation, the report is saved as a "Draft" and the user is redirected back to the main list of discrepancy reports. If validation fails, the system highlights the errors so the user can correct them.
1.3Key Concepts
–Entity: The specific store location where the stock discrepancy is being reported.
–Discrepancy: A mismatch between the recorded stock levels and the actual physical count.
–Draft Status: The initial state of a new report, allowing for review before any final stock adjustments are processed.
–Validation: Automated checks that prevent incomplete or incorrect data (such as zero quantities or missing product selections) from being saved.
1.4Business Value
–Accuracy: By requiring specific product identification and quantity entry, the feature reduces manual errors in inventory tracking.
–Accountability: The inclusion of notes for each discrepancy provides a clear audit trail, helping management understand why stock levels were adjusted.
–Efficiency: The streamlined, row-based interface allows staff to quickly document multiple discrepancies in a single session, saving time compared to manual or paper-based reporting.
–Standardization: By forcing all discrepancy reports through a structured digital form, the business ensures consistent data collection across all store locations.
2.  Logic
2.1Overview

The "New Discrepancy Stocks Report" feature provides a streamlined way for users to document inventory discrepancies within the Lumi ERP system. This page allows staff to select a store and list specific products that have stock variances, along with the quantity and any relevant notes. The system automatically handles administrative details like document numbering and status tracking, ensuring that records are created consistently and accurately.

2.2Step-by-Step Flow
1.Authentication & Setup: When the page loads, the system verifies the user's login status. If authorized, it automatically retrieves a list of active stores to populate the "Select Entity" dropdown.
2.Adding Items: Users can add products to the report. As the user types a product name, SKU, or code, the system searches the product database in real-time to help the user select the correct item.
3.Data Entry: For each selected product, the user enters the discrepancy quantity and any necessary notes. Users can add multiple rows or remove rows as needed.
4.Saving the Report: Once the form is complete, the user clicks "Save." The system validates the input (e.g., ensuring a store is selected and the table is not empty) and submits the data.
5.System Processing: Upon a successful save, the server automatically assigns a unique document reference code, sets the status to "Draft," and records the creation date.
6.Completion: The user is redirected back to the main Discrepancy Stocks list, where the new report appears at the top of the list. If there are any errors during saving, the system highlights the specific fields that need attention.
2.3Key Concepts
–Discrepancy Stock: A record used to track differences between expected and actual inventory levels.
–Entity Field: A selection menu that allows the user to specify which store location the inventory discrepancy belongs to.
–Draft Status: The initial state of a new report, indicating that it has been created but is still open for review or further action.
–Document Reference Code: A unique, system-generated identifier (e.g., DISC/StoreCode/Sequence) that makes it easy to track and find specific reports.
–Validation: Automated checks performed by the system to prevent incomplete or incorrect data from being saved, such as preventing duplicate product entries or zero-quantity reports.
2.4Business Value

This feature simplifies inventory management by providing a dedicated, user-friendly interface for reporting stock variances. By automating the generation of reference codes and document statuses, the system reduces manual administrative work and minimizes the risk of human error. This ensures that inventory discrepancies are captured in a standardized format, allowing for better oversight and more accurate stock reconciliation across all store locations.

3.  Data
3.1Overview

The "New Discrepancy Stocks Report" feature allows store staff to formally document inventory mismatches within the Lumi ERP system. When a user identifies a difference between expected and actual stock levels, they can create a "Discrepancy Stock" record. This feature ensures that these findings are captured accurately, assigned a unique tracking number, and saved as a draft for further review or processing.

3.2Step-by-Step Flow
1.Data Entry: The user selects the relevant store location and adds one or more products to the report, specifying the quantity of the discrepancy and any necessary notes for each item.
2.Validation: The system checks the entry to ensure a store is selected, the product list is not empty, no duplicate products are listed, and all quantities are greater than zero. If any information is missing or incorrect, the system alerts the user and keeps the form open for corrections.
3.Document Generation: Once validated, the system automatically generates a unique reference code for the report based on the store location and a sequential number.
4.Record Creation: The system saves the report header and the list of items as a single "Draft" record. No changes are made to actual inventory levels at this stage, as this is a documentation step.
5.Confirmation: Upon successful saving, the user is redirected to the main Discrepancy Stocks list, where the new report appears at the top with its unique reference code and a "Draft" status.
3.3Key Concepts
–Discrepancy Stock: A formal record used to document items where the physical count does not match the system records.
–Draft Status: The initial state of a report, indicating that it has been saved but has not yet triggered any final inventory adjustments.
–Document Reference: A unique, system-generated identifier (e.g., DISC/STORE-CODE/0001) that allows staff to easily track and locate specific discrepancy reports.
–Validation: Automated checks that prevent incomplete or erroneous data from being saved, ensuring the integrity of the inventory records.
3.4Business Value

This feature provides a structured and reliable way to track inventory errors. By moving from informal notes to a standardized digital report, the business gains better visibility into stock inaccuracies. Because the system handles the unique numbering and validation, it reduces manual data entry errors and ensures that all discrepancies are accounted for before any final inventory adjustments are made.
