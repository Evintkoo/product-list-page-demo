1.  Frontend
1.1Overview

The Store Stock Reservations feature provides a centralized view for tracking inventory that has been set aside for specific purposes. This page allows users to monitor reserved stock across different store locations, filter by date ranges or specific products, and quickly navigate to related work orders or product details.

1.2Step-by-Step Flow
1.Authentication: Upon opening the page, the system verifies your identity. If you are not logged in, you will be automatically redirected to the login screen.
2.Initialization: The system automatically loads the list of available stores to populate the filter dropdown and performs an initial search to display all current stock reservations without requiring manual input.
3.Filtering: You can narrow down the list of reservations using the filter bar, which includes:

* A date range (Start and End dates).

* Product identifiers (SKU or Name).

* A specific store location (required).

4.Search: After adjusting your filters, clicking the "Search" button updates the table instantly to show only the relevant records.
5.Navigation: You can click on specific items in the table to view more details:

* Clicking a Reference Code takes you directly to the associated work order.

* Clicking a Product SKU takes you to the product detail page.

1.3Key Concepts
–Stock Reservation: Inventory that has been allocated or "held" for a specific work order or business requirement.
–Reference Code: A unique identifier linked to the source document (such as a work order) that triggered the stock reservation.
–SKU (Stock Keeping Unit): A unique code used to identify and track specific products in the inventory.
–Filter Parameters: The criteria (dates, product info, store) used to refine the list of reservations displayed in the table.
1.4Business Value

This feature improves inventory accuracy and operational efficiency by providing clear visibility into reserved stock. By allowing staff to quickly filter and locate reservations, the system helps prevent stockouts and ensures that inventory is correctly allocated to the right work orders. The ability to jump directly from a reservation to a work order or product page streamlines the workflow for inventory managers and store staff, reducing the time spent searching for information.

2.  Logic
2.1Overview

The Stock Reservations feature provides a centralized view for tracking inventory that has been set aside. When a user navigates to the page, the system automatically verifies their identity and populates a list of current reservations. Users can refine this list using various filters, such as date ranges, specific products, or store locations, ensuring they can quickly find the information they need to manage stock effectively.

2.2Step-by-Step Flow
1.Authentication: Upon opening the page, the system checks if the user is logged in. If the user is not authorized, they are automatically redirected to the login screen.
2.Initialization: Once authenticated, the system retrieves a list of available stores to populate the "Select Store" filter dropdown.
3.Automatic Data Load: The system immediately performs an initial search to display all current stock reservations without requiring the user to manually click a search button.
4.Filtering: When a user enters criteria (such as a date range, product name, or store), the system updates the view by sending these specific filters to the database and refreshing the table.
5.Data Display: The system maps the retrieved reservation details—including reservation dates, product information, quantities, and store names—into a clear, readable table format.
2.3Key Concepts
–Stock Reservation: A record indicating that a specific quantity of a product has been set aside at a particular store location.
–Filter Criteria: Search parameters (like date, product SKU, or store) that allow users to narrow down the list of reservations.
–Authentication: A security check that ensures only logged-in users can access sensitive inventory data.
–Automatic Retrieval: A user-friendly design choice where the system fetches and displays data immediately upon page load, saving the user an extra click.
2.4Business Value

This feature improves inventory accuracy and operational efficiency by providing real-time visibility into reserved stock. By automating the data retrieval process and offering intuitive filtering, staff can quickly identify which products are held for specific orders or purposes, reducing the risk of overselling and helping store managers make better-informed decisions about their available inventory.

3.  Data
3.1Overview

The Stock Reservations feature provides a centralized view for tracking items that have been set aside or reserved across different store locations. This tool allows staff to easily search, filter, and monitor reservation records, ensuring that inventory levels are accurately reflected and managed. By providing a clear overview of what is reserved, where it is held, and when it was requested, the system helps prevent overselling and improves stock accuracy.

3.2Step-by-Step Flow
1.Initial Load: When the page opens, the system automatically retrieves the full list of current stock reservations and populates the "Select Store" dropdown menu with all available store locations.
2.Filtering: Users can narrow down the list of reservations by applying specific criteria, such as a date range, a specific product name or code (SKU), or by selecting a particular store.
3.Data Retrieval: Once filters are applied, the system sends these criteria to the database to fetch only the relevant records.
4.Display: The system presents the filtered results in a clear table format, showing key details like the reservation date, product information, quantity, and the associated store name.
3.3Key Concepts
–Stock Reservation: A record indicating that a specific quantity of a product has been set aside at a particular store for a future purpose.
–Filter Criteria: The specific parameters (such as date, product name, or store) used to refine the list of reservations so users can find exactly what they need.
–Store Mapping: The process of linking a reservation record to a specific store location, ensuring that users can see exactly where the reserved inventory is physically held.
–SKU (Stock Keeping Unit): A unique identifier used to track a specific product within the inventory system.
3.4Business Value
–Improved Inventory Accuracy: By tracking reservations in real-time, the business can avoid selling items that are already spoken for, reducing customer service issues.
–Operational Efficiency: Staff can quickly locate reservation details without manually searching through paper records or disparate systems, saving time during daily operations.
–Better Decision Making: With the ability to filter by store and date, managers can gain insights into reservation trends, helping them better allocate stock across different locations.
