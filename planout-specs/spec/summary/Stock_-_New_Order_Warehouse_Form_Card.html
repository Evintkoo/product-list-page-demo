1.  Frontend
1.1Overview

The "New Order Warehouse Form" is a user-friendly interface designed to help staff create new stock transfer orders within the Lumi ERP system. This form allows users to specify where stock is coming from, where it is being delivered, and when it is expected to arrive, ensuring all necessary details are captured before an order is officially recorded.

1.2Step-by-Step Flow
1.Select Origin: The user chooses the source warehouse from a list of available locations.
2.Select Destination: The user chooses the destination store where the stock should be delivered.
3.Enter Reference: The user provides a unique reference code for the order.
4.Set Due Date: The user selects the date by which the order is expected to be completed.
5.Set Status: The user selects the current workflow state (e.g., Draft or Confirmed).
6.Add Notes: The user may optionally include any additional comments or instructions regarding the order.
7.Validation: As the user fills out the form, the system checks that all required fields are completed.
8.Submission: Once the user clicks "Create Order," the system verifies the information and saves the new transfer order to the system.
1.3Key Concepts
–Required Fields: Specific information—such as the source warehouse, destination store, reference code, and due date—must be provided to ensure the order can be processed correctly.
–Workflow State: A status indicator that tracks the progress of an order, starting from a "Draft" phase through to completion or cancellation.
–Reference Code: A unique identifier used to track and locate specific orders within the system.
–Transfer Order: The underlying business process where stock is moved from one internal location (warehouse) to another (store).
1.4Business Value

This feature streamlines inventory management by providing a standardized way to initiate stock transfers. By enforcing data entry requirements at the point of creation, the system reduces errors, improves tracking accuracy, and ensures that warehouse staff have clear, actionable information to fulfill delivery requests on time.

2.  Logic
2.1Overview

The New Order Warehouse Form Card is a feature within the Lumi ERP system designed to streamline the creation of stock transfer orders. It provides a user-friendly interface for staff to input essential details about moving inventory from a warehouse to a specific store. The system ensures that all critical information is captured and validated before the order is officially recorded in the database.

2.2Step-by-Step Flow
1.Data Collection: The user fills out the form, selecting the source warehouse, the destination store, the current workflow status, a reference code, and the expected due date. An optional notes field is also available for additional context.
2.Validation: Upon submission, the system checks that all mandatory fields (source warehouse, destination store, reference code, due date, and workflow status) have been provided. If any required information is missing, the system will alert the user.
3.Mapping: The system organizes the collected information into a standardized format, automatically assigning the order type as a "Transfer" and aligning the user-selected workflow status with the internal system requirements.
4.Persistence: Once validated and mapped, the order details are securely saved to the inventory database, and the system confirms the creation of the new order.
2.3Key Concepts
–Workflow State: The current phase of the order (e.g., Draft, Confirmed, Sent, or Received), which helps track the progress of the inventory transfer.
–Source Warehouse: The specific location from which the stock is being moved; the system only displays active warehouses to ensure accuracy.
–Reference Code: A unique identifier or tracking number assigned to the order for easy searching and auditing.
–Due Date: The target date by which the stock transfer is expected to be completed.
2.4Business Value

This feature improves inventory management efficiency by providing a structured, error-proof way to initiate stock transfers. By enforcing mandatory fields and validating data at the point of entry, the system reduces manual errors and ensures that warehouse staff have all the necessary information to fulfill orders accurately. This leads to better visibility into stock movement and helps maintain consistent inventory levels across all store locations.

3.  Data
3.1Overview

The New Order Warehouse Form Card is a user-friendly interface component designed to help staff initiate new inventory stock orders within the Lumi ERP system. This feature streamlines the ordering process by allowing users to select a specific warehouse and define the type of order, ensuring that all new requests are captured accurately and consistently as "Draft" orders.

3.2Step-by-Step Flow
1.Loading Available Warehouses: When the form card is opened, the system automatically retrieves a list of all currently active warehouses to ensure users only select valid locations.
2.User Selection: The user selects the desired warehouse from the provided dropdown menu and confirms the type of order (defaulting to "Restock").
3.Submission: Upon clicking the submit button, the system captures the selected warehouse and order type.
4.Order Creation: The system creates a new stock order record, automatically assigning it a "Draft" status.
5.System Refresh: Once the order is successfully created, the system automatically updates the inventory dashboard to reflect the new order, ensuring the user sees the most current information.
3.3Key Concepts
–Active Warehouse: A facility that is currently operational and eligible to receive or process new stock orders.
–Draft Status: The initial state of a new order, indicating that it has been created but is not yet finalized or processed.
–Order Type: A classification for the request (such as "Restock"), which helps the system categorize and manage inventory movement correctly.
–Data Refresh: An automatic background process that ensures the inventory list stays up-to-date immediately after a new order is submitted.
3.4Business Value

This feature simplifies inventory management by providing a standardized, error-proof way to initiate stock orders. By restricting selections to active warehouses and automating the initial "Draft" status, the system reduces manual data entry errors and ensures that inventory records remain organized. Furthermore, the automatic refresh functionality provides real-time visibility, allowing teams to track new orders immediately without needing to manually reload the page.
