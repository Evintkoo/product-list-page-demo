1.  Frontend
1.1Overview

The "Add Discount" feature provides a user-friendly interface to apply price reductions to specific products within the inventory system. This tool allows staff to set discounts either as a fixed monetary amount (IDR) or as a percentage, while automatically calculating the final price in real-time to ensure accuracy before saving.

1.2Step-by-Step Flow
1.Identify Product: The modal opens, displaying the specific product name and SKU to ensure the user is editing the correct item.
2.View Base Price: The system displays the current price (including tax) in a read-only field for reference.
3.Select Discount Type: The user chooses whether to apply the discount as a flat currency amount (IDR) or a percentage (%).
4.Enter Discount Value: The user inputs the discount value. The system validates this input immediately to prevent negative numbers or percentages exceeding 100%.
5.Toggle Tax Status: The user can check a box to indicate if the discount calculation should account for tax.
6.Review Final Price: The system automatically calculates and displays the "Final Price" based on the inputs provided.
7.Save or Cancel: The user clicks "Save" to apply the changes to the product or "Cancel" to discard the inputs and close the window.
1.3Key Concepts
–Discount Type: A toggle that determines if the discount is calculated as a fixed currency deduction or a percentage of the total price.
–Real-time Calculation: The system instantly updates the "Final Price" field as the user modifies the discount value or type, providing immediate feedback.
–Input Validation: Built-in safety checks that prevent invalid entries, such as negative discounts or percentages greater than 100%.
–Read-only Fields: Specific fields (like the original price and final price) are locked from manual editing to ensure data integrity and prevent calculation errors.
1.4Business Value

This feature streamlines the inventory management process by removing the need for manual price calculations. By providing an automated, validated interface, it reduces the risk of human error during sales or promotional activities, ensures consistent pricing, and saves time for staff when updating product information.

2.  Logic
2.1Overview

The "Add Discount" feature for the Lumi ERP inventory system is designed to streamline how staff apply price reductions to specific items. When a user selects a product to discount, this feature automatically opens a dedicated window that pre-fills the necessary product information, ensuring accuracy and saving time by eliminating the need for manual data entry.

2.2Step-by-Step Flow
1.Triggering the Action: The user selects a specific product from the inventory list to apply a discount.
2.Data Retrieval: The system automatically captures the selected product's unique identifier (SKU), its name, and its current price from the inventory row.
3.Information Mapping: The system maps this captured information into the "Add Discount" window.
4.Display: The discount window opens, clearly showing the product details so the user can confirm they are applying the discount to the correct item before proceeding.
2.3Key Concepts
–Product Context: The specific set of information (SKU, name, and price) associated with an item that is passed from the inventory list to the discount tool.
–Data Mapping: The internal process of ensuring that the information from the inventory list is correctly labeled and placed into the corresponding fields in the discount window.
–Initialization: The automatic "setup" phase that occurs the moment the window opens, ensuring all relevant product data is ready for the user immediately.
2.4Business Value

This feature improves operational efficiency and reduces human error. By automatically pulling product details into the discount window, staff members avoid the risk of applying a discount to the wrong item or misreading the current price. This creates a smoother, more reliable workflow for managing inventory pricing adjustments within the Lumi ERP system.
