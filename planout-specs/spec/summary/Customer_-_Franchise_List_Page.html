1.  Frontend
1.1Overview

The Franchise List Page provides a centralized view for managing franchise customer records within the Lumi ERP system. This page allows users to view a comprehensive list of franchisees, search for specific records using various criteria, and perform quick administrative actions like editing or deactivating a franchise account.

1.2Step-by-Step Flow
1.Initial Load: When the page is first opened, the system automatically retrieves and displays the full list of available franchises.
2.Filtering: Users can narrow down the list using the filter bar. You can search by specific details such as customer group, store, active status, code, tax number, birthdate, phone, or address.
3.Applying Search: Once the desired filters are entered, clicking the "Apply Search" button triggers the system to refresh the table, showing only the records that match the criteria provided.
4.Viewing Details: Users can click on a franchisee's name or their unique franchise code to navigate directly to that specific customer's detailed record.
5.Managing Records: Each row includes action buttons to either edit the franchisee's information or deactivate the account. If "Deactivate" is selected, a confirmation window appears to prevent accidental changes.
1.3Key Concepts
–Filter Bar: A set of search fields that allows users to find specific franchisees without needing to scroll through the entire list. Only fields with information entered are used to refine the search.
–Franchise Table: The main display area that organizes franchisee data into columns, including contact information, status, and geographic region.
–Action Buttons: Tools located on each row that allow for quick updates (Edit) or status changes (Deactivate) for individual franchisees.
–Deactivation Modal: A safety feature that requires a user to confirm their intent before an account status is changed to "Inactive."
1.4Business Value

This feature streamlines franchise management by providing a high-level overview of all franchise partners in one place. By enabling quick filtering and direct access to individual records, staff can spend less time searching for data and more time managing relationships. Additionally, the built-in deactivation workflow ensures that status changes are intentional and accurate, maintaining data integrity across the ERP.

2.  Logic
2.1Overview

The Franchise List Page is a dedicated interface within the Lumi ERP system designed to help users manage and view franchise-specific customer data. This feature allows users to instantly view a list of all franchise customers upon opening the page, search for specific records using various criteria, and manage the status of these customers by deactivating them when necessary.

2.2Step-by-Step Flow
1.Initial Load: When the page is opened, the system automatically retrieves the full list of franchise customers and displays them in the list view.
2.Data Mapping: The system organizes the raw customer information into the user interface, ensuring details like the customer's name, franchise code, contact information, and current status are clearly visible.
3.Filtering: Users can narrow down the list by entering information into the filter bar (such as customer group, store, tax number, or contact details). When the user clicks "Apply," the system sends only the active search criteria to the server to fetch the relevant results.
4.Deactivation: If a user needs to remove a franchise customer from active status, they can click the "Deactivate" button. This triggers a confirmation process, after which the system updates the customer's status to "Inactive" in the database.
2.3Key Concepts
–Franchise Customer: A specific category of customer within the ERP system that requires unique tracking, such as a franchise code and regional assignment.
–Filter Bar: A search tool that allows users to find specific records by applying one or more criteria (e.g., searching by phone number or tax ID) without needing to browse the entire list.
–Status Management: The ability to toggle a customer's state to "Inactive," which helps maintain accurate records without permanently deleting historical data.
–Data Mapping: The process of taking raw information from the system's database and placing it into the correct fields on the screen so it is easy for the user to read.
2.4Business Value

This feature streamlines franchise management by providing a centralized, searchable view of all franchise-related customers. By enabling quick filtering and simple status updates, it reduces the administrative burden on staff, ensures that customer records remain accurate and up-to-date, and allows for faster decision-making when managing franchise relationships.

3.  Data
3.1Overview

The Franchise List Page feature provides a dedicated view within the Lumi ERP system to manage and monitor franchise-specific customer accounts. This tool allows users to quickly locate franchises, filter them by their current operational status, and view their relationship to parent corporate entities, ensuring clear oversight of the franchise network.

3.2Step-by-Step Flow
1.Requesting the List: The system retrieves all customers categorized specifically as "Franchises."
2.Applying Filters: Users can narrow down the list by searching for a specific franchise name or by selecting a status (such as Active or Inactive).
3.Sorting: The results are automatically organized to show the most recently created franchises at the top of the list.
4.Viewing Details: When a user selects a specific franchise, the system displays its profile, including its official name, current status, registration date, and the name of its parent corporate organization.
3.3Key Concepts
–Franchise: A specific type of customer account within the ERP that operates under a parent corporate entity.
–Status Filtering: A tool that allows users to isolate franchises based on their operational state, helping to manage active versus inactive locations.
–Parent Organization: The corporate entity that oversees or owns the franchise, providing context on the business hierarchy.
–Data Mapping: The process of translating raw system information into a clear, user-friendly format for the dashboard.
3.4Business Value

This feature streamlines administrative tasks by providing a centralized hub for franchise management. By enabling quick searches and status-based filtering, staff can spend less time hunting for records and more time managing relationships. Additionally, by clearly linking franchises to their parent organizations, the system ensures that users have the necessary context to make informed decisions regarding corporate compliance and account management.
