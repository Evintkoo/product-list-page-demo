1.  Frontend
1.1Overview

The Supplier Details Card is a read-only component designed for the Supplier Detail Page within the Lumi ERP system. Its primary purpose is to provide a clear, organized view of a supplier's identity and contact information, ensuring that users can quickly reference essential business data without the risk of accidental modification.

1.2Step-by-Step Flow
1.Header Display: The card displays a "Details" header accompanied by a person icon to clearly identify the section's purpose.
2.Identity Information: The system populates the card with the supplier's name, unique supplier code, and the designated contact person's name.
3.Contact Information: The system displays the supplier's email, phone number, fax number, and physical address.
4.Tax & Registration: The system displays the Tax Number and Registration Number. These specific fields include a help icon to provide additional context or guidance to the user if needed.
5.Empty State Handling: If any specific piece of information is missing for a supplier, the system will display a dash (-) to maintain a clean and consistent layout.
1.3Key Concepts
–Read-Only Fields: Information displayed for reference purposes only; users cannot edit or change these values directly within this component.
–Help Icons: Visual indicators placed next to complex or specific fields (Tax and Registration numbers) that allow users to access additional information or definitions.
–Data Grid: A structured layout that groups related information (Identity, Contact, and Tax/Registration) to improve readability and user experience.
1.4Business Value

This component centralizes critical supplier data, reducing the time users spend searching for contact or tax information. By presenting this data in a standardized, read-only format, the feature minimizes the risk of data entry errors and ensures that all team members are viewing consistent, accurate information when managing supplier relationships.
