1.1Overview

The Customer Sub Menu is a navigation component designed to help users easily switch between different customer categories within the Lumi ERP system. It functions as an accordion-style menu, providing a clean and organized way to access specific customer lists, such as Retail and Corporate customers.

1.2Step-by-Step Flow
1.Initialization: When the Customer module is first accessed, the system automatically selects "Retail Customers" as the default active view.
2.User Interaction: The user selects a category (Retail or Corporate) from the sub-menu.
3.State Update: The system highlights the selected category to indicate it is currently active.
4.Navigation: The system directs the user to the corresponding page for the selected customer category.
5.URL Synchronization: If a user navigates to a customer page via a direct link or browser history, the menu automatically detects the current location and updates the highlighted tab to match the page being viewed.
1.3Key Concepts
–Accordion Menu: A space-saving navigation style that allows users to expand or collapse sections to find specific information.
–Active State: A visual indicator (highlighting) that shows the user which section of the system they are currently viewing.
–Routing: The process of moving the user to a specific page within the software based on their menu selection.
–Synchronization: A background process that ensures the menu's visual state always matches the page currently displayed in the browser.
1.4Business Value
–Improved Usability: By grouping customer types into a dedicated sub-menu, users can navigate the ERP system more intuitively without getting lost in complex menus.
–Consistency: The automatic synchronization between the URL and the menu ensures that the interface always reflects the user's current context, reducing confusion.
–Efficiency: Providing a clear, default starting point ("Retail Customers") streamlines the workflow for the most common user tasks, saving time during daily operations.
