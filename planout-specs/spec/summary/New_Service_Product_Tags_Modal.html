1.  Frontend
1.1Overview

The "New Service Product Tag" modal is a streamlined tool designed to help users categorize service products directly within the "Add Service Product" page. This feature allows staff to quickly define new tags—such as specific service types or categories—without navigating away from their current workflow, ensuring that product data remains organized and consistent.

1.2Step-by-Step Flow
1.Open the Modal: The user initiates the process from the "Add Service Product" page, opening the "New Service Product Tag" window.
2.Enter Tag Details: The user provides a name for the tag (which is mandatory) and an optional description to provide further context.
3.Validation: The system ensures the name is provided and adheres to length requirements.
4.Submit or Cancel:

* If the user clicks Save, the system attempts to create the new tag. Upon success, the modal closes and the new tag becomes available for use.

* If the user clicks Cancel or the Close (X) icon, the modal closes immediately, and any entered information is discarded.

1.3Key Concepts
–Service Product Tag: A label used to categorize or group service products, making them easier to filter and manage within the ERP system.
–Modal: A pop-up window that appears over the main screen, allowing the user to complete a specific task without leaving their current page.
–Validation: A built-in check that ensures required information (like the tag name) is present and formatted correctly before the system accepts the data.
1.4Business Value
–Improved Efficiency: Users can create new tags on the fly, preventing interruptions to their data entry process.
–Data Consistency: By providing a simple interface for tag creation, the system encourages users to categorize products accurately, which leads to better reporting and easier product discovery.
–Reduced Friction: The intuitive design minimizes the time spent managing administrative settings, allowing staff to focus on core service product management.
2.  Logic
2.1Overview

The New Service Product Tags Modal is a feature designed to help users quickly create and categorize service products directly within the "Add Service Product" page. Instead of navigating away to a separate settings page, users can open this modal to define a new tag name and description, which is then immediately available for use in their current task.

2.2Step-by-Step Flow
1.Input Details: The user enters a name and an optional description for the new tag into the modal form.
2.Validation: When the user clicks "Save," the system checks that a name has been provided. If the name field is empty, an error message appears to prompt the user for the required information.
3.Submission: Once validated, the system securely sends the new tag information to the database.
4.Confirmation and Update: Upon a successful save, the system receives confirmation and the new tag's unique ID. The modal automatically closes, and the new tag is instantly added to the service product dropdown menu and selected for the user.
2.3Key Concepts
–Service Product Tag: A label used to categorize and organize service products, making them easier to find and manage.
–Validation: A built-in check that ensures essential information (the tag name) is provided before the system attempts to save the data.
–Modal: A pop-up window that allows users to perform a specific task—in this case, creating a tag—without leaving the page they are currently working on.
2.4Business Value

This feature improves user efficiency by streamlining the workflow. By allowing users to create tags "on the fly" while adding a service product, it eliminates the need to interrupt their work to navigate to a different part of the application. This reduces friction, saves time, and ensures that product categorization remains consistent and up-to-date.
