1.  Frontend
1.1Overview

The "Edit Flexible Voucher" page allows authorized users to update the details of an existing flexible voucher product within the Lumi ERP system. This interface ensures that all relevant information—such as naming, validity periods, location restrictions, and member eligibility—can be adjusted to reflect current business requirements.

1.2Step-by-Step Flow
1.Page Load: When the user navigates to the edit page, the system automatically retrieves the current data for the specific voucher and populates all form fields with the existing values.
2.Data Modification: The user updates the necessary fields, including the SKU, name, description, expiration settings, product conditions, and location or member restrictions.
3.System-Managed Fields: Certain fields, such as the price (excluding tax) and the total voucher value, are displayed as read-only to ensure data integrity, as these are managed by the system.
4.Saving Changes: Once the user is satisfied with the updates, they click the "Save" button. The system sends the updated information to the database and redirects the user back to the voucher's detail page.
5.Cancellation: If the user decides not to proceed with the changes, they can click the "Cancel" button to discard all edits and return to the voucher's detail page without modifying any data.
1.3Key Concepts
–Flexible Voucher: A versatile voucher product that allows for configurable pricing, validity, and usage rules.
–SKU (Stock Keeping Unit): A unique identifier used to track and manage the voucher product within the system.
–Open Price: A setting that, when enabled, allows the voucher to have a flexible or variable price rather than a fixed one.
–Read-only Fields: Information fields that are visible to the user but cannot be modified, as they are calculated or controlled by the system.
–Location/Member Restrictions: Configurable settings that define exactly where a voucher can be sold, issued, or redeemed, and whether it is exclusive to specific members.
1.4Business Value

This feature provides the flexibility needed to manage promotional and financial products effectively. By allowing users to easily update voucher parameters, the business can respond quickly to changing market conditions, adjust expiration dates for seasonal campaigns, or refine the eligibility criteria for specific customer segments without needing technical intervention. This ensures that voucher data remains accurate and aligned with current sales and marketing strategies.

2.  Logic
2.1Overview

The "Edit Flexible Voucher" feature allows administrators to update the details of an existing flexible voucher product within the Lumi ERP system. This ensures that voucher information—such as pricing, validity periods, and redemption locations—remains accurate and up-to-date.

2.2Step-by-Step Flow
1.Page Initialization: When a user opens the edit page for a specific voucher, the system automatically retrieves the current data for that voucher using its unique identifier.
2.Data Population: The retrieved information is automatically mapped to the corresponding fields on the screen (e.g., Name, SKU, Price, and Validity dates), allowing the user to see the current settings.
3.User Modification: The user updates the necessary fields in the form to reflect the desired changes.
4.Submission: Upon clicking the "Save" button, the system collects the updated information from the form.
5.System Update: The system sends the updated data to the database to overwrite the previous voucher details.
6.Confirmation: Once the update is successfully processed, the user is automatically redirected back to the voucher’s detail page to view the changes.
2.3Key Concepts
–Flexible Voucher: A versatile voucher product type within the ERP that supports customizable pricing, expiration rules, and specific location-based usage.
–Unique Identifier (ID): A specific reference code used by the system to ensure the correct voucher is being edited.
–Data Mapping: The process of ensuring that information entered into a form field (like "Price") is correctly saved into the corresponding database field.
–Payload: The collection of all form data bundled together by the system to be sent to the server during the save process.
2.4Business Value
–Operational Efficiency: Provides a streamlined interface for staff to quickly adjust voucher terms without needing technical intervention.
–Data Accuracy: Ensures that critical business information, such as voucher validity and pricing, is consistently maintained and synchronized across the system.
–Flexibility: Allows the business to adapt voucher offerings in real-time to meet changing promotional needs or operational requirements.
