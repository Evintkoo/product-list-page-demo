1.  Logic
1.1Overview

This feature provides a way to view the specific products (line items) associated with a single stock order. It allows users to retrieve a detailed list of items for a chosen order, with options to search by product name and navigate through large lists using pagination. The system automatically ensures that users can only access orders belonging to their own company.

1.2Step-by-Step Flow
1.Verification: The system checks if the requested stock order exists and confirms that it belongs to the user's company. If the order is missing or belongs to another company, the request is denied.
2.Filtering: If a product name is provided, the system narrows down the list to only include items that match that name.
3.Retrieval: The system fetches the requested items in the order they were originally added to the stock order. It uses pagination to return a manageable number of items at a time.
4.Response: The system returns the total quantity of all items in the original order, along with the specific list of items requested. Each item in the list is assigned a row number, which resets based on the current page of results.
1.3Key Concepts
–Pagination: A method of breaking a large list of items into smaller, manageable pages (e.g., 20 items per page) to improve performance and readability.
–Filtering: The ability to search for specific items within an order by typing a product name.
–Data Ownership: A security measure that ensures users can only view stock orders associated with their specific company.
–Total Order Quantity: A summary figure that represents the sum of all items in the order, which remains constant even if you filter the list to view only specific items.
1.4Business Value

This feature improves inventory management efficiency by allowing staff to quickly locate specific products within a stock order without having to scroll through long lists. By providing a clear, paginated view and maintaining accurate total quantity reporting, it ensures that warehouse and procurement teams have reliable, easy-to-access information to verify shipments and manage stock levels effectively.

2.  Data
2.1Overview

This feature provides a way to retrieve a list of individual products (line items) associated with a specific stock order. It is designed to be secure, efficient, and easy to navigate, allowing users to view order details even when those orders contain a large number of items.

2.2Step-by-Step Flow
1.Security Check: The system first verifies that the requested stock order exists and confirms it belongs to the company currently logged into the system. If the order cannot be found or belongs to a different company, the request is denied.
2.Data Retrieval: The system fetches the specific items for that order. It applies any search filters requested by the user and organizes the results in the order they were originally added to the system.
3.Pagination Calculation: The system counts the total number of items matching the search criteria to help the user navigate through pages of results.
4.Response Delivery: The system returns the requested list of items, the total quantity of the entire order (regardless of filters), and the pagination details (such as the current page and total count) to the user.
2.3Key Concepts
–Data Isolation: A security measure that ensures users can only access stock orders that belong to their own company.
–Pagination: A method of breaking a large list of items into smaller, manageable chunks (pages) to improve performance and readability.
–Filtering: The ability to narrow down the list of items (e.g., searching for a specific product name) without affecting the overall order totals.
–Insertion Order: The default way items are displayed, showing them in the sequence they were originally added to the order.
2.4Business Value

This feature enables staff to efficiently manage and audit inventory by providing a clear, searchable view of what is contained within a specific stock order. By including pagination and robust security checks, the system remains fast and reliable even as order sizes grow, while ensuring that sensitive company data remains protected and accessible only to authorized users.
