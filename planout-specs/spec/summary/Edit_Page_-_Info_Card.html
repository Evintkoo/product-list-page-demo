1.  Frontend
1.1Overview

The Service Product Info Card is the primary interface for viewing and updating the core details of a service product within the Lumi ERP system. This component provides a user-friendly form that allows staff to manage essential product information, such as its classification, identification codes, and descriptive metadata, ensuring that service records remain accurate and up-to-date.

1.2Step-by-Step Flow
1.Load Existing Data: When the page opens, the form is automatically populated with the current details of the service product (Type, Name, SKU, Description, and Tags).
2.Edit Fields: Users can modify the Name, SKU, and Description directly. The system performs real-time validation to ensure that mandatory fields like Name and SKU are not left empty.
3.Manage Type: Users can select a service type from a dropdown menu. If the required type is missing, they can click the "New Type" button to open a pop-up window, create a new category, and immediately apply it to the current product.
4.Manage Tags: Users can view existing tags as removable chips. They can add new tags via a multi-select menu or click the "New Tag" button to create and add a brand-new tag on the fly.
5.Real-time Feedback: As the user types or changes selections, the system immediately checks for errors and displays alerts if required information is missing.
1.3Key Concepts
–SKU (Stock Keeping Unit): A unique identifier used to track specific services within the system.
–Real-time Validation: A feature that checks for errors (such as missing required fields) the moment a user interacts with a field, providing instant feedback.
–Dynamic Creation: The ability to create new "Types" or "Tags" directly from the edit screen without needing to navigate away to a separate settings page.
–Multi-select Tags: A flexible way to categorize services by applying multiple labels, which can be easily added or removed as needed.
1.4Business Value
–Data Integrity: By enforcing mandatory fields like Name and SKU in real-time, the system prevents incomplete or invalid data from being saved.
–Operational Efficiency: The ability to create new categories (Types and Tags) directly within the edit screen reduces administrative friction, allowing users to maintain their product catalog without interrupting their workflow.
–User Experience: The pre-filled form and intuitive controls (like removable chips and clear error messaging) minimize manual data entry effort and reduce the likelihood of user error.
