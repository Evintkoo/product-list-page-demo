1.  Logic
1.1Overview

The Service Products API endpoint allows users to retrieve a filtered and organized list of service products from the Lumi ERP system. It provides a flexible way to search for specific items based on their attributes, such as name, SKU, type, or assigned tags. This feature is designed to help users quickly locate relevant service products while maintaining system performance through pagination and controlled access.

1.2Step-by-Step Flow
1.Security Check: The system verifies that the user is logged in and has the necessary permissions to view the service product list.
2.Validation: The system checks that all search criteria provided are formatted correctly. If the request is malformed or contains invalid values, the system rejects the request.
3.Reference Verification: If the user is filtering by a specific "Type" or "Tag," the system confirms that these categories actually exist in the database before proceeding.
4.Data Filtering: The system applies the requested filters (SKU, name, type, or tags) to narrow down the list of service products.
5.Sorting and Pagination: The system organizes the results based on the user's preferred sort order and limits the number of items returned to a manageable size.
6.Data Delivery: The system returns the final list of matching service products, including key details like the ID, SKU, name, type, and creation date.
1.3Key Concepts
–Filtering: The ability to narrow down a large list of items by specific criteria, such as searching for a product by its name or SKU.
–Pagination: A method of breaking a large list of results into smaller, manageable pages to improve performance and readability.
–Sorting: The ability to arrange the results in a specific order (e.g., alphabetically by name).
–Authentication & Authorization: Security measures that ensure only verified users with the correct access rights can view the data.
–Validation: A process that ensures the data sent by the user meets the system's requirements, preventing errors or invalid searches.
1.4Business Value

This feature empowers users to efficiently manage and locate service products within the Lumi ERP. By providing robust search and filter capabilities, it reduces the time spent manually browsing through records. Furthermore, by including pagination and strict permission checks, the API ensures that the system remains fast, secure, and reliable, even as the volume of service product data grows.

2.  Data
2.1Overview

This feature provides a search and filtering interface for the "Service Products" catalog within the Lumi ERP system. It allows users to retrieve a specific list of products by applying various criteria—such as searching by name or SKU, filtering by product type, or narrowing results down by specific tags. The system also supports sorting and pagination to ensure that large lists of products are easy to navigate and manage.

2.2Step-by-Step Flow
1.Receive Request: The system receives a request containing search criteria, sorting preferences, and the number of items to display per page.
2.Apply Filters: The system processes the provided filters:

* Text Search: Matches partial text for SKU or product name.

* Type Filtering: Verifies that the requested product type exists in the system before applying the filter.

* Tag Filtering: Verifies that all requested tags exist before filtering the products to include only those associated with those specific tags.

3.Apply Sorting: If a sort preference is provided (e.g., sorting by name), the system organizes the results accordingly.
4.Apply Pagination: The system limits the number of results returned based on the requested page size.
5.Return Results: The system returns the filtered, sorted, and paginated list of service products to the user.
2.3Key Concepts
–Filtering: The ability to narrow down a large list of items based on specific attributes like name, SKU, type, or tags.
–Validation: A safety check performed by the system to ensure that any categories or tags requested by the user actually exist in the database before attempting to filter by them.
–Sorting: The process of arranging the final list of results in a specific order (e.g., alphabetical).
–Pagination: A method of breaking a large dataset into smaller, manageable chunks (pages) to improve performance and readability.
–Partial Match: A search capability where the system finds results that contain the entered text, even if it is only a portion of the full name or SKU.
2.4Business Value

This feature significantly improves the user experience for staff managing the service catalog. By providing robust search and filter capabilities, users can quickly locate specific service products without manually scanning through the entire database. This reduces administrative time, minimizes errors in product selection, and ensures that the ERP system remains an efficient tool for daily operations.
