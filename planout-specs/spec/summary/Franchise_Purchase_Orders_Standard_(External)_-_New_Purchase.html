1.  Frontend
1.1Overview

The "Franchise Purchase Order Standard (External)" feature allows users to create new purchase orders for external suppliers within the Lumi ERP system. This interface provides a structured way to select a destination store, choose a supplier, define the products and quantities required, and set delivery expectations. The system ensures data accuracy through built-in validation before the order is officially submitted to the inventory management workflow.

1.2Step-by-Step Flow
1.Initialization: Upon opening the page, the system verifies your access permissions and automatically loads the necessary lists for stores, suppliers, and products.
2.Header Information: You select the destination store ("Deliver To") and the supplier ("From Supplier"). You may also optionally enter a supplier reference code, a due date, and any additional notes.
3.Adding Items: You add products to the order by selecting them from the list and specifying the desired order quantity. You can add multiple unique products to a single order.
4.Validation: When you click "Save," the system checks for errors, such as missing required fields, quantities of zero, or duplicate products.
5.Submission: If the form is valid, the order is sent to the system. The server then calculates totals, prices, and stock levels, and assigns a unique document number to the order.
6.Completion: If the submission is successful, the order is created. If there are issues, the system will highlight the specific errors for you to correct.
1.3Key Concepts
–Deliver To: The specific store location that will receive the items ordered.
–From Supplier: The external vendor or supplier providing the goods.
–Supplier Reference Code: An optional tracking number provided by the supplier for their own internal records.
–Due At: The target date by which the order is expected to be delivered.
–Validation: Automated checks that prevent incomplete or incorrect orders (e.g., ensuring you don't order the same product twice on one form).
–Product Entries: The list of items included in the purchase order, where you define what to buy and how much.
1.4Business Value

This feature streamlines the procurement process for franchises by providing a standardized, error-proof method for ordering inventory from external suppliers. By automating the validation of order details and integrating directly with the inventory workflow, it reduces manual data entry errors, ensures that all necessary information is captured before an order is placed, and provides clear visibility into supply chain costs and stock requirements.

2.  Logic
2.1Overview

This feature enables the creation of a new "External" purchase order within the Lumi ERP system. It allows users to request products from an external supplier to be delivered to a specific franchise store. The system ensures data accuracy by validating all entries before saving the order and automatically calculating financial details like supply prices and average costs.

2.2Step-by-Step Flow
1.Data Entry: The user fills out the purchase order form, including the destination store, the supplier, the due date, any relevant notes, and a list of products with their requested quantities.
2.Validation: When the user clicks "Save," the system immediately checks for errors:
–Ensures the destination store and supplier are selected.
–Confirms at least one product is included.
–Verifies that all order quantities are greater than zero.
–Checks that no product is listed more than once.
3.Processing: If the data is valid, the system creates the purchase order record. It automatically assigns a status of "Draft" and categorizes it as an "External" order.
4.Item Calculation: For every product in the order, the system automatically retrieves the current supply price and the company’s average cost to ensure financial accuracy.
5.Confirmation: Once saved, the system returns the finalized order details, including a unique reference code generated by the system.
2.3Key Concepts
–External Purchase Order: A formal request for goods sent to a supplier outside of the immediate company network.
–Validation: A safety check performed by the system to prevent incomplete or incorrect orders from being processed.
–Draft State: The initial status of a new order, indicating it has been created but is not yet finalized or sent to the supplier.
–Reference Code: A unique identifier automatically generated by the system for every new purchase order to help with tracking and record-keeping.
–Supply Price & Average Cost: Financial data points automatically pulled by the system to provide accurate valuation for the items being ordered.
2.4Business Value

This feature streamlines the procurement process for franchise stores by providing a standardized, error-proof way to order inventory. By automating the calculation of costs and enforcing strict validation rules, the system reduces manual data entry errors, ensures financial consistency across the organization, and provides a clear audit trail for all external purchases.

3.  Data
3.1Overview

The "Franchise Purchase Order" feature allows users to create new external purchase orders within the Lumi ERP system. This process ensures that orders are accurately recorded, validated, and linked to the correct store and supplier. By automating the calculation of costs and inventory levels at the time of creation, the system maintains data integrity and provides immediate visibility into the financial impact of each order.

3.2Step-by-Step Flow
1.Validation: The system checks that the order includes a destination store, a supplier, and at least one product. It also ensures that the order quantity for each product is greater than zero and that no product is listed more than once.
2.Order Header Creation: The system creates the main order record, assigning it a unique reference code, setting its status to "Draft," and recording details like the due date and any provided notes.
3.Item Processing: For every product in the order, the system automatically retrieves the current supplier price, the store's existing inventory level, and the company’s average cost for that item.
4.Financial Calculation: The system calculates the total order amount for each item (quantity multiplied by the current supply price) and saves these details alongside the order.
5.Finalization: The entire order, including the header and all calculated item details, is saved to the system as a single, complete transaction.
3.3Key Concepts
–External Purchase Order: A formal request sent to an outside supplier to procure goods for a specific franchise store.
–Draft State: The initial status of a new order, allowing for review before it is processed further.
–Atomic Transaction: A safety mechanism that ensures all parts of an order (the header and all individual items) are saved together; if any part fails, the entire order is not created, preventing incomplete data.
–Server-Side Calculation: The process where the system automatically determines prices and totals based on current data, ensuring accuracy and reducing manual entry errors.
3.4Business Value
–Data Accuracy: By automatically fetching current supply prices and inventory levels, the system eliminates manual calculation errors and ensures the order reflects the most up-to-date financial information.
–Operational Efficiency: Standardizing the creation process ensures that all necessary information is captured upfront, reducing the need for follow-up corrections.
–Reliability: The use of strict validation rules and atomic transactions ensures that every purchase order created is complete, valid, and ready for the next stage of the supply chain workflow.
