1.  Frontend
1.1Overview

The Sales Menu is the primary navigation component for the Sales module within the Lumi ERP system. It provides a clean, organized way for users to access different areas of the sales workflow—specifically Company, Store, and Service—using an accordion-style layout. By default, the "Store" section is expanded when the user first accesses the menu, ensuring the most common tasks are immediately visible.

1.2Step-by-Step Flow
1.Initial Load: When the Sales module is opened, the "Store" menu is automatically selected and expanded to show its sub-options.
2.Navigation Selection: Users can click on any of the three main categories: "Company," "Store," or "Service."
3.State Update: Clicking a category highlights that item as the "active" selection.
4.Accordion Toggle: Each category acts as an accordion. Clicking a category toggles its specific sub-menu open or closed.
5.Visual Feedback: A chevron icon next to each category name updates automatically to indicate whether that section is currently expanded (pointing down) or collapsed (pointing right).
1.3Key Concepts
–Accordion Menu: A design pattern where clicking a header expands or collapses a section of content, helping to keep the interface uncluttered.
–Active State: A visual indicator that highlights which menu item the user is currently interacting with or viewing.
–Chevron: A small arrow icon used to signal to the user that a menu item can be expanded or collapsed.
–Sub-menu: A secondary list of options nested under a main category, revealed only when the user chooses to expand that category.
1.4Business Value
–Improved Usability: By using an accordion structure, the menu prevents information overload, allowing users to focus only on the specific sales area they are currently working in.
–Efficiency: Setting the "Store" menu as the default expanded view reduces the number of clicks required for the most frequent sales tasks.
–Consistency: The standardized navigation behavior across all three categories ensures that users can easily learn and navigate the system without confusion.
