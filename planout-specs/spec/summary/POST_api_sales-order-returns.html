1.  Logic
1.1Overview

This feature allows users to record a "Sales Order Return" within the Lumi ERP system. It enables businesses to track items being returned by customers against a specific original sales invoice. The system ensures data integrity by validating that all returned items are accounted for correctly and that the return process is linked to the appropriate warehouse and customer records.

1.2Step-by-Step Flow
1.Validation: The system checks that the warehouse, customer, and sales invoice provided in the request exist and belong to the user's company.
2.Item Verification: The system confirms that at least one item is being returned and that the quantity for each item is greater than zero.
3.Quantity Check: The system verifies that the requested return quantity does not exceed the amount originally sold on the invoice (accounting for any items already returned).
4.Record Creation: If all checks pass, the system generates a unique return number and creates the return record in a "draft" status.
5.Transaction Finalization: The return header and all associated items are saved to the database simultaneously. If any part of this process fails, the entire operation is canceled to prevent data errors.
6.Confirmation: Upon success, the system returns the details of the newly created return record.
1.3Key Concepts
–Sales Order Return: A formal record documenting items sent back by a customer, linked to an original invoice.
–Draft Status: The initial state of a return, allowing for review before it is finalized or processed.
–Transaction: A safety mechanism that ensures all parts of the return (the header and the individual items) are saved together; if one part fails, nothing is saved.
–Over-return Prevention: A safeguard that prevents users from returning more items than were originally purchased on the invoice.
1.4Business Value

This feature provides a reliable audit trail for customer returns, ensuring that inventory levels are accurately managed and that returns are always tied to valid sales invoices. By automating the validation of quantities and ownership, the system reduces manual errors and prevents fraudulent or incorrect return entries, ultimately improving inventory accuracy and customer service efficiency.

2.  Data
2.1Overview

This feature allows users to record a sales order return within the Lumi ERP system. When a customer returns items, this process creates a formal record linked to the original sales invoice, ensuring that the return is tracked accurately against the correct warehouse, customer, and invoice details.

2.2Step-by-Step Flow
1.Validation: The system checks that the warehouse, customer, and sales invoice exist and belong to the user's company. It also verifies that the invoice belongs to the specified customer.
2.Quantity Verification: The system ensures that the requested return quantity is greater than zero and does not exceed the amount originally sold (accounting for any items already returned).
3.Return Number Generation: The system automatically generates a unique identification number for the return.
4.Record Creation: The system creates the return header (containing general information) and the individual return items in a single, unified action.
5.Status Assignment: The new return is saved with an initial status of "Draft."
6.Confirmation: Upon successful creation, the system returns the details of the newly created return record.
2.3Key Concepts
–Atomicity: A safety mechanism that ensures the entire return record (the header and all individual items) is saved successfully as one unit. If any part of the process fails, nothing is saved, preventing incomplete or corrupted data.
–Returnable Quantity: The remaining balance of an item from an original invoice that is eligible to be returned. The system prevents users from returning more items than were originally purchased.
–Draft Status: The initial state of a new return, indicating that the record has been created but is not yet finalized or processed.
–Ownership Validation: A security check to ensure that the warehouse, customer, and invoice selected for the return are authorized for the user's specific company.
2.4Business Value

This feature provides a reliable and controlled way to manage product returns, which is essential for maintaining accurate inventory levels and financial records. By automating the validation of return quantities against original invoices, the system prevents errors and over-crediting, ensuring that the company’s sales data remains consistent and trustworthy.
