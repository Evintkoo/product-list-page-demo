1.  Frontend
1.1Overview

The Franchise Purchase Order Standard Details feature provides a centralized view for managing purchase orders between a franchise and its suppliers. It allows users to track the lifecycle of an order—from initial draft to final receipt—while providing clear visibility into order items, financial totals, and current workflow status.

1.2Step-by-Step Flow
1.Initialization: When you open a specific purchase order, the system automatically retrieves the order header information and the list of items included in that order.
2.Review: You can view the order details, including supplier information, delivery destination, and financial summaries (subtotals, discounts, and taxes).
3.Workflow Management: Depending on the current status of the order, you can perform specific actions:

* Draft: You can confirm the order to move it to "Store Confirmed" or cancel it.

* Store Confirmed: You can send the order to the supplier to move it to "Ordered" or cancel it.

* Ordered: You can initiate the "Receive" process to verify items and finalize the order as "Store Received."

* Cancelled: You can reset the order back to "Draft" if needed.

4.Confirmation: For critical actions (like confirming, cancelling, or resetting), a pop-up window will appear to ensure you intend to proceed before the system updates the status.
5.Finalization: Once the "Receive" action is completed, the system updates the order status to "Store Received" and automatically updates the store's stock records.
1.3Key Concepts
–Workflow Status: The current stage of the order (Draft, Store Confirmed, Ordered, or Store Received), which determines which buttons and actions are available to you.
–Order Items Table: A detailed list of products in the order, showing quantities, pricing, discounts, and the final amount for each line item.
–Action Buttons: Context-sensitive controls that allow you to progress the order through its lifecycle or perform administrative tasks like printing or exporting data.
–Review State: A specific view used during the receiving process that allows you to verify order details and update notes or reference numbers before finalizing the receipt of goods.
1.4Business Value

This feature streamlines inventory management by providing a single source of truth for franchise procurement. By digitizing the workflow, it reduces manual errors in order tracking, ensures that stock levels are accurately updated upon receipt, and provides clear accountability through recorded timestamps and user tracking. This ultimately helps franchise owners maintain better control over their supply chain and financial reporting.

2.  Logic
2.1Overview

The Franchise Purchase Order feature provides a centralized view for managing inventory procurement. It allows users to view the full details of a purchase order, including header information (such as supplier details, dates, and financial totals) and a breakdown of the specific items being ordered. The system automatically adjusts the page display based on the current status of the order to ensure users only interact with relevant information.

2.2Step-by-Step Flow
1.Data Retrieval: When a user opens a specific purchase order, the system simultaneously fetches the order header (general information) and the list of line items (the products being ordered).
2.Header Mapping: The system maps the retrieved order data to the corresponding fields on the screen, such as Document Number, Supplier Name, Due Date, and financial summaries like Subtotal and Tax.
3.Item Mapping: The system populates the product table by mapping item details—such as SKU, Product Name, Order Quantity, and pricing—into the appropriate columns.
4.Status Validation: The system checks the "workflow state" of the order.
5.UI Rendering:

* If the order is marked as "placed," the page displays the full details and item list, ready for processing.

* If the order is in any other state, the system hides the item list and displays a "Not awaiting receipt" message to prevent unnecessary actions.

2.3Key Concepts
–Workflow State: A status indicator that determines whether an order is ready for receipt or if it is in a different stage of the procurement process.
–Header Details: The high-level summary of the purchase order, including administrative data (who created it), dates, and total financial values.
–Line Items: The individual products included in the purchase order, displayed in a table format with specific quantities and pricing per item.
–Empty State: A user-friendly interface view that appears when an order does not meet the criteria for further action, preventing user confusion.
2.4Business Value

This feature streamlines inventory management by providing a clear, consistent view of franchise purchase orders. By automatically filtering the display based on the order's status, the system reduces manual errors and ensures that staff only focus on orders that are ready for receipt. This improves operational efficiency and provides better visibility into procurement costs and supplier commitments.

3.  Data
3.1Overview

The Franchise Purchase Order feature provides a comprehensive view of procurement documents within the Lumi ERP system. It allows users to view both the high-level summary of a purchase order (such as dates, supplier information, and financial totals) and the specific list of items included in that order. This ensures that franchise managers and staff have clear visibility into their ordering process, from creation through to final receipt.

3.2Step-by-Step Flow
1.Load Order Summary: When a user selects a specific purchase order, the system retrieves the header information, including document references, supplier details, store location, and financial totals (subtotals, taxes, and final amounts).
2.Display Header Details: The system maps this information to the "Details" view, providing a clear summary of the order's status, timeline, and financial breakdown.
3.Load Line Items: The system retrieves the list of products associated with the order. This list is organized by line number to ensure the order of items is preserved.
4.Display Item Table: The system populates a table with the item details, including product names, codes, quantities ordered versus received, pricing, and any applicable discounts.
3.3Key Concepts
–Purchase Order Header: The top-level information for an order, containing administrative data like dates, supplier names, and overall financial totals.
–Line Items: The individual products or services included within a single purchase order, detailing specific quantities and costs per item.
–Financial Breakdown: A clear view of the order's costs, including subtotals, discounts, tax calculations, and the final total amount.
–Order Tracking: The ability to see key milestones such as when an order was created, placed, and received, as well as the due date.
3.4Business Value
–Operational Transparency: Provides staff with an immediate, accurate view of what was ordered, where it is being delivered, and the current status of the shipment.
–Financial Accuracy: By clearly separating subtotals, discounts, and taxes, the system reduces errors in procurement accounting and helps users verify that invoices match the original order.
–Improved Efficiency: Centralizing all order details and itemized lists in one view saves time for franchise staff, allowing them to quickly resolve discrepancies between ordered and received goods.
