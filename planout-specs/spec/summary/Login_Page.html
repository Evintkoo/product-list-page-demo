1.  Frontend
1.1Overview

The Login Page is the secure entry point for the Lumi ERP system. It is designed to provide a clean, user-friendly interface that verifies user credentials and ensures that only authorized personnel can access the product management dashboard. The page includes proactive validation to help users identify account issues quickly and automatically redirects logged-in users to their workspace to save time.

1.2Step-by-Step Flow
1.Automatic Session Check: When the page loads, the system automatically checks if the user is already signed in. If a valid session is detected, the user is immediately taken to the Product List page.
2.User Identification: The user enters their email address. As they type, the system checks in real-time if the email exists in our records. If the email is not found, an error message appears to alert the user.
3.Credential Entry: The user enters their password in a masked field to ensure privacy.
4.Authentication: Upon clicking the "Login" button, the system verifies the provided email and password.
5.Access Granted: If the credentials are correct, the system grants access and redirects the user to the Product List page.
1.3Key Concepts
–Session Persistence: The ability of the system to remember a user, allowing them to bypass the login screen if they have already authenticated recently.
–Real-time Validation: A feature that checks the validity of the email address while the user is still typing, providing immediate feedback rather than waiting until the form is submitted.
–Masked Input: A security standard for password fields where characters are hidden (usually as dots or asterisks) to prevent others from seeing the password as it is typed.
–Redirect: An automated action that moves the user to a different page (the Product List) once a specific condition, such as a successful login, is met.
1.4Business Value
–Improved User Experience: By automatically redirecting active users and providing real-time feedback on email entry, we reduce friction and help users get to their work faster.
–Enhanced Security: Masked password fields and server-side authentication ensure that sensitive account information remains protected.
–Operational Efficiency: The clear, focused interface minimizes login errors, reducing the number of support inquiries related to account access and authentication.
2.  Logic
2.1Overview

The Login Page feature provides a secure entry point for users to access the Lumi ERP system. It is designed to be intuitive, ensuring that users are only prompted to log in when necessary, while providing immediate feedback if their account information is incorrect. The system also includes a proactive check to see if a user is already logged in, automatically directing them to their workspace if they have an active session.

2.2Step-by-Step Flow
1.Automatic Session Check: When the login page loads, the system automatically checks if you are already logged in. If you have an active session, you are immediately taken to the Product List page.
2.Email Verification: As you enter your email address, the system checks in the background to confirm that the email exists in our records. If the format is incorrect or the email is not found, you will be notified.
3.Login Attempt: Once you enter your password and click the "Login" button, the system verifies your credentials.
4.Authentication & Access: If the email and password match our records, the system securely saves your session and redirects you to the Product List page.
5.Error Handling: If the credentials do not match or are missing, the system will display an error message, preventing unauthorized access.
2.3Key Concepts
–Session Token: A secure digital "key" provided to your browser after a successful login, which allows you to stay logged in without re-entering your password for a set period.
–Credential Verification: The process of comparing your entered password against the securely stored version in our system to ensure your identity is confirmed without ever exposing your actual password.
–Client-Side Validation: Immediate checks performed by the login page to ensure that required fields (like email and password) are filled out correctly before the information is even sent to our servers.
2.4Business Value
–Improved User Experience: By automatically detecting active sessions, returning users can jump straight into their work without unnecessary login steps.
–Enhanced Security: By using secure hashing for passwords and validating credentials on the server side, we ensure that user data remains protected against unauthorized access.
–Reduced Friction: Real-time email validation helps users identify typos or registration issues immediately, preventing frustration during the login process.
3.  Data
3.1Overview

The login feature for the Lumi ERP system provides a secure way for users to access their accounts and maintain their logged-in status. It handles the initial verification of credentials and manages ongoing access sessions to ensure that only authorized users can view the product list.

3.2Step-by-Step Flow
1.User Login: The user enters their email and password. The system verifies these credentials against our records.
2.Session Creation: If the credentials are correct, the system generates a secure digital "key" (session token) that identifies the user for the next 24 hours.
3.Access Grant: This key is stored in the user's browser, allowing them to navigate to the Product List page.
4.Automatic Verification: Whenever the user refreshes the page or returns to the site, the system automatically checks for this valid key to confirm the user is still logged in.
5.Session Expiration: If the key is missing or has expired (after 24 hours), the system will require the user to log in again to ensure account security.
3.3Key Concepts
–Authentication: The process of confirming that the email and password provided match an existing user account in our system.
–Session: A temporary, secure connection that keeps a user logged in so they don't have to re-enter their password every time they click a new page.
–Session Token: A unique, encrypted identifier used by the system to recognize a specific user's active session.
–Expiration: A security measure that automatically ends a session after 24 hours, requiring the user to re-authenticate to maintain access.
3.4Business Value
–Security: By validating credentials and using time-limited session tokens, we protect sensitive business data from unauthorized access.
–User Experience: The system remembers the user, allowing for a seamless transition between pages without the frustration of repeated logins.
–Reliability: The automated check on page load ensures that users are always directed to the correct area of the application based on their current login status.
