1.  Frontend
1.1Overview

The "Stock Outgoing Form Card" is the primary header component used when initiating a new stock outgoing document in the Lumi ERP system. This form captures essential administrative details—such as the origin of the stock, relevant dates, and associated work orders—to ensure that outgoing inventory is tracked accurately from the moment the process begins.

1.2Step-by-Step Flow
1.Document Identification: The system displays a read-only document number field. This is automatically generated by the server upon saving, so no manual entry is required.
2.Select Source Location: The user selects the origin (store or warehouse) from a required dropdown menu. This selection is critical, as it determines the available stock and costs for the rest of the document.
3.Set Administrative Details: The user may optionally enter a due date and a custom reference number for their own internal tracking.
4.Link Work Orders: Once a source location is selected, the user can search for and attach one or more service work orders. The system will only suggest work orders that are associated with the chosen source location.
5.Add Notes: The user can provide additional context or instructions in the optional notes field, which remains editable even after the initial form submission.
1.3Key Concepts
–Source Location: The specific store or warehouse from which inventory is being removed. This is the only mandatory field, as it acts as the "anchor" for all subsequent data.
–Work Order Picker: A smart search tool that filters available work orders based on the selected source location, ensuring that only relevant tasks can be linked to the outgoing stock.
–Validation: The system enforces data integrity by requiring the source location before allowing the user to search for work orders, preventing mismatched data.
–Auto-Generation: The system handles document numbering automatically, reducing manual data entry errors and ensuring consistent record-keeping.
1.4Business Value
–Data Accuracy: By requiring the source location first, the system ensures that inventory and cost calculations are always tied to the correct physical location.
–Operational Efficiency: The smart search for work orders saves time by filtering out irrelevant data, allowing staff to quickly link outgoing stock to specific service tasks.
–Improved Traceability: The combination of reference numbers, due dates, and notes provides a clear audit trail, making it easier for management to track why and when stock was moved.
