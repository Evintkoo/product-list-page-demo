1.  Logic
1.1Overview

This feature provides a dedicated way for the Lumi ERP system to retrieve a list of sales specifically generated through your ecommerce channels. It allows users to pull sales data in a controlled, paginated format, ensuring that only relevant ecommerce transactions are returned. The system includes built-in security checks and error handling to ensure data integrity and authorized access.

1.2Step-by-Step Flow
1.Security Verification: The system first checks if the user has an active, valid session. If the session is missing or invalid, the request is rejected.
2.Parameter Processing: The system collects your search criteria (such as specific customer IDs or sale statuses). If you do not specify how many records to return or where to start, the system automatically defaults to showing the 20 most recent sales.
3.Data Retrieval: The system filters the database to include only sales marked as "ecommerce." It then applies your specific filters and sorts the results by the date they were created, showing the newest sales first.
4.Response Delivery:

* If successful, the system returns the requested list of sales, including details like the sale amount, currency, status, and customer information.

* If the request contains invalid information (such as a malformed ID), the system returns a "Bad Request" error.

* If an unexpected system error occurs, the system returns a general server error message.

1.3Key Concepts
–Pagination: A method of breaking large lists of data into smaller, manageable chunks (using "limit" and "offset") to improve performance and readability.
–Filtering: The ability to narrow down the list of sales by specific criteria, such as a particular customer or the current status of an order.
–Session Validation: A security gate that ensures only authenticated users can access the sales data.
–Source Scoping: An internal rule that automatically restricts the search to "ecommerce" sales, preventing other types of sales data from appearing in these results.
1.4Business Value

This feature enables your team to programmatically access ecommerce sales data directly within the ERP. By providing a standardized, filterable list, it simplifies reporting and order management workflows. The inclusion of pagination and default sorting ensures that the system remains fast and responsive, even as your volume of ecommerce transactions grows, while the built-in security ensures that sensitive sales data remains protected.

2.  Data
2.1Overview

The `GET /api/sales/ecommerce` feature provides a dedicated way to retrieve sales data specifically generated through your e-commerce channels. This tool allows users to pull a list of transactions, apply specific filters to narrow down the results, and view the data in a clean, organized format. It is designed to be consistent with existing sales reporting tools within the Lumi ERP system.

2.2Step-by-Step Flow
1.Request Initiation: The system receives a request to list e-commerce sales.
2.Data Scoping: The system automatically filters the database to include only records marked as "ecommerce."
3.Applying Filters: If provided, the system applies optional filters for a specific date range (start and end dates) and transaction status.
4.Sorting and Pagination: The system organizes the results by date (newest first). By default, it displays 20 records at a time, starting from the first record, unless different limits or offsets are requested.
5.Data Formatting: The raw database information is transformed into a standardized, easy-to-read format containing key details like the sale amount, currency, status, and customer ID.
6.Response: The final list is delivered to the user.
2.3Key Concepts
–Pagination: A method of breaking a large list of data into smaller, manageable pages (defaulting to 20 items) to ensure the system remains fast and responsive.
–Filtering: The ability to narrow down search results based on specific criteria, such as a date range or the current status of a sale.
–Sorting: The automatic arrangement of data in a specific order; in this case, the most recent sales appear at the top of the list.
–Data Mapping: The process of taking raw internal data and converting it into a clean, consistent structure that is ready for display or use by other applications.
2.4Business Value

This feature enables the sales and operations teams to gain clear visibility into e-commerce performance without manual data extraction. By providing a standardized, filterable list, users can quickly track revenue, monitor order statuses, and perform audits on e-commerce activity. The consistent design ensures that teams familiar with other sales reporting tools in the Lumi ERP can use this feature immediately with no additional training.
