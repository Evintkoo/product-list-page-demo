1.  Logic
1.1Overview

This feature provides a secure way to add new products to the Lumi ERP system. By sending product details—such as the unique identifier (SKU), name, description, and price—to this endpoint, the system automatically registers the item, assigns it a unique ID, and records the creation time. The process includes built-in safeguards to ensure that only authorized users can add products and that no duplicate items are created.

1.2Step-by-Step Flow
1.Authentication: The system verifies that the person attempting to add a product is currently signed in. If not, the request is rejected.
2.Validation: The system checks the provided information to ensure all mandatory fields (SKU, name, and price) are included. If any are missing, the request is rejected.
3.Duplicate Check: The system searches the database to ensure no other product already uses the same SKU. If a match is found, the request is rejected to prevent duplicates.
4.Record Creation: If all checks pass, the system generates a unique ID and timestamps for the product, saves the information to the database, and confirms the successful creation of the record.
1.3Key Concepts
–SKU (Stock Keeping Unit): A unique code used to identify a specific product in your inventory.
–Authentication: The security step that confirms the user has permission to perform the action.
–Validation: The process of ensuring the data provided is complete and formatted correctly before it is saved.
–Duplicate Prevention: A safety mechanism that stops the system from creating two different products with the same unique identifier.
1.4Business Value

This feature streamlines inventory management by providing a reliable, automated way to ingest product data into the Lumi ERP. By enforcing data quality (via validation) and preventing errors (via duplicate checks), it ensures that your product catalog remains accurate and organized. Furthermore, the automated handling of IDs and timestamps reduces manual data entry, saving time and minimizing the risk of human error.

2.  Data
2.1Overview

The "Create Product" feature allows authorized users to add new items to the Lumi ERP system. When a user submits product details, the system automatically handles the assignment of unique identifiers and timestamps, ensuring that the data is consistent and accurate without requiring manual input for these fields.

2.2Step-by-Step Flow
1.Validation: The system checks the incoming request to ensure that essential information, specifically the SKU (Stock Keeping Unit) and the product name, is provided. If these are missing, the request is rejected.
2.Uniqueness Check: The system searches the database to verify that the provided SKU is not already in use. If a match is found, the system prevents the creation of a duplicate record.
3.Data Preparation: If the validation and uniqueness checks pass, the system automatically generates a unique ID for the product and records the current date and time for both the creation and update timestamps.
4.Persistence: The new product information is saved into the database.
5.Confirmation: Upon successful saving, the system returns the complete product record to the user to confirm the action was successful.
2.3Key Concepts
–SKU (Stock Keeping Unit): A unique identifier used to track individual products in the inventory.
–Validation: The process of ensuring that the data submitted by the user meets the minimum requirements before the system attempts to process it.
–Uniqueness Constraint: A safeguard that prevents the system from creating two different products with the same SKU, which helps maintain data integrity.
–Automated Metadata: Information such as unique IDs and timestamps that the system generates internally, removing the burden from the user and ensuring consistency.
2.4Business Value

This feature streamlines inventory management by providing a reliable and standardized way to add new products to the ERP. By automating ID generation and timestamping, it reduces the risk of human error. Furthermore, the built-in validation and duplicate-checking mechanisms ensure that the product catalog remains clean, organized, and free of conflicting data, which is essential for accurate reporting and sales operations.
