1.  Frontend
1.1Overview

The Stock Return List page is a centralized dashboard within the Lumi ERP system that allows users to view, filter, and manage inventory returns sent to warehouses. It provides a clear overview of return statuses and key details, ensuring that inventory movements are tracked accurately from the store to the warehouse.

1.2Step-by-Step Flow
1.Access & Authentication: When you navigate to the page, the system verifies your credentials. If you are not logged in, you will be redirected to the login screen.
2.Initial Data Load: Once authenticated, the system automatically retrieves and displays the current list of stock returns, along with the available lists of stores and warehouses.
3.Filtering: You can narrow down the list of returns using several criteria:

* Reference Code: Search by a specific return ID.

* Warehouse/Store: Select specific locations to view relevant returns.

* Date Range: Use the "From" and "To" date pickers to view returns within a specific timeframe.

* Status: Filter by the current stage of the return (e.g., Draft, Confirmed, Sent, Approval, or Cancelled).

4.Validation: If you enter a "From Date" that is later than the "To Date," the system will display an alert to correct the range before searching.
5.Search Execution: Clicking the search button updates the table to show only the records matching your selected filters.
6.Navigation: You can switch between the "Warehouse" view (current page) and the "Franchisee" view, or click "New Stock Order" to start a new return process.
1.3Key Concepts
–Reference Code: A unique, system-generated identifier for every stock return, used for easy tracking and auditing.
–Workflow State: The current stage of a return process. This helps users identify if a return is still being prepared (Draft), waiting for review (Approval), or completed (Sent/Confirmed).
–Date Range Validation: A safety feature that ensures search criteria are logical, preventing errors caused by selecting an end date that occurs before a start date.
–Inventory Tabs: A navigation tool that allows users to toggle between different types of return lists (Warehouse vs. Franchisee) without leaving the inventory module.
1.4Business Value

This feature streamlines inventory management by providing a single source of truth for all stock returns. By offering robust filtering and clear status tracking, it reduces the time spent searching for specific records and helps staff quickly identify which returns require attention or approval. This visibility minimizes the risk of lost inventory and ensures that the return process remains organized and accountable.

2.  Logic
2.1Overview

The Stock Returns List Page provides a centralized view for tracking inventory items being returned from stores to warehouses. This feature allows users to view a comprehensive list of return records, filter them by specific criteria, and monitor their progress through the approval workflow.

2.2Step-by-Step Flow
1.Authentication Check: When a user navigates to the page, the system verifies their login status. If the user is not logged in, they are automatically redirected to the login screen.
2.Initial Data Load: Once authenticated, the system automatically retrieves and displays the full list of stock returns.
3.Filter Selection: Users can refine the list using various filters, including reference codes, specific stores, warehouses, date ranges, or current workflow statuses.
4.Validation: When applying a date range, the system ensures the "From Date" is not later than the "To Date." If the dates are invalid, an alert notifies the user to correct the selection.
5.Search Execution: Upon clicking the search button, the system fetches the filtered data and updates the table. If no records match the selected criteria, the table remains empty while keeping the headers visible.
6.Data Display: The system maps the retrieved information into clear columns, including the return reference code, relevant dates (creation, sent, and approval), store and warehouse names, current status, and the user who created the record.
2.3Key Concepts
–Stock Return: A unique record representing inventory being moved back from a store to a warehouse.
–Workflow State: The current stage of a return (e.g., draft, sent, or approved), which helps users track the progress of the return process.
–Reference Code: A unique identifier assigned to each stock return for easy tracking and lookup.
–Filter Criteria: Tools provided to narrow down the list, such as date ranges and location selectors, to help users find specific records quickly.
2.4Business Value
–Operational Efficiency: By providing a searchable, filtered list, staff can quickly locate specific return records without manually scanning through all inventory data.
–Improved Accountability: The inclusion of "Created By" and specific timestamp fields (Sent/Approved) ensures full visibility into who initiated a return and when it reached its final status.
–Error Reduction: Built-in validation for date ranges prevents common user input errors, ensuring that search results are always accurate and relevant.
–Streamlined Workflow: Centralizing the status of returns allows managers to easily identify pending items that require approval, helping to keep inventory records up to date.
3.  Data
3.1Overview

The Stock Returns List page provides a centralized view for tracking inventory items being sent back from stores to a warehouse. This feature allows staff to monitor the lifecycle of a return, from its initial creation to its final approval, ensuring transparency and accountability throughout the return process.

3.2Step-by-Step Flow
1.Requesting the List: The system retrieves a list of all stock returns, organized by the date they were created, with the most recent entries appearing at the top.
2.Filtering and Pagination: Users can narrow down the list using specific filters, and the system displays the results in manageable pages to ensure the interface remains fast and easy to navigate.
3.Data Consolidation: The system gathers information from multiple sources—including the store of origin, the destination warehouse, and the user who initiated the request—to provide a complete summary for each return.
4.Displaying Details: The final list presents the return reference code, key dates (creation, shipment, and approval), the involved locations, the current status of the return, and the name of the staff member who created it.
3.3Key Concepts
–Stock Return: A formal record representing inventory being moved from a store back to a warehouse.
–Workflow State: The current status of a return (e.g., pending, sent, or approved), which helps track where the item is in the process.
–Reference Code: A unique identifier assigned to each return, making it easy to search for or discuss specific transactions.
–Pagination: A method of breaking a large list of records into smaller, readable pages to improve system performance and user experience.
3.4Business Value

This feature improves inventory accuracy by providing clear visibility into the movement of goods. By tracking exactly when a return was initiated, sent, and approved, management can identify bottlenecks in the supply chain, reduce the risk of lost inventory, and maintain a clear audit trail of who is responsible for each return transaction.
