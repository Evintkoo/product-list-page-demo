1.  Frontend
1.1Overview

The "New Stock Order Warehouse" page is a dedicated interface within the Lumi ERP system designed to help staff create and manage requests for moving stock from a warehouse to a specific store. This feature streamlines the ordering process by allowing users to input order details, select products, and specify quantities in a single, organized workflow.

1.2Step-by-Step Flow
1.Navigation: The user accesses the page via the main menu by selecting the "Inventory" module and ensuring the "Store" tab is active.
2.Order Details Entry: The user fills out the primary order information, including the source warehouse, the destination store, a reference code, the requested delivery date, and any additional notes.
3.Product Selection: The user adds products to the order. For each product, they specify the current store quantity, the amount they wish to order, and any relevant remarks. The system automatically displays the company’s average cost for each item.
4.Submission: Once the form is complete, the user clicks "Save." The system validates the information and submits the order to the inventory database.
5.Completion: Upon a successful save, the user is automatically redirected back to the main Stock Order List page.
6.Cancellation: If the user decides not to proceed, they can click "Cancel" at any time to discard their changes and return to the Stock Order List page.
1.3Key Concepts
–Stock Order: A formal request to transfer inventory items from a central warehouse to a retail store location.
–Workflow State: The current status of the order; new orders begin as a "draft" until they are finalized and submitted.
–Reference Code: A unique identifier or tracking number assigned to the order for easy searching and record-keeping.
–Company Average Cost: A read-only value provided by the system that shows the standard cost of an item, helping users understand the financial impact of the order.
1.4Business Value
–Operational Efficiency: By centralizing the order entry process, staff can quickly generate stock requests without navigating multiple screens.
–Data Accuracy: Standardized forms and required fields ensure that all necessary information—such as delivery dates and specific quantities—is captured correctly before an order is processed.
–Improved Inventory Control: Providing visibility into current store quantities and average costs allows for more informed decision-making, helping to prevent overstocking or stockouts at the store level.
2.  Logic
2.1Overview

The "New Stock Order Warehouse" feature allows users to create and submit requests to move inventory from a central warehouse to a specific store. This feature streamlines the ordering process by capturing all necessary logistical details—such as the source warehouse, destination store, delivery deadlines, and specific product quantities—into a single, organized digital order.

2.2Step-by-Step Flow
1.Data Entry: The user fills out the "New Order Warehouse" form with general information, such as the source warehouse, destination store, reference codes, due dates, and any relevant notes.
2.Product Selection: The user adds specific items to the order, detailing the product, the quantity currently held at the store, the quantity being ordered, and any specific remarks for each item.
3.Submission: Once the user clicks the "Save" button, the system automatically gathers all the information from the form and the product list.
4.Validation and Processing: The system checks the data to ensure it meets all requirements. If valid, it saves the order to the system.
5.Confirmation: Upon a successful save, the user is automatically redirected to the main Stock Order List page to view the status of their newly created order.
2.3Key Concepts
–Stock Order Header: The primary information for the request, including the "who, where, and when" (e.g., source warehouse, destination store, and due date).
–Line Items: The specific list of products included in the order, along with their respective quantities and costs.
–Workflow State: The current status of the order within the system (e.g., draft, pending, or approved).
–Reference Code: A unique identifier or document number used to track the order for easy searching and auditing.
2.4Business Value
–Operational Efficiency: By centralizing the ordering process, staff can quickly request stock without manual paperwork, reducing the time spent on administrative tasks.
–Accuracy: Standardized forms ensure that all necessary information—such as product quantities and delivery deadlines—is captured correctly before an order is processed, minimizing errors.
–Improved Inventory Visibility: Because the system tracks the movement of goods from the warehouse to the store, managers gain better insight into stock levels and replenishment needs across all locations.
3.  Data
3.1Overview

The New Stock Order Warehouse feature allows users to create and submit a formal request to move inventory from a central warehouse to a specific store. This process captures all necessary details—such as which products are needed, the quantities required, and the expected delivery timeline—ensuring that inventory replenishment is tracked accurately within the Lumi ERP system.

3.2Step-by-Step Flow
1.Initiation: The system begins the process of recording a new stock order request.
2.Order Header Creation: The system saves the primary order information, including the source warehouse, the destination store, a unique reference code, the requested due date, and any additional notes.
3.Itemized Entry: The system processes the list of products included in the order. For each product, it records the specific quantity requested, the current stock level at the store, the average cost of the item, and any specific remarks provided by the store.
4.Finalization: Once all items are successfully recorded, the system confirms the order, making it available for fulfillment.
3.3Key Concepts
–Stock Order: A formal document that tracks the movement of goods from a warehouse to a retail store.
–Warehouse: The central storage location where inventory is held before being distributed to stores.
–Store: The retail location receiving the inventory.
–Line Item: An individual entry within a stock order that specifies a particular product and the quantity requested for that item.
–Reference Code: A unique identifier assigned to each order to make it easy to search for and track throughout the fulfillment process.
3.4Business Value

This feature streamlines the replenishment process by providing a standardized way for stores to request stock. By capturing both the requested quantity and the store's current stock levels, the system enables better inventory visibility and data-driven decision-making. This reduces manual errors, ensures that warehouses have clear instructions for picking and packing, and helps maintain optimal stock levels across all retail locations.
