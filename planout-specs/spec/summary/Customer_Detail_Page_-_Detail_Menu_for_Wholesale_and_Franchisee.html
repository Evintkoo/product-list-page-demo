1.  Frontend
1.1Overview

The Customer Detail Menu is a navigation component designed for Wholesale and Franchisee customer profiles within the Lumi ERP system. It provides a consistent sidebar that allows users to quickly switch between different information categories—such as billing, products, and history—without leaving the customer's profile page.

1.2Step-by-Step Flow
1.Initialization: When a user opens a customer profile, the system identifies the current page and automatically highlights the corresponding menu item.
2.User Interaction: The user selects a category from the navigation list (e.g., "Addresses" or "History").
3.State Update: The system updates the visual "active" state of the menu to show the user which section they are currently viewing.
4.Navigation: The system instantly routes the user to the specific detail page associated with the selected menu item.
1.3Key Concepts
–Active State: A visual indicator (such as highlighting) that tells the user which section of the customer profile they are currently viewing.
–Routing: The mechanism that ensures clicking a menu item takes the user to the correct, relevant page within the ERP.
–Navigation Menu: A centralized list of links that acts as the primary way to move between different data views for a specific customer.
1.4Business Value
–Improved Efficiency: Users can navigate between complex customer data points (like billing and product history) in a single click, reducing the time spent searching for information.
–Consistent User Experience: By standardizing the navigation across all Wholesale and Franchisee profiles, the system ensures that staff can easily find the information they need, regardless of which customer they are managing.
–Reduced Errors: Clear visual feedback on the "active" section helps prevent users from accidentally entering data into the wrong category.
