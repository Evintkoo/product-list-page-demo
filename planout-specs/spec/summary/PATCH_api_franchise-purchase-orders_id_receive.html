1.  Logic
1.1Overview

This feature allows authorized staff (Admins or Managers) to confirm the receipt of goods for a franchise purchase order. When a franchise receives a shipment, this process updates the order status to "received" and automatically records the incoming stock into the inventory system for each item listed.

1.2Step-by-Step Flow
1.Security Check: The system verifies that the user is logged in and holds the necessary administrative or managerial permissions to perform this action.
2.Order Verification: The system locates the specific purchase order and ensures it is currently in the "placed" state. If the order has already been processed or does not exist, the request is rejected.
3.Input Validation: The system checks the provided list of items to ensure there are no duplicate entries and that the quantity being received does not exceed the quantity originally ordered.
4.Inventory Update: The system performs a secure, all-or-nothing update. It records the received quantity for each item and creates an official inventory movement log to reflect the new stock levels.
5.Finalization: Once all items are processed successfully, the purchase order status is updated to "store_received," and the system confirms the successful completion of the transaction.
1.3Key Concepts
–Atomic Transaction: A safety mechanism that ensures all parts of the update (updating the order status and recording inventory movements) happen together. If any part of the process fails, the entire operation is canceled to prevent data errors.
–Franchise Workflow State: A status tracker that ensures purchase orders move through the system in the correct sequence (e.g., an order must be "placed" before it can be "received").
–Inventory Movement: A digital record created whenever stock levels change, providing an audit trail of how and when products were added to the franchise's inventory.
1.4Business Value

This feature streamlines the franchise supply chain by automating the transition from "ordered" to "received." By integrating inventory updates directly into the receipt process, it eliminates manual data entry, reduces the risk of human error, and ensures that franchise stock levels are always accurate and up-to-date immediately upon delivery.

2.  Data
2.1Overview

This feature allows franchise staff to officially "receive" a purchase order that has been placed. When a user marks an order as received, the system updates the order's status and automatically records the incoming stock into the franchise's inventory records. This ensures that the digital inventory levels accurately reflect the physical goods that have arrived at the store.

2.2Step-by-Step Flow
1.Validation: The system verifies that the user has the correct permissions and that the purchase order exists and belongs to their franchise.
2.Status Check: The system confirms the order is currently in the "placed" state. If the order has already been processed or is in a different state, the request is rejected to prevent duplicate entries.
3.Quantity Verification: The system checks that the received quantities do not exceed the amounts originally ordered.
4.Order Update: The system updates the purchase order status to "store_received."
5.Inventory Recording: For every item in the order, the system updates the received quantity and creates an inventory movement record, which increases the franchise's stock levels for those specific products.
6.Finalization: These updates happen as a single, unified action; if any part of the process fails, none of the changes are saved, ensuring data consistency.
2.3Key Concepts
–Purchase Order: A formal request for goods sent by a franchise to a supplier.
–Inventory Movement: A digital log entry that tracks changes in stock levels (in this case, an increase due to a delivery).
–Atomic Transaction: A safety mechanism that ensures all parts of an update (status change and inventory recording) succeed together or fail together, preventing partial or incorrect data.
–Workflow State: The current stage of an order (e.g., "placed" vs. "store_received"), which dictates what actions can be performed on it.
2.4Business Value
–Accuracy: By automating the creation of inventory movements, the system eliminates manual data entry errors, ensuring that store inventory levels are always up-to-date.
–Operational Control: The system prevents common mistakes, such as receiving more items than were ordered or processing the same delivery twice.
–Auditability: Every receipt of goods is automatically logged, providing a clear history of when and how much stock was added to the franchise's inventory.
