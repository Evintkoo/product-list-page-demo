1.  Data
1.1Overview

The "Supplier Edit" feature allows authorized users to update existing supplier information within the Lumi ERP system. This ensures that contact details, credit terms, and financial account mappings remain accurate and up-to-date. The system enforces strict data validation to ensure that essential information—such as the supplier's name and credit terms—is always provided.

1.2Step-by-Step Flow
1.Initiation: A user opens the "Edit Supplier" page and submits updated information for a specific supplier.
2.Validation: The system checks the submitted data against a predefined set of rules (the JSON Schema) to ensure all required fields are present and formatted correctly.
3.Security & Scoping: The system identifies the specific supplier using a unique ID and ensures the update is restricted to the user's current company.
4.Processing: The system updates the supplier record in the database, automatically recording which user performed the update.
5.Confirmation: Once the update is successful, the system returns the full, updated supplier record to confirm the changes were saved.
1.3Key Concepts
–JSON Schema: A set of rules that defines what information is required (e.g., name, address) and how it must be formatted (e.g., email addresses, numeric credit limits) before the system will accept an update.
–Data Scoping: A security measure that ensures users can only edit suppliers that belong to their own company, preventing unauthorized access or accidental cross-company data modification.
–Audit Trail: The system automatically tracks the "updaterid" (who made the change) and the "updatedat" timestamp, providing accountability for all modifications.
–Required Fields: Specific pieces of information, such as the supplier's name and credit terms, that must be provided for every supplier record to maintain operational integrity.
1.4Business Value
–Data Accuracy: By enforcing validation rules, the system prevents incomplete or incorrectly formatted data from entering the ERP, which reduces errors in procurement and accounting.
–Operational Efficiency: Users can quickly and reliably update supplier details, ensuring that financial and contact information is always current for daily operations.
–Security & Compliance: By scoping updates to the user's company and tracking who performed each update, the system maintains a secure and auditable record of all changes, which is essential for financial reporting and internal controls.
