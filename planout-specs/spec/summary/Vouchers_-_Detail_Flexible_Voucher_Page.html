1.  Frontend
1.1Overview

The "Detail Flexible Voucher" page provides a centralized view for staff to review the specific configuration of a flexible voucher product. This page acts as a read-only dashboard that pulls data from the system to display everything from pricing and validity periods to redemption locations and administrative audit logs. It ensures that staff have a clear, consistent understanding of how a voucher is structured before it is issued to a customer.

1.2Step-by-Step Flow
1.Navigation: The user accesses the page via the main menu (under the Products module) and the secondary product sub-menu.
2.Data Retrieval: Upon loading, the system automatically fetches the specific voucher record from the database using its unique identifier.
3.Loading State: While the data is being retrieved, the user sees a loading indicator to confirm the system is processing the request.
4.Display: Once the data is retrieved, the page populates a grid with all relevant voucher details, including its name, description, pricing, status, and audit information (such as who created it and when it was last updated).
5.Error Handling: If the voucher cannot be found or an error occurs, the system displays a clear message to the user.
6.Action: The user can click the "Edit" button at any time to navigate to the modification screen if changes are required.
1.3Key Concepts
–Flexible Voucher: A versatile voucher product that allows for custom pricing, specific redemption locations, and eligibility rules.
–Open Price: A setting that allows staff to define a custom value for the voucher at the point of sale, rather than being restricted to a pre-set amount.
–Audit Fields: Automatically generated data points (Created By, Created At, Updated By, Updated At) that track the history and management of the voucher record.
–Redemption Logic: Rules governing where a voucher can be used (Location Fields) and when it is valid (Expiry and Valid From/Until fields).
–Membership Restriction: An optional setting that limits the use of a voucher to specific customer loyalty groups or membership tiers.
1.4Business Value

This feature improves operational efficiency by providing a single source of truth for voucher details. By clearly displaying complex rules—such as the difference between the price paid and the redemption value, or specific location restrictions—it reduces the risk of errors during the sales process. Furthermore, the inclusion of audit logs ensures accountability and transparency, allowing managers to easily track who created or modified voucher configurations.

2.  Logic
2.1Overview

The "Detail Flexible Voucher Page" feature allows users to view comprehensive information about a specific flexible voucher product. When a user navigates to the voucher details page, the system automatically retrieves the relevant data from our database and populates the screen with all necessary product attributes, such as pricing, validity periods, and status.

2.2Step-by-Step Flow
1.Page Initialization: When a user opens the voucher details page, the system identifies the specific voucher ID.
2.Data Retrieval: The system sends a request to the server to fetch all stored information associated with that unique voucher ID.
3.Data Validation: The system confirms that the data has been successfully retrieved from the server.
4.Field Population: The system maps the retrieved information into the corresponding fields on the screen (such as the voucher name, description, base value, and status).
5.Display: The page renders the complete voucher profile for the user to review.
2.3Key Concepts
–Flexible Voucher: A versatile voucher product type within the Lumi ERP system that can be configured with specific values, validity dates, and usage rules.
–Data Mapping: The process of taking raw information from our database and placing it into the correct, labeled fields on the user interface so it is easy to read.
–Voucher ID: A unique identifier used by the system to ensure that the correct voucher details are displayed when a user selects a specific product.
2.4Business Value

This feature provides a centralized and reliable way for staff to verify the details of flexible vouchers. By automating the display of product information—including pricing, location rules, and validity—the system reduces manual lookup time, minimizes the risk of human error, and ensures that customer-facing voucher information is always consistent with the backend records.

3.  Data
3.1Overview

The "Detail Flexible Voucher Page" feature allows users to view comprehensive information about a specific flexible voucher product within the Lumi ERP system. This page acts as a dedicated information hub, ensuring that staff can quickly access the details, status, and monetary value of any flexible voucher by its unique identifier.

3.2Step-by-Step Flow
1.Request Initiation: The system receives a request to view a specific voucher using its unique ID.
2.Data Retrieval: The system searches the database for a record that matches the provided ID and confirms that the product is categorized as a "flexible" voucher.
3.Validation: If the system cannot find a matching flexible voucher, it triggers an error message to notify the user that the product does not exist or is not a flexible type.
4.Data Formatting: Once the record is found, the system organizes the raw data into a clear, readable format, grouping the monetary amount and currency together.
5.Display: The finalized voucher details are presented to the user.
3.3Key Concepts
–Flexible Voucher: A specific type of product within the ERP that allows for variable usage or value, distinct from standard fixed-value products.
–Unique Identifier (ID): A specific code assigned to each voucher that ensures the system retrieves the exact product requested.
–Data Mapping: The process of taking raw system information and organizing it into a user-friendly structure for the screen.
3.4Business Value

This feature provides a reliable and efficient way to manage flexible voucher inventory. By centralizing the details of these products, the system reduces manual lookup time and prevents errors by ensuring that only valid, flexible vouchers are displayed. This clarity helps staff manage product offerings accurately and improves the overall efficiency of the voucher management process.
