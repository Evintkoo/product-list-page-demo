1.  Frontend
1.1Overview

The Stock Opname Product Form is a user-friendly interface designed to help staff record physical inventory counts. It provides a flexible table where users can manually enter product details and their corresponding counted quantities. The feature also includes tools to manage the list efficiently, such as bulk uploading via files or printing blank forms for manual tallying on the warehouse floor.

1.2Step-by-Step Flow
1.Accessing the Form: Users view the "Products" section, which displays a table for entering inventory data.
2.Managing the List:
–Users can add new rows to the table as needed to accommodate different products.
–Users can remove any row from the list by clicking the delete button.
–Users can utilize the "Upload Manager" to import product lists or the "Print Blank Form" button to generate physical sheets for manual counting.
3.Data Entry: For each row, the user inputs the product identifier (SKU, code, or name) and the counted quantity.
4.Validation: The system automatically checks that the entered quantity is a valid, non-negative number. If an invalid number is entered, the system highlights the field to alert the user.
5.Submission: Once the list is complete, the system processes the entries and saves the counted stock data to the inventory records.
1.3Key Concepts
–Stock Opname: The process of physically counting and verifying the actual stock levels currently held in the warehouse.
–Product Identifier: A unique reference (such as a SKU, product code, or name) used to ensure the correct item is being recorded.
–Counted Quantity: The actual number of items found during the physical stock check.
–Validation: A built-in safety check that prevents errors by ensuring only logical, positive numbers are accepted for stock counts.
1.4Business Value
–Accuracy: By providing real-time validation, the system reduces human error during data entry, ensuring that inventory records match physical reality.
–Efficiency: The ability to upload files and print blank forms streamlines the workflow, saving time for warehouse staff during busy stock-taking periods.
–Flexibility: The dynamic row system allows users to scale the form to fit any size of inventory count, whether it is a small spot-check or a full warehouse audit.
2.  Logic
2.1Overview

The New Stock Opname Product Form Card is a feature designed to help staff accurately record physical inventory counts within the Lumi ERP system. This tool allows users to select a specific product and input the quantity they have physically counted, ensuring that the system's digital records match the actual stock on hand.

2.2Step-by-Step Flow
1.Data Entry: The user selects a product and enters the quantity they have physically counted.
2.Validation: The system checks the input to ensure a valid product is selected and that the quantity entered is a positive number.
3.Mapping: The system organizes the information into the required format for the inventory database.
4.Submission: The system sends the data to the inventory records.
5.Confirmation: The system confirms that the stock count has been successfully recorded or alerts the user if there was an issue with the submission.
2.3Key Concepts
–Stock Opname: The process of physically counting inventory items to verify that the actual stock matches the records in the system.
–Product ID: A unique identifier used to ensure the correct item is being updated in the inventory database.
–Counted Quantity: The specific number of items physically found during the stock check.
–Validation: A safety check performed by the system to prevent errors, such as entering negative numbers or missing product information, before the data is saved.
2.4Business Value

This feature streamlines the inventory reconciliation process by providing a simple, error-resistant interface for staff. By ensuring that physical counts are accurately captured and validated before they reach the database, the business can maintain high inventory accuracy, reduce discrepancies, and make better-informed purchasing and sales decisions.
