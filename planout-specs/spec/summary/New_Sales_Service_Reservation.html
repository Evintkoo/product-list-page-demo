1.  Frontend
1.1Overview

The New Sales Service Reservation feature provides a streamlined interface for staff to schedule vehicle service appointments within the Lumi ERP system. This form ensures that all critical information—such as the customer, vehicle, and service timing—is captured accurately before a reservation is finalized. The system also includes flexible options to add multiple service items and record additional administrative details.

1.2Step-by-Step Flow
1.Document Initialization: The system displays an auto-generated document number, which serves as the unique identifier for the reservation once saved.
2.Core Selection: The user selects the servicing store, the customer, and the specific vehicle from existing records. If a customer is not yet in the system, the user can trigger a quick action to add them.
3.Scheduling: The user enters the planned date and time for the service drop-off.
4.Vehicle Status: The user inputs the current odometer reading to ensure accurate vehicle history tracking.
5.Service Details: The user lists the specific services required. The system allows for multiple service items to be added dynamically as needed.
6.Optional Information: The user may optionally assign a service advisor or salesperson, note the booking source, and include any additional comments or instructions.
7.Validation and Submission: Upon clicking save, the system verifies that all required fields are completed. If valid, the reservation is submitted to the system.
1.3Key Concepts
–Required Fields: Essential data points (such as store, customer, vehicle, date, time, and odometer) that must be provided to successfully create a reservation.
–Dynamic Item List: A flexible table structure that allows users to add as many individual service descriptions as necessary for a single appointment.
–Auto-generated Document Number: A system-assigned reference code that ensures every reservation is uniquely tracked without manual input.
–Immediate Validation: A built-in check that provides instant feedback if a user misses a required field, preventing incomplete data from being saved.
1.4Business Value
–Data Integrity: By enforcing mandatory fields and validation, the system ensures that every reservation contains the necessary information for service teams to prepare effectively.
–Operational Efficiency: The ability to add new customers on the fly and dynamically add multiple service items reduces administrative friction during the booking process.
–Improved Tracking: Capturing odometer readings and specific service descriptions at the point of booking creates a reliable audit trail for vehicle maintenance history, which is critical for long-term customer service and vehicle resale value.
