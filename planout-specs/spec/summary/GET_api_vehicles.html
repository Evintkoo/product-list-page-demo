1.  Logic
1.1Overview

The `GET /api/vehicles` feature provides a flexible way for users to retrieve a list of vehicles from the system. It is designed to handle large datasets by allowing users to narrow down results using specific filters, date ranges, and a general search function. The system also supports custom sorting to ensure the most relevant information appears first.

1.2Step-by-Step Flow
1.Validation: The system checks the incoming request to ensure that any provided filters (such as vehicle type or date categories) use valid, supported values. If the input is invalid, the request is rejected.
2.Initialization: The system prepares to pull the full list of vehicles from the database.
3.Filtering: The system applies specific criteria provided by the user, such as matching a specific registration number, customer name, or store location.
4.Date Range Application: If a date range is requested, the system narrows the results to vehicles created or registered within the specified "from" and "to" dates.
5.General Search: If a general search term is provided, the system scans across registration numbers, hull numbers, VINs, and customer names to find partial matches.
6.Sorting: The system organizes the final list based on the user's preferred field (e.g., customer name) and order (ascending or descending). If no preference is given, it defaults to showing the most recently created vehicles first.
7.Execution: The system retrieves the filtered, sorted list and returns it to the user.
1.3Key Concepts
–Filtering: The ability to narrow down the vehicle list by specific attributes like vehicle type, store ID, or unique identifiers (VIN/FIN).
–Date Range Filtering: A feature that allows users to focus on vehicles based on their creation date or registration date within a specific timeframe.
–General Search: A "fuzzy" search capability that looks for a keyword across multiple fields simultaneously to help users find vehicles without knowing the exact identifier.
–Sorting: The process of arranging the output list in a specific order to improve readability and data management.
–Validation: A safety check that ensures the system only processes requests with recognized parameters, preventing errors and ensuring data integrity.
1.4Business Value

This feature empowers staff to manage fleet inventory efficiently by providing quick access to specific vehicle records. By offering robust search and filter capabilities, users can spend less time navigating through long lists and more time managing operations. The ability to sort and filter by date or customer also supports better reporting and auditing, ensuring that the right vehicle information is always available when needed.

2.  Data
2.1Overview

The Vehicle API provides a flexible way to retrieve a list of vehicles from the Lumi ERP system. It is designed to help users quickly find specific vehicles or groups of vehicles by allowing them to filter, search, and sort the data based on various criteria such as registration details, customer information, or specific timeframes.

2.2Step-by-Step Flow
1.Initialization: The system starts by accessing the complete list of vehicles stored in the database.
2.Type Filtering: If a specific vehicle type (e.g., Car, Motorcycle, or Heavy Equipment) is requested, the system narrows the list to only include that category.
3.Specific Filtering: The system applies any provided exact matches, such as a specific registration number, VIN, or store location.
4.Date Range Filtering: If a date range is provided, the system filters the results based on either the registration date or the creation date, depending on the user's preference.
5.General Search: If a general search term is entered, the system scans across key fields (like registration number, VIN, or customer name) to find partial matches.
6.Sorting: Finally, the system organizes the resulting list based on the user's preferred field and order (ascending or descending). If no preference is provided, it defaults to showing the most recently created vehicles first.
2.3Key Concepts
–Filtering: The ability to narrow down a large list of vehicles to a smaller, more relevant subset based on specific attributes.
–Date Range: A feature that allows users to isolate records created or registered within a specific window of time.
–General Search: A broad search function that looks for keywords across multiple descriptive fields simultaneously.
–Sorting: The process of arranging the final list in a specific order (e.g., alphabetical by customer or chronological by date) to make the data easier to read.
2.4Business Value

This feature empowers users to manage their fleet efficiently by reducing the time spent searching for specific assets. By providing robust filtering and sorting capabilities, the system ensures that staff can quickly access the exact vehicle information they need—whether they are looking for a single unit by its VIN or generating a report of all vehicles registered at a specific store within a certain month.
