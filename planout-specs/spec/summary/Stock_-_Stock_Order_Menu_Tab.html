1.1Overview

The Stock Order Menu is a centralized navigation component within the Lumi ERP system. It provides a clean, tabbed interface that allows users to quickly switch between different categories of stock orders. By organizing these categories into distinct views, the system ensures that users can efficiently manage inventory tasks relevant to their specific operational needs, such as warehouse management, retail sales, service requests, or internal work orders.

1.2Step-by-Step Flow
1.Navigation: The user interacts with the Stock Order Menu, which displays four primary tabs: Warehouse, Sales Retail, Service Orders, and Work Orders.
2.Selection: Clicking on a specific tab highlights that tab as "active" and immediately directs the user to the corresponding list view for that category.
3.Viewing Data: Once on a specific list page (e.g., Warehouse Stock Orders), the user can view existing records in a table format.
4.Initiating Action: On the Warehouse view, the user can click the "+ New Stock Order" button to open a data entry window.
5.Submission: Within the new order window, the user fills out the required information (such as order type and warehouse location). The system validates the input to ensure all fields are complete before saving the new order and closing the window.
1.3Key Concepts
–Tabbed Navigation: A user interface design that allows users to switch between different views or categories without leaving the main page, keeping the workspace organized.
–List View: A dedicated page that displays a collection of records, allowing users to monitor and manage their stock orders in one place.
–Primary Action Button: A prominent button (e.g., "+ New Stock Order") designed to help users quickly perform the most important task on a specific page.
–Form Validation: A safety feature that checks if all required information has been entered correctly before allowing the user to submit a new record, preventing incomplete or erroneous data.
1.4Business Value

This feature streamlines inventory management by reducing the time users spend searching for specific order types. By grouping related tasks into a single, intuitive menu, the system minimizes navigation complexity and improves user productivity. Furthermore, the standardized creation process ensures that all new stock orders are captured with the necessary information, leading to better data accuracy and more reliable inventory tracking across the organization.
