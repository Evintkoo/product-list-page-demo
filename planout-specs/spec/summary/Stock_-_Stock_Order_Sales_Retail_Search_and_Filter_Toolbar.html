1.1Overview

The Stock Order Sales Retail Search and Filter Toolbar is a user-friendly interface component designed to help staff quickly locate specific stock order records within the Lumi ERP system. By providing a centralized set of controls, users can narrow down large lists of data based on specific criteria such as location, order number, timeframes, and current status.

1.2Step-by-Step Flow
1.Define Criteria: The user interacts with the toolbar to input or select their desired search parameters. This includes choosing a specific warehouse, entering a unique stock order number, selecting a store, picking a status, or choosing a sales type.
2.Set Timeframe: The user selects a "From Date" and a "To Date" to define the specific period they wish to review.
3.Trigger Search: The user clicks the "Search" button (identified by a magnifying glass icon).
4.Validation: The system automatically checks the date range. If the "From Date" is set after the "To Date," the system alerts the user to correct the error before proceeding.
5.Apply Filters: Once validated, the system applies all selected criteria to the inventory records and displays the relevant results.
1.3Key Concepts
–Filter Criteria: The specific data points (like Warehouse, Store, or Status) used to refine a search and reduce the number of records shown.
–Date Range Validation: A built-in safety check that ensures the search timeframe is logical (i.e., the start date cannot occur after the end date).
–Search Execution: The final action that triggers the system to process the selected filters and update the view for the user.
1.4Business Value

This feature significantly improves operational efficiency by reducing the time staff spend manually searching for stock orders. By allowing users to filter by precise categories—such as specific stores or order statuses—the tool ensures that warehouse and retail teams can access the exact information they need to manage inventory, track sales, and resolve order-related inquiries quickly and accurately.
