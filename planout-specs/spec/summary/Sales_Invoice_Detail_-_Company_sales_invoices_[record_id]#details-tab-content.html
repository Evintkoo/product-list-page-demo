1.  Frontend
1.1Overview

The Sales Invoice Detail feature provides a comprehensive view of an individual customer invoice within the Lumi ERP system. It allows finance users to review invoice data, track the current status of the invoice through its lifecycle, and perform necessary actions to move the invoice forward (such as approving or sending it to the customer).

1.2Step-by-Step Flow
1.Loading: When you open a specific invoice, the system automatically retrieves all relevant data, including customer details, line items, and financial totals.
2.Review: You can view the invoice’s current status (e.g., Draft, Approved, Sent, or Paid) and examine the breakdown of costs, including subtotals, discounts, taxes, and the final amount due.
3.Workflow Management: Depending on the current status, the system displays specific action buttons:

* Draft: You can Approve, Send, or Cancel the invoice.

* Approved: You can Send the invoice to the customer or Reset it back to a draft if changes are needed.

4.Update: When you click an action button, the system processes the request and immediately refreshes the screen to show the updated status and any new available actions.
1.3Key Concepts
–Workflow State: The current stage of the invoice in the billing process (Draft, Approved, Sent, Paid, or Cancelled). This determines which buttons are available to the user.
–Financial Breakdown: A clear summary of the invoice math, showing how the final "Amount Due" is calculated after applying discounts, credit notes, and taxes.
–Action Buttons: Context-aware controls that allow users to transition an invoice from one state to another without needing to navigate to different pages.
–Details Grid: A static display of essential invoice information, such as dates, customer billing address, and tax identification numbers.
1.4Business Value

This feature centralizes the invoice management process, reducing the time spent navigating between different screens. By providing a clear, status-driven interface, it minimizes errors in the billing workflow and ensures that finance teams can quickly identify the next required step for any invoice, ultimately helping to accelerate the payment collection cycle.

2.  Logic
2.1Overview

The Sales Invoice Detail feature provides a comprehensive view of an individual invoice within the Lumi ERP system. It allows users to view all financial data associated with an invoice—such as billing details, line items, and payment status—and manage the invoice's lifecycle through a guided workflow (e.g., approving, sending, or cancelling an invoice).

2.2Step-by-Step Flow
1.Page Load: When a user opens a specific sales invoice, the system automatically retrieves all relevant invoice data, including financial totals, customer information, and the current status.
2.Data Display: The system maps the retrieved information into the "Invoice Details" tab, organizing it into clear sections for general details, financial amounts, payment status, and individual line items.
3.Header Adaptation: The invoice header automatically updates its appearance based on the current status (e.g., "Draft," "Approved," "Sent," "Paid," or "Cancelled") to ensure the user always knows the current state of the document.
4.Workflow Interaction: Depending on the current status, the user is presented with relevant action buttons (such as "Approve" or "Reset"). Clicking an action triggers an update to the invoice's status.
5.Automatic Refresh: Once an action is performed, the system immediately refreshes the page data, updating the header, the available action buttons, and the financial values to reflect the new status.
2.3Key Concepts
–Workflow State: The current stage of an invoice in its lifecycle, which dictates what actions a user can take and how the invoice is displayed.
–Invoice Mapping: The process of taking raw financial data and organizing it into user-friendly categories like "Amounts," "Payments," and "Invoice Items."
–Action Buttons: Context-aware controls that appear or disappear based on the invoice's current status to prevent invalid operations (e.g., you cannot "Approve" an invoice that is already "Paid").
2.4Business Value

This feature streamlines the finance team's operations by providing a single, reliable source of truth for invoice status. By automating the transition between states and ensuring the interface always reflects the most current data, the system reduces manual errors, improves visibility into payment timelines, and ensures that users only perform valid actions at the right time.

3.  Data
3.1Overview

The Sales Invoice Detail feature provides a comprehensive view of an individual invoice within the Lumi ERP system. It allows users to see all relevant financial data, customer information, and line-item details in one place. Additionally, the feature includes a dynamic workflow system that updates the invoice status (e.g., from Draft to Approved or Sent) and adjusts the available action buttons based on the current state of the invoice.

3.2Step-by-Step Flow
1.Data Retrieval: When a user opens a specific sales invoice page, the system automatically fetches all relevant invoice details, including customer information, financial totals, and individual product line items.
2.Display Mapping: The system organizes this data into three clear sections:

* Header: Displays the invoice reference code and the current status (e.g., Draft, Approved, Paid).

* Details & Amounts: Shows billing addresses, dates, tax information, and a breakdown of costs (subtotals, discounts, taxes, and final totals).

* Items: Lists every product included in the invoice with its specific pricing and quantity.

3.Workflow Interaction: Depending on the invoice's current status, the system presents relevant action buttons (such as "Approve," "Send," or "Cancel").
4.Status Update: When a user clicks an action button, the system updates the invoice status.
5.Automatic Refresh: Upon a successful update, the page automatically refreshes to show the new status, update the header display, and adjust the available action buttons to match the new state.
3.3Key Concepts
–Workflow State: The current lifecycle stage of an invoice (e.g., Draft, Approved, Sent, Paid, or Cancelled), which dictates what actions a user can perform next.
–Header Component: A dynamic UI element that changes its appearance and available options based on the invoice's current workflow state.
–Line Items: The individual products or services listed on an invoice, including their specific quantities, prices, and any applied discounts.
–Financial Summary: The calculated breakdown of the invoice, including subtotals, tax, credit notes, and the final amount due versus the amount already paid.
3.4Business Value

This feature centralizes all critical invoice information, reducing the need for users to navigate between different screens to verify billing or product details. By automating the workflow status and providing context-aware action buttons, the system minimizes manual errors and ensures that users only perform valid actions (e.g., preventing an invoice from being "Approved" if it has already been "Cancelled"). This creates a more efficient, reliable, and transparent billing process for the finance team.
