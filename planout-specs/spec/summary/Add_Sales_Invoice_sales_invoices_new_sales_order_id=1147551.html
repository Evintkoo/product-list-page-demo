1.  Frontend
1.1Overview

The "Add Sales Invoice" feature allows users to create a new invoice directly from an existing sales delivery. When a user navigates to this page, the system automatically pulls in the relevant order and customer information, ensuring accuracy and saving time by eliminating the need for manual data entry.

1.2Step-by-Step Flow
1.Security Verification: Upon loading the page, the system checks if the user is currently logged in. If the session has expired or the user is not authenticated, they are automatically redirected to the login screen.
2.Data Retrieval: The system identifies the specific sales delivery associated with the request. It then fetches the corresponding sales order reference code and customer name from the database.
3.Form Pre-filling: The retrieved information is automatically populated into the "Sales Order" and "For Customer" fields on the invoice form.
4.Data Integrity: These pre-filled fields are set to "read-only" (disabled). This ensures that the invoice remains strictly linked to the original delivery details, preventing accidental changes during the invoicing process.
1.3Key Concepts
–Pre-filling: The automated process of populating form fields with existing data to reduce manual effort and human error.
–Read-only Fields: Form inputs that display information but cannot be edited by the user, ensuring that critical data remains consistent with the source record.
–Authentication Check: A security measure that ensures only logged-in users can access financial data and create invoices.
1.4Business Value
–Efficiency: By automatically pulling in customer and order details, staff can generate invoices much faster.
–Accuracy: Eliminating manual entry for these fields prevents typos and data mismatches between the delivery record and the final invoice.
–Process Consistency: By locking the reference fields, the system enforces a standardized workflow where invoices are always tied directly to their originating sales delivery, simplifying financial auditing and tracking.
2.  Logic
2.1Overview

The "Add Sales Invoice" feature streamlines the billing process by automatically pulling information from an existing sales delivery. When a user navigates to the invoice creation page, the system verifies their identity and immediately populates key fields—such as the sales order reference and customer name—based on the delivery record provided. This eliminates the need for manual data entry, ensuring accuracy and saving time during the invoicing workflow.

2.2Step-by-Step Flow
1.Security Check: When the page loads, the system verifies that the user is currently logged in. If the session is invalid or expired, the user is automatically redirected to the login screen.
2.Data Retrieval: Once authenticated, the system uses the specific delivery ID from the web address to look up the relevant sales delivery details.
3.Form Pre-filling: The system extracts the sales order reference code and the customer's name from the delivery record.
4.UI Update: These details are automatically inserted into the "Sales Order" and "For Customer" fields on the invoice form, allowing the user to proceed with the invoice creation immediately.
2.3Key Concepts
–Authentication: A security step that ensures only logged-in users can access the invoicing tools.
–Pre-filling: The process of automatically populating form fields with existing data to reduce manual effort and prevent typing errors.
–Sales Delivery: The source record that contains the necessary information (like customer identity and order references) required to generate an accurate invoice.
2.4Business Value
–Increased Efficiency: By automating the entry of customer and order details, staff can generate invoices significantly faster.
–Improved Data Accuracy: Pre-filling information directly from the source record minimizes the risk of human error, such as selecting the wrong customer or entering an incorrect order reference.
–Seamless Workflow: The feature creates a smooth transition from the delivery stage to the billing stage, providing a more intuitive experience for finance team members.
