1.  Frontend
1.1Overview

The Fixed Asset Purchase Order table provides a centralized, read-only view of all purchase orders related to fixed assets. This component allows users to quickly scan the status, financial details, and progress of various asset purchases in a clean, organized list format.

1.2Step-by-Step Flow
1.View List: The table displays a comprehensive list of all fixed asset purchase orders.
2.Identify Order: Users can locate specific orders using the Document Number or Reference Number.
3.Navigate to Details: By clicking on the Document Number, the user is redirected to a dedicated page containing full details for that specific purchase order.
4.Review Financials & Dates: Users can view the supplier name, the total amount in Rupiah, and the specific creation and due dates for each order.
5.Monitor Progress: The table provides a snapshot of operational progress, including the number of returns, invoices, and deliveries associated with each order.
6.Check Status: Users can quickly identify the current state of an order (e.g., Draft, Sent, Delivered) via a color-coded status badge and verify if the order is officially closed using a simple check or cross icon.
1.3Key Concepts
–Read-Only Display: All information presented in the table is for viewing purposes only; no data can be edited directly from this screen.
–Status Badge: A visual indicator that categorizes the purchase order (e.g., Draft, Cancelled, Sent, or Delivered) to help users understand the current lifecycle stage of the order.
–Closed Indicator: A visual icon (Check or X) that provides an immediate "at-a-glance" confirmation of whether the purchase order process is complete.
–Currency Formatting: All monetary values are automatically formatted in Indonesian Rupiah (IDR) for consistency and readability.
1.4Business Value

This feature improves operational efficiency by providing procurement and finance teams with a clear, high-level overview of fixed asset spending. By consolidating key metrics—such as delivery counts, invoice status, and return history—into a single view, users can easily track asset acquisition progress and identify which orders require attention without needing to open each record individually.
