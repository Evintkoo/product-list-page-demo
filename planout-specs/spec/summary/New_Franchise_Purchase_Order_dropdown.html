1.  Frontend
1.1Overview

The "New Franchise Purchase Order" dropdown is a navigation feature designed to streamline how users begin the process of creating new purchase orders. Instead of navigating through multiple screens, users can now select the specific type of purchase order they need directly from the inventory list page, ensuring they are directed to the correct entry form immediately.

1.2Step-by-Step Flow
1.The user clicks the "New Franchise Purchase Order" button located on the inventory list page.
2.A menu appears, presenting the user with two options: "Standard (External)" or "Internal."
3.The user selects their desired option from the list.
4.The system automatically navigates the user to the specific creation page corresponding to their selection.
5.The menu closes automatically once the selection is made.
1.3Key Concepts
–Standard (External) Purchase Order: A document used for ordering goods or services from outside vendors or suppliers.
–Internal Purchase Order: A document used for requesting goods or services from within the organization or between franchise locations.
–Dropdown Menu: A user interface element that allows the user to choose one value from a list, keeping the main screen clean and organized.
1.4Business Value

This feature improves operational efficiency by reducing the number of clicks required to start a new task. By clearly distinguishing between "Standard" and "Internal" purchase orders at the point of entry, the system helps prevent user error and ensures that the correct workflow is initiated from the start, saving time and reducing administrative confusion.
