1.1Overview

The Franchise Purchase Return workflow bar is a visual navigation and control component located on the inventory page. It provides users with a clear, at-a-glance view of where a specific return document stands in the approval process, while offering quick access to essential document management actions.

1.2Step-by-Step Flow
1.Status Visualization: The bar displays the document's journey through four distinct stages: DRAFT, CONFIRMED, SENT, and APPROVED.
2.Progress Tracking: As a document moves through the workflow, the bar highlights the current stage with solid styling, marks previous stages as completed, and keeps future stages in a muted, pending state.
3.Document Management: Users can interact with the action buttons located on the right side of the bar to manage the document:

* Print: Opens the system print dialog to generate a physical or digital copy.

* Send: Advances the document to the next stage in the workflow.

* Cancel: Discards any unsaved changes and reverts the document to its previous state after a confirmation prompt.

1.3Key Concepts
–Workflow Stages: The sequential steps (Draft, Confirmed, Sent, Approved) that a purchase return must pass through.
–Status Pill: A visual indicator representing a single stage; its appearance changes based on whether the stage is active, completed, or pending.
–Chevron Icon: A graphical separator used between stages to indicate the forward direction of the workflow.
–Action Buttons: A set of controls that allow users to perform immediate tasks like printing, advancing the workflow, or canceling changes without leaving the status bar area.
1.4Business Value

This feature improves operational efficiency by providing immediate visibility into the status of franchise returns, reducing the need for users to search for document updates. By centralizing status tracking and common actions (Print, Send, Cancel) into a single, consistent interface, it minimizes user error, ensures a standardized process for handling returns, and allows staff to manage inventory documentation with greater speed and confidence.
