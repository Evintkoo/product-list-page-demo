1.  Data
1.1Overview

The "Edit Customer" feature allows users to update the details of a retail customer, including their personal information and associated addresses. The system is designed to ensure that all changes are processed reliably and that the customer's data remains consistent and accurate, such as ensuring every customer has exactly one designated "main" address.

1.2Step-by-Step Flow
1.Validation: The system checks that the required information (name, phone, store, and tax ID) is provided and that the data meets specific quality standards (e.g., phone number length).
2.Customer Update: The main customer profile is updated with the new information provided in the request.
3.Address Management: The system processes the list of addresses:

* Existing addresses are updated if changes are provided.

* New addresses are added to the customer's profile.

* Addresses marked for deletion are removed.

4.Integrity Check: The system verifies that the customer still has exactly one "main" address. If this rule is violated, the entire update is canceled to prevent data errors.
5.Synchronization: The system automatically copies the "main" address details to the customer's primary profile record to ensure consistency across the system.
6.Confirmation: Once the changes are saved, the system returns the updated customer profile so the screen can refresh immediately with the latest information.
1.3Key Concepts
–Atomic Transaction: A safety mechanism that ensures all changes (customer profile and addresses) are saved together. If any part of the update fails, the entire process is canceled, leaving the data exactly as it was before.
–Main Address: A mandatory designation for one specific address in a customer's profile. The system enforces that every customer must have exactly one, ensuring reliable contact and shipping information.
–Data Integrity: The practice of maintaining accurate and consistent data by enforcing rules (like the "one main address" requirement) during every update.
–Retail Customer: The specific category of customer this feature manages, ensuring that wholesale, franchise, or consignment settings are not accidentally modified through this interface.
1.4Business Value

This feature provides a streamlined and error-proof way to maintain customer records. By automating the validation of addresses and ensuring that critical information is always synchronized, the system reduces manual data entry errors and ensures that customer contact information is always reliable for sales and shipping operations.
