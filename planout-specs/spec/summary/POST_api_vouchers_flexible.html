1.  Logic
1.1Overview

The "Flexible Voucher" feature allows authorized users to create new, customizable vouchers within the Lumi ERP system. By providing a unique identifier (SKU), a name, a monetary value, and a currency, users can generate vouchers that are immediately stored and ready for use. The system automatically handles the assignment of unique IDs and timestamps to ensure data consistency and auditability.

1.2Step-by-Step Flow
1.Security Check: The system verifies that the user is logged in and possesses the necessary permissions to create vouchers.
2.Data Validation: The system checks the incoming information to ensure all required fields (SKU, name, value, and currency) are present and formatted correctly.
3.Uniqueness Verification: The system checks the database to ensure the provided SKU is not already in use, preventing duplicate entries.
4.Record Creation: If all checks pass, the system generates a unique ID and timestamps for the voucher, saves it to the database, and confirms the creation by returning the full voucher details.
1.3Key Concepts
–SKU (Stock Keeping Unit): A unique code used to identify a specific type of voucher, ensuring that each voucher can be tracked individually.
–Authentication: The process of verifying the identity of the user to ensure they are authorized to access the system.
–Validation: A safety check performed by the system to ensure that the data provided by the user meets all business requirements before it is saved.
–Conflict Handling: A protective measure that prevents the system from saving a new voucher if its unique identifier already exists, avoiding data corruption.
1.4Business Value

This feature provides the flexibility needed to manage diverse promotional or payment instruments within the ERP. By automating the generation of IDs and timestamps, it reduces manual data entry errors and ensures that every voucher is accurately tracked from the moment it is created. The built-in validation and security checks ensure that only authorized personnel can create vouchers, maintaining the integrity of the company's financial and inventory data.

2.  Data
2.1Overview

The "Create Flexible Voucher" feature allows authorized users to add new voucher types to the Lumi ERP system. This tool is designed to be flexible, enabling the business to define unique vouchers by providing a specific stock-keeping unit (SKU), a name, and a monetary value. The system automatically handles administrative details like unique identification and timestamps, ensuring data consistency and preventing duplicate entries.

2.2Step-by-Step Flow
1.Submission: The user submits a request containing the voucher details (SKU, name, description, value, and currency).
2.Validation: The system checks that all mandatory fields (SKU, name, and value) are present and correctly formatted. If information is missing, the request is rejected.
3.Conflict Check: The system verifies that the provided SKU is not already in use by another voucher. If a duplicate is found, the request is rejected to maintain data integrity.
4.System Enrichment: Once validated, the system automatically assigns a unique identifier to the voucher and records the exact date and time of creation.
5.Confirmation: The new voucher is saved to the database, and the system returns a success confirmation to the user.
2.3Key Concepts
–SKU (Stock Keeping Unit): A unique identifier used to track a specific type of voucher; no two vouchers can share the same SKU.
–Validation: A safety check performed by the system to ensure that all required information is provided before processing begins.
–Conflict Handling: A protective measure that prevents the system from creating duplicate records if a user attempts to add a voucher with an existing SKU.
–System-Generated Fields: Data points, such as unique IDs and creation timestamps, that the system creates automatically so the user does not have to manage them manually.
2.4Business Value

This feature streamlines the voucher management process by automating the administrative overhead of record-keeping. By enforcing strict validation and preventing duplicate SKUs, the system ensures that financial and inventory data remains accurate and reliable. This allows the business to quickly and confidently scale its voucher offerings without the risk of data entry errors or conflicting records.
