1.  Frontend
1.1Overview

The "Add Sales Order" feature provides a streamlined interface for creating new sales orders within the Lumi ERP system. It allows users to select a warehouse, identify a customer, and build a list of products to be sold. The system includes flexible pricing and discount tools, ensuring that sales staff can accurately record order details before submitting them for processing.

1.2Step-by-Step Flow
1.Initialization: Upon opening the page, the system automatically retrieves and displays a list of available warehouses.
2.Order Header Setup: The user selects the source warehouse and the customer. The system automatically populates the delivery address based on the selected customer.
3.Adding Items: The user adds products to the order. For each product, the system displays available stock levels to help guide the order quantity.
4.Pricing and Discounts:

* Users can enter a simple percentage discount directly in the product row.

* For more complex needs (such as fixed-amount discounts or tax-inclusive adjustments), users can open a dedicated "Discount Popup" for that specific item.

* A global "Set" tool is available to apply a uniform percentage discount to all items in the order at once.

5.Review and Save: The system calculates totals automatically. Once the required fields (Warehouse, Customer, and at least one product) are filled, the user clicks "Save" to submit the order as a draft.
1.3Key Concepts
–Warehouse Selection: A mandatory step that defines where the stock for the order will be sourced.
–Customer Search: A type-ahead search feature that retrieves customer details and automatically fills in the delivery address.
–Discount Types: The system supports two ways to reduce prices: a percentage-based discount or a fixed-amount deduction.
–Tax-Inclusive Toggle: A setting that determines whether a discount is applied to the gross price (including tax) or the net price (before tax).
–Draft State: All new orders are initially saved as "Drafts," allowing for review or approval before they are finalized and delivered.
1.4Business Value

This feature centralizes the sales order process, reducing manual data entry errors by pre-filling customer information and automating price calculations. By providing both quick-entry discount shortcuts and advanced configuration options, the system balances efficiency for standard sales with the flexibility required for complex pricing agreements. This ensures that the sales team can generate accurate, professional orders quickly, keeping inventory and financial records in sync from the moment an order is created.

2.  Logic
2.1Overview

The "Add Sales Order" feature allows users to create new sales orders within the Lumi ERP system. This interface provides a structured way to capture customer details, shipping information, and specific product line items, including any applicable discounts. Once the user completes the form and clicks "Save," the system validates the information and securely transmits it to the server to generate a new draft sales order.

2.2Step-by-Step Flow
1.Initialization: When the page loads, the system automatically retrieves a list of available warehouses to populate the "From Warehouse" selection menu.
2.Data Entry: The user fills out the order header (Customer, Warehouse, Delivery Date, etc.) and adds one or more product rows.
3.Search Assistance: As the user types in the "Customer" or "Product" fields, the system provides real-time search suggestions to ensure accurate selection.
4.Discount Management: Users can apply discounts to individual items using either a quick percentage shortcut or a detailed editor for specific discount amounts and tax settings.
5.Validation: Upon clicking "Save," the system checks that a customer and warehouse are selected and that at least one product with a valid quantity has been added.
6.Submission: If valid, the system packages the form data—including combining the address and zip code—and sends it to the server.
7.Confirmation: The server processes the request, generates a unique document number, calculates final totals, and returns a confirmation that the draft order has been created.
2.3Key Concepts
–Type-ahead Search: A feature that suggests matching customers or products as you type, reducing manual entry errors.
–Draft State: The initial status of a new sales order, allowing for review before it is finalized or processed.
–Validation Rules: Built-in safeguards that prevent an order from being saved if essential information (like the customer or product quantity) is missing.
–Payload Mapping: The behind-the-scenes process where the information you enter into the form is organized into the specific format required by the system's database.
2.4Business Value
–Data Accuracy: By using searchable dropdowns and mandatory field checks, the system ensures that sales orders are created with complete and correct information.
–Efficiency: Automating the calculation of totals and the generation of document numbers on the server side saves time and reduces the risk of manual calculation errors.
–Flexibility: The discount editor allows sales staff to apply various pricing strategies (percentage-based or fixed-amount) directly at the line-item level, providing better control over sales margins.
3.  Data
3.1Overview

The "Add Sales Order" feature allows users to create a new sales record within the Lumi ERP system. This process captures essential customer information, delivery details, and a list of products being ordered. The system automatically handles the administrative side of the order—such as generating a unique tracking number and reserving stock—to ensure that the order is accurate and ready for fulfillment from the moment it is saved.

3.2Step-by-Step Flow
1.Submission: The user submits the sales order form, which includes customer details, delivery information, and a list of items with their respective pricing and discount settings.
2.Validation: The system checks that all mandatory information (such as the customer and the list of items) is present.
3.Document Numbering: The system automatically generates a unique document number for the order to ensure it can be easily tracked and referenced.
4.Record Creation: The system saves the main order details (the "header") and links all individual product items to that specific order.
5.Inventory Reservation: The system automatically triggers a stock reservation process to ensure the items ordered are set aside for this specific customer.
6.Confirmation: Once all steps are successfully completed, the system confirms the order has been created and provides the full details of the saved record. If any part of this process fails, the system cancels the entire action to prevent incomplete or corrupted data.
3.3Key Concepts
–Sales Order Header: The top-level information for an order, including the customer, delivery address, due date, and notes.
–Sales Order Items: The individual products included in the order, along with their specific quantities, prices, and any applied discounts.
–Atomic Transaction: A safety mechanism that ensures all parts of the order (header and items) are saved together; if one part fails, nothing is saved, preventing "half-finished" orders.
–Stock Reservation: An automated check that ensures the products requested are accounted for in the warehouse inventory as soon as the order is placed.
3.4Business Value
–Data Integrity: By using automated document numbering and atomic transactions, the system prevents duplicate records and ensures that orders are never saved with missing or mismatched information.
–Operational Efficiency: Automating the stock reservation process removes the need for manual inventory checks, allowing sales staff to confirm availability immediately.
–Accuracy: By recalculating financial fields and validating data upon submission, the system reduces human error in pricing and discount calculations, ensuring that the final order reflects the correct totals.
