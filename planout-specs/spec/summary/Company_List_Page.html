1.  Frontend
1.1Overview

The Company List Page is a central hub within the Lumi ERP system that allows users to view and manage all registered companies. This page provides a clear, organized table view of company information, ensuring that users can easily identify and access specific company records for updates.

1.2Step-by-Step Flow
1.Page Initialization: When the user navigates to the Company List page, the system automatically triggers a request to retrieve the full list of companies.
2.Loading State: While the data is being fetched, the user sees a loading indicator to confirm the system is working.
3.Data Display: Once the data is retrieved, the system populates a table with the following details for each company: Name, Address, Country, and Currency.
4.Error Handling: If the system fails to retrieve the data, an error message is displayed to inform the user.
5.Navigation: Each row in the table includes an "Edit" button. Clicking this button redirects the user to a dedicated page where they can modify the details of that specific company.
1.3Key Concepts
–Company Table: A structured list view that displays key business information for each company in a clean, readable format.
–Loading State: A visual cue that informs the user that the system is currently processing a request, preventing confusion during brief wait times.
–Edit Action: A functional link associated with each company row that allows for quick navigation to the editing interface for that specific record.
–Setup Menu: The navigation context that helps users understand they are currently working within the "Setup" area of the ERP system.
1.4Business Value

This feature streamlines administrative tasks by providing a centralized, easy-to-navigate view of all company entities. By enabling quick access to company details and providing a direct path to the editing interface, the page reduces the time and effort required for users to maintain accurate company records, ultimately improving data management efficiency within the Lumi ERP.

2.  Logic
2.1Overview

The Company List Page feature provides a centralized view for users to browse all companies registered within the Lumi ERP system. This page acts as a directory, allowing you to see key details for every company at a glance, ensuring that all organizational data is easily accessible and organized in one place.

2.2Step-by-Step Flow
1.The system receives a request to display the list of companies.
2.The system retrieves the complete collection of company records from the database.
3.The system organizes this data into a clear, readable format, ensuring each company includes its name, address, country, and currency.
4.The system presents this compiled list to the user on the Company List Page.
5.If the system encounters an issue while gathering this information, it will notify the user that the list could not be retrieved.
2.3Key Concepts
–Company Record: The core set of information stored for each business entity, including its name, location, and financial currency.
–Row Identifier: A unique internal reference for each company that allows the system to link specific entries to actions, such as clicking an "Edit" button to update details.
–Data Mapping: The process of taking raw information from the system's database and presenting it in a structured, user-friendly layout on your screen.
2.4Business Value

This feature improves operational efficiency by providing a single source of truth for all company entities. By having a clear, browsable list, users can quickly verify company information, maintain accurate records, and easily navigate to specific company profiles for further management or updates.

3.  Data
3.1Overview

The Company List Page is a centralized dashboard within the Lumi ERP system that allows you to view all registered companies in one place. This feature acts as a directory, pulling data from our secure database and presenting it in a clean, organized table format so you can easily manage and review your organization's entities.

3.2Step-by-Step Flow
1.The system initiates a request to the Lumi ERP backend to retrieve the complete list of registered companies.
2.The system receives the raw data, which includes details such as the company name, physical address, country of operation, and local currency.
3.The system automatically standardizes this information to ensure it matches our internal display format.
4.The processed data is then populated into the Company List table, where each company is assigned a unique identifier to allow for future actions, such as editing specific records.
3.3Key Concepts
–Company Entity: A single record representing a business entity within the ERP, containing its core details like name, location, and financial settings.
–Data Standardization: A background process that ensures information from our database is presented consistently in the user interface, regardless of how it is stored technically.
–Unique Identifier: A hidden, permanent reference number assigned to each company that ensures the system always knows exactly which record you are viewing or editing.
3.4Business Value

This feature provides a "single source of truth" for your company data. By offering a clear, browsable list, it eliminates the need to search through disparate records, reduces manual data entry errors, and provides a reliable foundation for managing company-specific settings across the entire ERP platform.
