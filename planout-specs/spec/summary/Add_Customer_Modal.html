1.  Frontend
1.1Overview

The "Add Customer Modal" is a pop-up feature designed for the Lumi ERP Sales module. It allows sales staff to quickly register a new customer and their associated vehicle details directly within the sales process. The feature includes built-in safeguards to ensure essential information is captured correctly before the record is saved.

1.2Step-by-Step Flow
1.Open Modal: The user triggers the "Add New Customer" pop-up from the sales screen.
2.Data Entry: The user fills out three main sections:

* Basic Info: Captures personal details like name, contact information, and store assignment.

* Address Details: A hierarchical selection process where choosing a province, regency, or district automatically updates the available options for the next level, ensuring accurate location data.

* Vehicle Details: Captures specific vehicle information. Selecting a vehicle model automatically populates the vehicle category.

3.Real-Time Validation: As the user types, the system checks for required fields (such as Name, Phone, Store, and Vehicle details). If a required field is left empty, the system immediately flags it.
4.Submission: Once all required fields are valid, the "Save" button becomes active.
5.Processing: Upon clicking "Save," the system sends the data to the database. If successful, the modal closes and the sales view refreshes; if an error occurs, the user is notified so they can correct the information.
1.3Key Concepts
–Real-time Validation: A feature that checks for missing information as you type, preventing errors before you attempt to save.
–Hierarchical Address Selection: A smart form behavior where selecting a broader location (like a province) narrows down the choices for more specific locations (like a district), making data entry faster and more accurate.
–Derived Data: Information that is automatically filled in by the system based on other selections (e.g., the vehicle category is automatically determined once the vehicle model is chosen).
–Form State: The system’s internal tracking of whether the form is currently being submitted or if it contains errors, which controls whether the "Save" button is clickable.
1.4Business Value
–Efficiency: Sales staff can add new customers on the fly without leaving the sales screen, reducing administrative friction.
–Data Integrity: By enforcing required fields and using hierarchical dropdowns for addresses, the system ensures that customer records are complete and accurate from the start.
–Reduced Errors: Automated validation and derived fields minimize manual data entry mistakes, leading to cleaner customer and vehicle databases.
