1.  Frontend
1.1Overview

The "Store - Report Discrepancy Stocks" page provides a centralized dashboard for inventory managers to view, search, and manage stock discrepancies. This feature allows users to filter through existing discrepancy reports using specific criteria—such as product details, document references, or status—and perform follow-up actions like editing reports or providing feedback directly from the list.

1.2Step-by-Step Flow
1.Access the Page: Navigate to the "Inventory" section of the main menu and select the "Store" tab to view the discrepancy list.
2.Apply Filters: Use the filter bar to narrow down results by entering a Product SKU, Product Name, or Document Reference Code, or by selecting a date range, specific entity, or report status.
3.Execute Search: Click the "Search" button to retrieve the relevant records. The system will only process the filters that have been filled out.
4.Review Data: The table will update to display the filtered list, showing key details such as the date, entity, product information, quantity, and current status.
5.Manage Records:

* Click "Show" on any row to view the full details of a specific discrepancy.

* Use the "Action" dropdown menu to either "Edit" an existing report or "Add Feedback" to a record.

6.Additional Actions: Use the dedicated buttons to create a "New Report" or "Download" the current list for external reporting.
1.3Key Concepts
–Discrepancy Stock: A record indicating a mismatch between recorded inventory levels and actual physical stock.
–Filter Bar: A set of search fields that allows users to isolate specific records without needing to browse the entire database.
–Document Reference Code: A unique identifier assigned to a specific discrepancy report for easy tracking and auditing.
–Entity: The specific store or warehouse location associated with the stock discrepancy.
–Status: The current lifecycle stage of a discrepancy report (e.g., pending, under review, or resolved).
1.4Business Value

This feature streamlines inventory management by providing a clear, searchable view of stock issues. By enabling users to quickly filter for specific discrepancies and take immediate action—such as adding feedback or editing reports—the system reduces the time spent on manual reconciliation and improves the accuracy of inventory records. This ensures that store managers can resolve stock imbalances faster, ultimately leading to better inventory control and operational efficiency.

2.  Logic
2.1Overview

The "Report Discrepancy Stocks" page is a centralized dashboard within the Lumi ERP system that allows users to view and manage inventory discrepancies. This feature provides a clear, searchable list of stock issues, enabling staff to track, review, and respond to discrepancies efficiently.

2.2Step-by-Step Flow
1.Authentication Check: When a user navigates to the page, the system automatically verifies their session. If the user is not logged in, they are redirected to the login screen.
2.Initial Data Load: Once authenticated, the system automatically fetches the first 20 discrepancy records to display in the table.
3.Filtering: Users can refine the list by applying filters such as Product SKU, Product Name, or Status. When the "Search" button is clicked, the system updates the table to show only the records that match the selected criteria.
4.Data Presentation: The system maps raw system data into a user-friendly table format, displaying key details like the date, product information, quantity, and current status.
5.Actionable Items: Each row in the table includes specific controls (such as "Show" and "Respond") that allow users to take immediate action on a specific discrepancy.
2.3Key Concepts
–Discrepancy Stock: An inventory record indicating a mismatch between expected and actual stock levels.
–Filtering: The ability to narrow down the list of records based on specific criteria (e.g., searching by a specific product name or SKU) to find relevant information quickly.
–Pagination: A method of displaying data in smaller, manageable chunks (e.g., 20 records at a time) to ensure the page remains fast and easy to navigate.
–Status: The current state of a discrepancy (e.g., pending, under review, or resolved), which determines what actions are available to the user.
2.4Business Value

This feature streamlines inventory management by providing a single source of truth for stock discrepancies. By allowing users to quickly search and filter through issues, the system reduces the time spent investigating stock errors. Furthermore, by providing direct "Respond" actions within the list, the feature ensures that discrepancies are addressed promptly, helping to maintain accurate inventory records and operational accountability.

3.  Data
3.1Overview

The "Report Discrepancy Stocks" feature provides a centralized view for store managers and staff to monitor inventory inconsistencies. It allows users to browse a list of products where the recorded stock levels do not match the actual physical count. This page ensures that inventory errors are visible, searchable, and manageable, helping the team maintain accurate stock records.

3.2Step-by-Step Flow
1.Authentication Check: When the page loads, the system verifies the user's identity. If the session is invalid, the user is redirected to the login screen.
2.Data Retrieval: Once authenticated, the system automatically fetches the list of reported stock discrepancies.
3.Filtering and Pagination: The system displays the data in manageable chunks (defaulting to 20 items at a time). Users can apply filters, such as the current status of the discrepancy, to narrow down the list.
4.Information Display: The system retrieves and displays key details for each entry, including the product name, its unique identification code (SKU), the expected versus actual quantity, the reason for the discrepancy, and the current status of the report.
5.Result Presentation: The final list is presented to the user, including a total count of records to help with navigation.
3.3Key Concepts
–Discrepancy Stock: An inventory record where the physical count in the store differs from the quantity recorded in the system.
–SKU (Stock Keeping Unit): A unique code used to identify and track specific products within the inventory.
–Pagination: A method of breaking a large list of data into smaller, easier-to-read pages to improve performance and usability.
–Status: The current state of a discrepancy report (e.g., pending review, resolved, or under investigation).
3.4Business Value

This feature is essential for maintaining inventory integrity. By providing a clear, searchable list of discrepancies, it enables store staff to:

* Identify Shrinkage: Quickly spot patterns of missing or excess stock.

* Improve Accuracy: Facilitate faster reconciliation of inventory records.

* Enhance Accountability: Track the status of reported issues from discovery to resolution, ensuring that no inventory error is overlooked.
