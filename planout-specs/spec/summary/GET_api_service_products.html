1.  Logic
1.1Overview

This feature provides a way for external systems to retrieve a list of service products stored in the Lumi ERP. By default, the system will return only active service products, ensuring that users are working with current and relevant data. The feature is designed to be flexible, allowing users to search for specific items, filter by recent updates, or organize the results in a specific order.

1.2Step-by-Step Flow
1.Request Initialization: The system receives a request to list service products. It automatically sets default values for pagination (starting on page 1 with up to 100 items) and ensures that only "active" products are included unless otherwise requested.
2.Filtering: The system applies any specific filters provided by the user, such as searching for a specific product ID, a unique SKU, or products that have been updated after a certain date.
3.Sorting: The system organizes the list based on the user's preferred field (such as ID or name) and direction (ascending or descending).
4.Pagination: The system limits the number of results returned per request (up to a maximum of 300) to ensure the response remains fast and manageable.
5.Data Delivery: The system retrieves the requested information—including the product ID, SKU, name, status, and creation/update timestamps—and sends it back to the user. If an error occurs during this process, the system provides a clear error message.
1.3Key Concepts
–Pagination: A method of breaking a large list of items into smaller, manageable pages to improve performance and readability.
–Filtering: The ability to narrow down the list of products based on specific criteria, such as status (active/inactive) or modification date.
–SKU (Stock Keeping Unit): A unique identifier used to track individual service products within the system.
–Sorting: The process of arranging the list in a specific order, such as alphabetical or chronological, to make it easier to find specific information.
1.4Business Value

This feature enables seamless integration between the Lumi ERP and other business tools. By providing a standardized way to pull service product data, it ensures that external applications always have access to accurate, up-to-date product information. The built-in filtering and pagination capabilities allow for efficient data retrieval, reducing the load on the system while providing the flexibility needed for various reporting and synchronization tasks.

2.  Data
2.1Overview

The Service Product API endpoint allows users to retrieve a list of service products currently stored in the Lumi ERP system. By default, the system provides a clean, organized list of all "active" products, but it also includes flexible search and organization tools to help users find specific items quickly.

2.2Step-by-Step Flow
1.Request Initiation: The system receives a request to fetch service products.
2.Filtering: The system applies any requested filters (such as searching by a specific ID, SKU, or checking for updates since a certain date). If no specific "active" status is requested, the system automatically filters for active products only.
3.Sorting: The results are organized based on the user's preference (e.g., by name, date, or SKU) in either ascending or descending order.
4.Pagination: To ensure the system remains fast, the results are broken into manageable pages. The system calculates which specific "slice" of data to show based on the requested page number and limit.
5.Data Delivery: The system retrieves the final, filtered, and sorted list and delivers it to the user. If the requested item cannot be found or an error occurs, the system provides a clear status message (such as "Not Found" or "Bad Request").
2.3Key Concepts
–Pagination: A method of breaking a large list of items into smaller, manageable pages to improve performance and readability.
–Filtering: The ability to narrow down the list of products based on specific criteria, such as whether a product is active or when it was last updated.
–Sorting: The process of arranging the list in a specific order (e.g., alphabetical or chronological) to make it easier to navigate.
–SKU (Stock Keeping Unit): A unique identifier used to track specific service products within the system.
–Active Status: A toggle that determines whether a product is currently available for use; the system defaults to showing only active items to keep the workspace uncluttered.
2.4Business Value

This feature provides a reliable and efficient way for users to access service product data. By offering built-in filtering and sorting, it reduces the time spent searching for information. Furthermore, the pagination feature ensures that the application remains responsive even as the number of service products grows, supporting the scalability of the Lumi ERP platform.
