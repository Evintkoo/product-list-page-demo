1.  Frontend
1.1Overview

The Supplier Settings Card is a dedicated section within the Supplier management page. It provides a centralized area for users to configure key operational and accounting preferences for a specific supplier. This component ensures that essential business rules—such as tax settings, account mapping, and supplier status—are easily accessible and consistently applied during the supplier setup or editing process.

1.2Step-by-Step Flow
1.Initialization: When the page loads, the system automatically retrieves the current list of financial accounts from the company’s Chart of Accounts to populate the dropdown menus.
2.Configuration Toggles: The user interacts with three primary checkboxes to define the supplier's operational status:

* Active: Marks the supplier as currently enabled for business.

* Internal Supplier: Flags whether the supplier is an internal entity or an external vendor.

* Allow Store Purchase Order: Determines if individual stores are permitted to place purchase orders directly with this supplier.

3.Account Mapping: The user selects specific financial accounts for four distinct categories (AP Invoice, AP Credit Note, Down Payment, and Deposit) from the pre-loaded list.
4.Tax Selection: The user selects the appropriate sales tax rule for the supplier. This field is mandatory, with a default option to "Use Product Tax Rate" if no specific tax rule is required.
5.Submission: Once configured, all selected settings and account mappings are saved as part of the overall supplier record.
1.3Key Concepts
–Chart of Accounts: The master list of financial accounts used by the organization to track money; these are used here to ensure accounting entries are mapped to the correct ledgers.
–Operational Toggles: Simple "Yes/No" switches that allow users to quickly enable or disable specific business capabilities for a supplier.
–Account Mapping: The process of linking a supplier to specific financial accounts, ensuring that transactions (like payments or deposits) are automatically categorized correctly in the accounting system.
–Mandatory Fields: Specific settings, such as the Sales Tax rule, that must be defined to ensure the supplier record is complete and compliant with financial reporting requirements.
1.4Business Value
–Operational Efficiency: By grouping all configuration settings into one card, users can manage supplier preferences quickly without navigating through multiple screens.
–Data Accuracy: Automating the retrieval of the Chart of Accounts reduces manual entry errors, ensuring that financial transactions are always linked to valid, pre-approved accounts.
–Standardization: Providing clear, consistent toggles and dropdowns ensures that every supplier is set up with the same level of detail, which simplifies reporting and auditing across the organization.
2.  Logic
2.1Overview

The Supplier Settings Card is a component within the Supplier management page that allows users to define specific accounting behaviors for a supplier. It provides four dropdown menus where users can select the appropriate financial accounts for different types of transactions, such as purchases, credit notes, down payments, and deposits. This ensures that all financial activity related to a specific supplier is automatically mapped to the correct ledger accounts.

2.2Step-by-Step Flow
1.Data Loading: When the page loads, the system automatically fetches the current list of available financial accounts from the company's Chart of Accounts.
2.Display Formatting: The system takes the raw account data and formats it into a user-friendly list, showing both the account code and the account name (e.g., "1001 - Inventory Purchases") so users can easily identify the correct option.
3.User Selection: The user selects the relevant account for each of the four categories: AP Invoice, AP Credit Note, Supplier Down Payment, and Supplier Deposit.
4.State Management: As the user makes selections, the system tracks these choices in the background, linking the selected account's unique identifier to the specific supplier setting.
5.Submission: When the supplier form is saved, these selected account identifiers are bundled with the rest of the supplier information to ensure the settings are applied correctly in the system.
2.3Key Concepts
–Chart of Accounts (COA): The master list of financial accounts used by the business to categorize transactions.
–Dropdown Mapping: The process of taking a list of accounts and presenting them in a menu so that a user can pick one, while the system remembers the underlying ID of that account.
–Account Identifier: A unique internal code used by the software to ensure that the correct financial account is referenced, regardless of how the account name is displayed to the user.
–Supplier Settings: Specific configurations that dictate how the system handles financial transactions for a particular supplier, ensuring consistency in accounting records.
2.4Business Value
–Accuracy: By providing a standardized list of accounts, the system reduces the risk of manual data entry errors when assigning financial categories to suppliers.
–Efficiency: Users can quickly configure supplier settings using pre-populated dropdowns rather than searching for or typing in account details manually.
–Consistency: Automating the link between suppliers and their respective financial accounts ensures that all accounting reports and financial statements remain accurate and reliable.
3.  Data
3.1Overview

The Supplier Settings Card is a new component within the Supplier management page that allows users to define specific accounting behaviors for each supplier. By selecting the appropriate accounts from the Chart of Accounts, users can ensure that financial transactions—such as invoices, credit notes, down payments, and deposits—are automatically mapped to the correct ledger accounts.

3.2Step-by-Step Flow
1.Data Retrieval: When the page loads, the system fetches the current list of available accounts from the Chart of Accounts.
2.Formatting: The system organizes this list so that each option is clearly displayed as a combination of the account code and the account name, making it easy for users to identify the correct selection.
3.User Selection: The user interacts with four distinct dropdown menus, each representing a specific financial category (AP Invoices, Credit Notes, Down Payments, and Deposits).
4.State Management: As the user selects an account for each category, the system tracks these choices in the background.
5.Submission: When the user saves the supplier form, these four account selections are bundled with the rest of the supplier data and sent to the system to update the supplier's financial settings.
3.3Key Concepts
–Chart of Accounts (COA): The master list of financial accounts used by the organization to categorize transactions.
–Dropdown Mapping: The process of linking a user-friendly label (Account Code + Name) to a unique system identifier (Account ID) to ensure accurate data processing.
–Financial Categories: The four specific areas (AP Invoices, Credit Notes, Down Payments, and Deposits) where the system needs to know which ledger account to use for that specific supplier.
3.4Business Value
–Accuracy: By allowing users to pre-select specific accounts for supplier transactions, the system reduces the risk of manual data entry errors during the accounting process.
–Efficiency: Automating the mapping of supplier-related financial activities saves time for the accounting team, as they no longer need to manually reclassify these transactions later.
–Consistency: Ensures that all financial activity related to a specific supplier is consistently recorded in the correct ledger, providing cleaner and more reliable financial reporting.
