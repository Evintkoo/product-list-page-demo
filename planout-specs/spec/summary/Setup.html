1.  Data
1.1Overview

The Setup module provides the foundational configuration for the Lumi ERP system. It allows administrators to manage essential business data, including warehouse locations, company profile details, administrative regions, and payment methods. This module ensures that the system is correctly tailored to the company's specific operational needs and geographic requirements.

1.2Step-by-Step Flow
1.Company Profile Setup: Administrators define core company information, such as business name, address, currency, and time zone. This section also handles platform-wide settings and document tracking (e.g., invoice numbering formats).
2.Warehouse Management: Users can create and maintain a list of warehouses. Each warehouse is assigned a unique code and location details, which are essential for inventory tracking.
3.Administrative Region Configuration: The system maintains a hierarchical list of administrative areas (Province, Regency, District, and Village) to support standardized location data across the platform.
4.Payment Type Configuration: The system provides a master list of available payment methods (e.g., Cash, Credit/Debit Cards, QRIS).
5.Store-Level Payment Mapping: Administrators can control which payment methods are active at specific store locations. The system automatically manages these mappings to ensure that each store only offers the payment options enabled for it.
1.3Key Concepts
–Company Profile: The central repository for business identity and operational settings, including tax identifiers and regional preferences.
–Warehouse: A physical or logical location where inventory is stored, identified by a unique code for easy tracking.
–Administrative Area: A structured, hierarchical list of regions used to ensure consistent location data entry throughout the system.
–Payment Type: A defined method of transaction (e.g., Cash or specific Bank Transfer) available for use within the business.
–Payment Mapping: A configuration that links specific payment types to individual stores, allowing businesses to toggle payment availability on or off per location.
1.4Business Value
–Operational Consistency: By centralizing company and warehouse data, the system ensures that all departments use the same standardized information.
–Flexibility: The ability to map payment types to specific stores allows businesses to customize their checkout experience based on the capabilities or requirements of individual locations.
–Scalability: The structured approach to administrative regions and document tracking allows the system to grow alongside the business, supporting new locations and complex operational requirements without manual data entry errors.
–Auditability: Every record includes tracking for who created or updated the information, providing a clear history of configuration changes for compliance and management oversight.
