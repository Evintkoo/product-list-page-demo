1.  Logic
1.1Overview

This feature allows authorized users to add a new vehicle record to the Lumi ERP system. By providing specific vehicle details—such as the make, model, year, and VIN—and linking it to an existing customer, the system creates a permanent record that tracks ownership and vehicle history.

1.2Step-by-Step Flow
1.Authentication: The system verifies that the person making the request is currently logged in.
2.Validation: The system checks that all required vehicle information (customer ID, make, model, year, and VIN) has been provided.
3.Customer Verification: The system confirms that the customer ID provided actually exists in the database.
4.Record Preparation: The system generates a unique ID for the vehicle, assigns the current user as the creator, and stamps the record with the current date and time.
5.Data Storage: The new vehicle information is saved into the system database.
6.Confirmation: The system returns the complete, newly created vehicle record to confirm the process was successful.
1.3Key Concepts
–Customer ID: A unique identifier used to ensure the vehicle is correctly linked to the right customer account.
–VIN (Vehicle Identification Number): The unique code used to identify a specific vehicle.
–Authentication: The security process that ensures only logged-in, authorized users can add new data to the system.
–Validation: A safety check to ensure that all necessary information is present and correct before the system attempts to save it.
1.4Business Value

This feature streamlines the vehicle management process within the Lumi ERP. By automating the creation of vehicle records and ensuring they are strictly linked to verified customers, the system reduces manual data entry errors and maintains high data integrity. This provides a reliable foundation for tracking customer assets and managing service history effectively.

2.  Data
2.1Overview

The "Create Vehicle" feature allows users to add a new vehicle record to the Lumi ERP system. This process ensures that every vehicle is correctly linked to an existing customer and tracks essential details such as the make, model, year, and unique vehicle identification number (VIN). The system automatically handles administrative tasks like assigning a unique ID, recording who created the entry, and logging the exact time of creation.

2.2Step-by-Step Flow
1.Request Submission: The user submits a request containing the vehicle details (make, model, year, VIN) and the ID of the customer to whom the vehicle belongs.
2.Authentication Check: The system verifies that the user is currently signed in and authorized to perform this action.
3.Customer Validation: The system checks the database to ensure the provided customer ID exists. If the customer cannot be found, the process stops and returns an error.
4.Data Preparation: The system generates a unique identifier for the new vehicle and captures the current date and time.
5.Record Creation: The system saves the vehicle information into the database, linking it to the specified customer and marking the current user as the creator.
6.Confirmation: Upon successful saving, the system returns a confirmation message along with the details of the newly created vehicle record.
2.3Key Concepts
–Customer Binding: The requirement that a vehicle must be associated with a valid, pre-existing customer record in the system.
–Unique Identifier: A system-generated, one-of-a-kind code used to distinguish each vehicle record from all others.
–VIN (Vehicle Identification Number): A unique code used to identify the specific vehicle; the system ensures no two vehicles share the same VIN.
–Audit Trail: The automatic recording of "who" created the record and "when" it was created/updated, ensuring data accountability.
2.4Business Value

This feature streamlines the vehicle management process within the Lumi ERP by automating data entry and ensuring data integrity. By validating customer associations and enforcing unique identifiers like the VIN, the system prevents duplicate entries and orphaned records. This provides a reliable, organized foundation for tracking customer assets, which is essential for accurate reporting and efficient service management.
