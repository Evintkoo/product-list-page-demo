1.  Logic
1.1Overview

This feature provides the necessary information to populate the "Add New Vehicle" form in the Lumi ERP system. When a user navigates to the page to add a vehicle, this tool automatically retrieves the current list of available vehicle makes and models, ensuring that the dropdown menus are always up-to-date and accurate.

1.2Step-by-Step Flow
1.Authentication Check: The system verifies that the user is logged in and authorized to access the vehicle data.
2.Data Retrieval: The system gathers all currently "active" vehicle makes from the database.
3.Model Association: The system gathers all currently "active" vehicle models from the database.
4.Data Delivery: The system combines these lists and sends them to the "Add Vehicle" form so the user can select the appropriate make and model from the dropdown menus.
5.Error Handling: If the user is not logged in, or if a technical issue occurs during the process, the system provides a clear error message to prevent the form from loading with incorrect or missing data.
1.3Key Concepts
–Active Records: The system only retrieves makes and models that are currently marked as "active," ensuring users cannot select outdated or discontinued options.
–Reference Data: This refers to the foundational lists (makes and models) that act as the building blocks for the vehicle entry form.
–Authentication: A security step that ensures only verified users can access the vehicle database.
1.4Business Value
–Data Integrity: By only displaying "active" makes and models, the system prevents users from accidentally entering invalid vehicle information.
–Improved User Experience: Automating the population of dropdown menus saves time and reduces manual data entry errors for staff.
–System Reliability: Standardized error handling ensures that if the system encounters a problem, it fails gracefully and notifies the user rather than displaying broken or incomplete forms.
2.  Data
2.1Overview

This feature provides the necessary information to populate the "Add New Vehicle" form in the Lumi ERP system. When a user navigates to the page to add a vehicle, this tool automatically gathers the current list of available vehicle manufacturers (makes) and their corresponding models. By ensuring the system only displays "active" options, we keep the user interface clean and prevent users from selecting outdated or discontinued vehicle data.

2.2Step-by-Step Flow
1.Authentication Check: The system verifies that the user is logged in and authorized to access the system. If not, the request is denied.
2.Data Retrieval: The system fetches the list of all currently active vehicle makes from the database.
3.Model Retrieval: The system fetches the list of all currently active vehicle models associated with those makes.
4.Data Compilation: The system combines the lists of makes and models into a single, organized package.
5.Delivery: The compiled information is sent to the user's screen to populate the dropdown menus on the "Add Vehicle" form.
2.3Key Concepts
–Active Status: A filter applied to ensure that only currently supported or relevant vehicle makes and models are shown to the user.
–Metadata: The background information (names and IDs of vehicles) required to make a form functional, rather than the actual vehicle records themselves.
–Dropdown Population: The process of filling the selection menus on the user interface so that users can choose from a pre-defined list rather than typing information manually.
2.4Business Value
–Data Accuracy: By automatically filtering for "active" items, we reduce the risk of users selecting obsolete vehicle data, which improves the quality of the information stored in the ERP.
–Improved User Experience: Providing a pre-populated list of makes and models makes the "Add Vehicle" process faster and less prone to human error compared to manual entry.
–System Efficiency: This feature centralizes the retrieval of form data, ensuring that the application remains responsive and consistent across the entire platform.
