1.  Frontend
1.1Overview

The Sales Order Filter feature provides a centralized control panel for users to quickly locate specific sales orders within the Lumi ERP system. By offering a variety of search criteria, users can narrow down large lists of orders to find exactly what they need without manually scrolling through records.

1.2Step-by-Step Flow
1.Input Data: The user enters or selects criteria in one or more filter fields, such as the document number, PO number, date range, warehouse, customer, salesperson, or order status.
2.Initiate Search: The user clicks the "Search" button to trigger the filtering process.
3.Clean Request: The system automatically ignores any empty or blank fields, ensuring only the active criteria are sent to the database.
4.Reset Pagination: The system automatically resets the view to the first page of results (starting at the beginning of the list) to ensure the user sees the most relevant data for their new search.
5.Retrieve Data: The system sends the request to the server, which returns the specific list of sales orders matching the provided criteria.
6.Display Results: The filtered list is updated and presented to the user.
1.3Key Concepts
–Filter Criteria: The specific data points (like date ranges or status) used to narrow down the search results.
–Active Filtering: The system's ability to ignore empty fields, ensuring that only relevant search parameters are processed.
–Pagination Reset: A standard behavior that returns the user to the first page of results whenever a new search is performed, preventing confusion when the number of results changes.
–Order Status: A category used to track the lifecycle of an order (e.g., Draft, Confirmed, or Shipped).
1.4Business Value

This feature significantly improves operational efficiency for sales and warehouse teams. By allowing users to instantly filter by specific attributes like customer name, warehouse location, or order status, the system reduces the time spent searching for information. This leads to faster customer service responses, better inventory visibility, and a more streamlined workflow for managing the sales order lifecycle.

2.  Logic
2.1Overview

The Sales Order List filter feature allows users to quickly locate specific sales records within the Lumi ERP system. By providing a set of search criteria, users can narrow down the list of orders to find exactly what they need without scrolling through the entire database. The system is designed to be flexible, meaning it only applies filters for the information you provide, ignoring any empty fields.

2.2Step-by-Step Flow
1.Input Selection: The user enters search criteria into one or more available fields, such as the document number, customer name, date range, warehouse location, salesperson, or order status.
2.Triggering the Search: Upon clicking the "Search" button, the system collects all active filter values.
3.Data Retrieval: The system sends a request to the database, including only the fields that have been filled out. It automatically sets a default view of 20 results to ensure the page loads quickly.
4.Processing Results: The system receives the matching sales orders and organizes them into a standardized format.
5.Display: The filtered list of sales orders is presented to the user, showing key details like the order date, status, and total amount.
2.3Key Concepts
–Filter Criteria: The specific data points (like dates or customer names) used to narrow down the search results.
–Dynamic Querying: A method where the system only searches based on the fields you have filled in, rather than requiring every field to be completed.
–Pagination: A feature that limits the number of results shown at once (defaulting to 20) to keep the interface clean and performant.
–Data Mapping: The process of taking raw information from the system and organizing it into a clear, readable list for the user.
2.4Business Value

This feature significantly improves operational efficiency by reducing the time staff spend searching for specific sales orders. By allowing users to filter by common business identifiers—such as purchase order numbers or specific date ranges—the system minimizes manual effort and reduces the likelihood of errors. This streamlined access to information supports faster customer service responses and more accurate order tracking.

3.  Data
3.1Overview

The Sales Order List filter feature allows users to quickly locate specific sales records within the Lumi ERP system. By providing a set of flexible search criteria, users can narrow down large volumes of data to find exactly what they need, whether they are searching by document numbers, dates, specific customers, or the status of an order.

3.2Step-by-Step Flow
1.Input Selection: The user enters search criteria into one or more available filter fields (such as date ranges, customer names, or order status).
2.Request Submission: When the user clicks the "Search" button, the system collects only the fields that contain information and sends them as a request to the database.
3.Data Filtering: The system processes the request by applying the provided filters to the sales order records. It intelligently matches partial information (like a partial document number) and looks up related details (like matching a customer name to their unique ID).
4.Pagination: To ensure the system remains fast and easy to read, the results are returned in manageable chunks (defaulting to 20 records at a time).
5.Display: The filtered list of sales orders is returned and presented to the user.
3.3Key Concepts
–Dynamic Filtering: The system only searches based on the fields you have filled out; if a field is left blank, it is ignored, allowing for highly customizable searches.
–Partial Matching: For fields like document numbers or names, the system can find results even if you only provide a portion of the information.
–Pagination: A method of breaking large lists of data into smaller pages to improve performance and make the information easier to navigate.
–Relational Lookup: The ability to search for orders by human-friendly names (like a customer or salesperson's name) rather than requiring you to know their internal system ID numbers.
3.4Business Value

This feature significantly improves operational efficiency for sales and warehouse teams. By reducing the time spent manually scrolling through long lists, staff can respond to customer inquiries faster, track order statuses more accurately, and maintain better oversight of company sales activity. The flexible search options ensure that users can find information using the terminology they are already familiar with, reducing training time and errors.
