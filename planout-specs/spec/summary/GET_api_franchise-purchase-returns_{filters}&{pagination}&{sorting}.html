1.  Logic
1.1Overview

This feature provides a way for the system to retrieve a list of "Franchise Purchase Returns." It is designed to power the Franchise tab within the Franchise Purchase Returns page. The tool allows users to search, filter, and view these returns in a paginated format, ensuring that users only see data relevant to their specific company.

1.2Step-by-Step Flow
1.Authentication: The system verifies the user's identity. If the user is not logged in or lacks proper authorization, the request is denied.
2.Parameter Collection: The system gathers the user's search criteria, such as specific stores, suppliers, warehouses, workflow statuses, or date ranges. It also notes which page of results the user is requesting.
3.Data Scoping: The system automatically restricts the search to only include "franchise-related" returns that belong to the user's company.
4.Filtering & Sorting: The system applies the user's specific filters (like searching by a reference code prefix) and sorts the results so that the most recently created returns appear at the top.
5.Result Delivery: The system returns the requested list of data. If an unexpected error occurs during this process, the system provides an error notification.
1.3Key Concepts
–Pagination: A method of breaking a large list of data into smaller, manageable pages (e.g., 20 items per page) to improve performance and readability.
–Workflow State: The current status of a return (e.g., pending, approved, or completed), which can be used to filter the list.
–Reference Code Search: A feature that allows users to find specific returns or orders by typing the beginning of their identification numbers.
–Data Isolation: A security measure ensuring that users can only access information belonging to their own company, preventing unauthorized access to other franchise data.
1.4Business Value

This feature streamlines inventory management by providing franchise managers with a dedicated, high-performance view of purchase returns. By offering robust filtering and sorting capabilities, it reduces the time spent searching for specific records and ensures that staff can quickly track the status of returns across different stores and warehouses. The built-in security ensures that sensitive company data remains protected and isolated.

2.  Data
2.1Overview

This feature provides a way for the system to retrieve a list of franchise-related purchase returns. It is designed to power the "Franchise" tab within the Franchise Purchase Returns page, allowing users to view, search, and filter their return records efficiently. The system ensures that users only see data belonging to their specific company and organizes the results so that the most recent returns appear first.

2.2Step-by-Step Flow
1.Authentication Check: The system verifies the user's identity to ensure they only access records belonging to their company.
2.Scope Filtering: The system automatically narrows the search to only include "franchise-external" and "franchise-internal" return types.
3.Applying User Filters: The system applies any specific criteria provided by the user, such as the return status (workflow state), specific store, supplier, warehouse, or date ranges.
4.Search Matching: The system looks for records that match the provided Return Number or Order Number prefixes.
5.Sorting and Pagination: The system sorts the matching records by date (newest first) and divides them into pages based on the requested page number and limit.
6.Data Retrieval: The system fetches the requested page of data and calculates the total count of matching records to support pagination controls in the user interface.
2.3Key Concepts
–Franchise Purchase Return: A record representing stock being returned within the franchise business flow.
–Workflow State: The current status of a return (e.g., pending, approved, completed), used to filter the list.
–Pagination: A method of breaking a large list of records into smaller, manageable pages to improve performance and readability.
–Company Scoping: A security measure that ensures users can only view data associated with their own organization.
–Prefix Search: A search method where the system finds records starting with the specific characters entered by the user (e.g., searching for "RET-001" will find all returns starting with those characters).
2.4Business Value

This feature enables franchise managers and staff to quickly locate and monitor return activity. By providing robust filtering and sorting capabilities, it reduces the time spent searching for specific transactions and ensures that users have an accurate, up-to-date view of their inventory returns. This visibility is essential for maintaining accurate stock levels and managing franchise-supplier relationships effectively.
