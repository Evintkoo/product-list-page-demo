1.  Frontend
1.1Overview

The "Franchise Purchase Order - Internal" feature allows staff to create new internal purchase orders within the inventory module. This tool streamlines the process of requesting stock from a warehouse for a specific store, ensuring that all necessary supply details are captured accurately before the order is processed.

1.2Step-by-Step Flow
1.Navigation: Access the form via the Inventory module in the main navigation panel.
2.Header Entry: Fill in the order details, including the source warehouse, destination store, supplier information, reference code, due date, and any additional notes.
3.Product Selection: Add items to the order using the product table, specifying the store quantity, order quantity, supply price, and any specific remarks for each item.
4.Validation: The system checks that all required fields are completed and that at least one product has been added to the order.
5.Submission: Click the "Save" button to finalize the order. The system will save the record as a "Draft" and automatically redirect you to the newly created order's detail page.
6.Cancellation: If you decide not to proceed, you can click the "Cancel" button to discard the current entry and return to the previous screen.
1.3Key Concepts
–Workflow Status: A tracker that displays the current stage of the order (e.g., Draft, Confirmed, Sent, Approved), helping users monitor the order's progress.
–Internal Order: A specific type of purchase order used for moving or requesting stock between internal company locations, such as from a central warehouse to a franchise store.
–Line Items: The individual products included in a single purchase order, each with its own quantity and pricing details.
–Draft State: The initial status of a new order, allowing users to save and review information before it is officially confirmed or sent.
1.4Business Value
–Operational Efficiency: Centralizes the internal ordering process, reducing manual paperwork and communication errors between warehouses and stores.
–Data Accuracy: Enforces mandatory field requirements, ensuring that every purchase order contains the necessary information for fulfillment.
–Improved Visibility: Provides a clear, status-driven workflow that allows management to track orders from creation through to approval.
2.  Logic
2.1Overview

The "Franchise Purchase Orders - Internal" feature allows users to create new internal purchase orders within the Lumi ERP system. This process captures essential order details—such as the source warehouse, destination store, supplier information, and specific product quantities—and saves them as a "draft" order. This ensures that all necessary procurement data is recorded accurately before the order moves forward in the supply chain workflow.

2.2Step-by-Step Flow
1.Data Validation: The system checks that all required order information and product line items are provided. If any information is missing, the process stops and alerts the user.
2.Order Initialization: The system creates a new purchase order record, automatically setting the status to "draft."
3.Header Recording: The system saves the primary order details, including the warehouse, store, supplier, reference codes, due dates, and any additional notes.
4.Line Item Processing: The system iterates through the list of products provided, linking each item (including quantities, pricing, and remarks) to the newly created purchase order.
5.Confirmation: Once all data is successfully saved, the system returns a unique order ID, allowing the user to be automatically redirected to the details page of the newly created order.
2.3Key Concepts
–Draft Status: The initial state of a new purchase order, indicating that the document has been created but is not yet finalized or active.
–Header Record: The main container for the purchase order that holds high-level information like the supplier, destination store, and due date.
–Line Items: The individual products associated with a purchase order, including specific details like the quantity requested and any store-specific remarks.
–Validation: A safety check performed by the system to ensure that no incomplete or invalid data is saved to the database.
2.4Business Value
–Operational Efficiency: By automating the creation of internal purchase orders, staff can quickly generate procurement requests without manual data entry errors.
–Data Integrity: The structured validation process ensures that every order contains all necessary information, preventing downstream issues in inventory management.
–Seamless Workflow: Automatically transitioning the user to the order details page after creation provides a smooth, intuitive experience, allowing for immediate review or further action on the order.
3.  Data
3.1Overview

The "Internal Franchise Purchase Order" feature allows your team to create and manage new purchase orders specifically for internal inventory needs. This system streamlines the process of requesting items from a warehouse for a specific store, ensuring that all necessary details—such as quantities, pricing, and delivery timelines—are captured accurately in one place.

3.2Step-by-Step Flow
1.Data Validation: The system checks the information provided in the request to ensure all required fields (such as store location, supplier details, and delivery dates) are present and correctly formatted.
2.Transaction Initiation: The system opens a secure process to ensure that the order and its associated items are saved together as a single, complete unit.
3.Order Creation: A primary purchase order record is created, capturing high-level details like the warehouse destination, the store requesting the items, and the expected due date.
4.Item Processing: The system adds the specific list of products to the order, recording the requested quantities, pricing, and any specific notes for each item.
5.Confirmation: Once all data is saved, the system returns a complete summary of the newly created purchase order and its line items for your review.
3.3Key Concepts
–Purchase Order: A formal document that tracks the request for goods from a warehouse to a specific store.
–Line Items: The individual products included within a single purchase order, each with its own specific quantity and pricing details.
–Workflow State: The current status of the order (e.g., pending, approved, or in progress) as it moves through the supply chain.
–Transaction: A safety mechanism that ensures that if any part of the order fails to save, the entire order is rolled back to prevent incomplete or "broken" data.
3.4Business Value
–Operational Efficiency: By centralizing the creation of internal orders, staff can quickly request inventory without manual paperwork or fragmented communication.
–Data Accuracy: Automated validation ensures that every order contains the necessary information, reducing errors in shipping and billing.
–Improved Inventory Visibility: Because every order and its specific items are tracked in the system, management gains a clearer view of stock movement between warehouses and stores.
