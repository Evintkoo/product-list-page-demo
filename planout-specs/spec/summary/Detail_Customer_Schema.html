1.  Data
1.1Overview

This feature provides a structured way to retrieve detailed information for a specific customer within the Lumi ERP system. Because the system handles different types of business relationships, the feature intelligently identifies and fetches the correct data based on whether the customer is classified as a Retail, Wholesale, or Franchise partner. This ensures that the information returned is relevant to that specific customer type.

1.2Step-by-Step Flow
1.Request Initiation: The system receives a request to view the details of a customer using a unique identifier.
2.Type Identification: The system checks the customer's classification (Retail, Wholesale, or Franchise) to determine which data set to retrieve.
3.Data Retrieval:

* For Retail Customers, the system gathers core profile data, links to their assigned store and customer group, and pulls their associated addresses.

* For Wholesale Customers, the system gathers core profile data, store and group information, and associated addresses.

* For Franchise Customers, the system gathers more extensive data, including specific contact details, financial account settings, and administrative information (such as who created or last updated the record).

4.Data Assembly: The system combines the customer's primary record with related information (like addresses and group names) into a single, organized response.
5.Response Delivery: The system returns the complete customer profile to the user.
1.3Key Concepts
–Customer Classification: A method of categorizing customers (Retail, Wholesale, or Franchise) to ensure the system displays the correct fields and business logic for each.
–Data Linking: The process of automatically pulling in related information—such as store names, occupation details, or user names—so the customer profile is complete and easy to read.
–Address Aggregation: A feature that collects all addresses associated with a customer and presents them as a single, organized list within the customer's profile.
–Unique Identifier: A specific code used to ensure the system retrieves the exact customer record requested without confusion.
1.4Business Value
–Improved Data Accuracy: By using specific schemas for different customer types, the system ensures that users only see relevant, accurate information, reducing confusion.
–Operational Efficiency: Staff can quickly access a comprehensive view of a customer—including their contact details, financial settings, and history—without needing to look up information in multiple places.
–Better Relationship Management: Having a clear, detailed view of a customer’s profile (especially for complex accounts like franchises) allows for more informed decision-making and better service delivery.
