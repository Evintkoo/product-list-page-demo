1.  Frontend
1.1Overview

The "Add Product" feature provides a comprehensive form within the Lumi ERP system that allows users to register new products into the database. This interface captures all necessary details—ranging from basic identification and pricing to advanced logistics and inventory settings—ensuring that every new item is fully defined for use across the system.

1.2Step-by-Step Flow
1.Access the Form: The user navigates to the product section of the application, where the "Add Product" form is presented.
2.Input Product Details: The user fills in the required and optional fields, which are categorized into:

* Basic Information: SKU, Name, Description, Type, Brand, and Tags.

* Pricing & Tax: Retail, Wholesale, and Supply prices, along with tax settings and Maximum Retail Price (MRP).

* Logistics & Inventory: Weight, Volume, Stock Tracking, and Bundle settings.

* Operational Settings: Barcode types, Warranty periods, Return limits, and status toggles (e.g., Active, Internal Product, Can Order).

* Media & Attributes: Uploading product images and defining specific product attributes.

3.Submit Data: Once the form is complete, the user clicks the "Save" button. The system validates the entries and sends the information to the database to create the new product record.
4.Cancel Action: If the user decides not to proceed, they can click the "Cancel" button at any time to discard their changes and return to the product list page.
1.3Key Concepts
–SKU (Stock Keeping Unit): A unique identifier used to track individual products within the system.
–Pricing Tiers: Different price points (Retail, Wholesale, Supply) that allow the system to handle various sales scenarios and tax calculations.
–Product Attributes: Customizable fields that allow for specific descriptive data to be attached to a product.
–Bundle: A feature that allows multiple items to be grouped and sold together as a single product unit.
–Stock Tracking: A setting that determines whether the system should monitor the inventory levels for that specific item.
–Quick Button: A configuration for Point of Sale (POS) systems that allows a product to be displayed as a shortcut button for faster checkout.
1.4Business Value

This feature centralizes product management, ensuring that all relevant data—from financial pricing to physical dimensions—is captured in one place. By providing a structured and detailed input process, the system reduces data entry errors and ensures that downstream processes, such as inventory tracking, sales reporting, and tax calculations, are accurate and consistent across the entire organization.

2.  Logic
2.1Overview

The "Add Product" feature allows users to register new items into the Lumi ERP system. By filling out a comprehensive digital form, users can capture all necessary details—such as pricing, tax information, physical dimensions, and inventory settings—to ensure the product is correctly categorized and ready for business operations.

2.2Step-by-Step Flow
1.Data Entry: The user completes the product form, entering details like the product name, SKU, supplier information, pricing, and physical attributes (weight/volume).
2.Image and Attribute Organization: The system automatically groups uploaded images and custom product attributes into organized sets, ensuring they are correctly linked to the new item.
3.Payload Construction: When the user clicks "Save," the system gathers all the entered information and formats it into a structured digital package.
4.Submission: The system sends this package to the central database to officially create the new product record.
5.Confirmation: The system processes the request and confirms that the product has been successfully added to the inventory.
2.3Key Concepts
–SKU (Stock Keeping Unit): A unique identifier used to track individual products within the inventory.
–Pricing & Tax Logic: Dedicated fields for wholesale and retail pricing, including settings to specify whether these prices already include tax.
–Product Attributes: Flexible fields that allow for specific product characteristics (e.g., color, size, or material) to be attached to an item.
–Inventory Controls: Settings that determine how a product is managed, such as whether the system should track stock levels, if the product is part of a bundle, or if it is currently active for sale.
–Operational Metadata: Information such as warranty periods, return limits, and validity dates that define the lifecycle and service terms of the product.
2.4Business Value

This feature provides a centralized and standardized way to manage product data, reducing manual entry errors and ensuring consistency across the organization. By capturing detailed pricing, tax, and inventory information upfront, the business can maintain accurate stock levels, streamline the sales process, and ensure that financial reporting remains precise.

3.  Data
3.1Overview

The "Add Product" feature allows users to create and store comprehensive product records within the Lumi ERP system. This functionality captures all necessary details—ranging from basic identification and pricing to logistics, tax settings, and visual assets—ensuring that every product is fully defined for inventory, sales, and reporting purposes.

3.2Step-by-Step Flow
1.Data Entry: The user inputs product information into the system, including core details (name, SKU, brand), pricing structures (wholesale, retail, MRP), and tax configurations.
2.Asset & Attribute Mapping: The system collects supplementary data, such as product images, custom attributes, physical dimensions (weight/volume), and warranty or return policy limits.
3.System Processing: The application assigns a unique identifier to the new product and organizes the provided information into the database structure.
4.Record Creation: The system saves the product record with a timestamp, enabling features like stock tracking, bundle management, and quick-access button configurations.
5.Confirmation: Once saved, the system retrieves the newly created record to confirm that the product has been successfully added to the inventory.
3.3Key Concepts
–SKU (Stock Keeping Unit): A unique identifier used to track individual products within the inventory.
–Pricing Tiers: The system supports multiple price points, including supply, wholesale, and retail prices, with options to specify if these prices include tax.
–Product Attributes: Flexible fields that allow for custom descriptions or specifications (e.g., color, size, or material) to be attached to a product.
–Logistics & Compliance: Settings that manage physical properties (weight/volume), warranty periods, and return limits to support supply chain operations.
–Operational Flags: Settings that control how a product behaves in the system, such as whether it is active, available for ordering, or eligible for stock tracking.
3.4Business Value

This feature provides a centralized, standardized way to manage the product catalog. By capturing granular data—such as tax codes, supplier details, and bundle configurations—the system ensures accurate financial reporting and streamlined inventory management. This reduces manual errors, improves the speed of order processing, and provides the flexibility needed to handle diverse product types within the ERP.
