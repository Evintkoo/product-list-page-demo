1.  Frontend
1.1Overview

The Flexible Voucher page provides a centralized view for managing "flexible" vouchers within the Lumi ERP system. This page allows users to view a comprehensive list of existing flexible vouchers, search for specific items using filters, and navigate to a dedicated form to create new vouchers. The interface is designed to ensure that only authorized users can access the data, maintaining security across the product management workflow.

1.2Step-by-Step Flow
1.Authentication Check: Upon loading the page, the system verifies the user's session. If the user is not logged in, they are automatically redirected to the login screen.
2.Data Retrieval: Once authenticated, the system automatically fetches all flexible vouchers to display in the table.
3.Filtering: Users can narrow down the list by entering a specific SKU or Name into the filter bar. Clicking the search button updates the table to show only the matching results.
4.Viewing Details: The table displays key information for each voucher, including pricing, validity dates, and location scopes. Users can click on a voucher's SKU to navigate to its specific details page.
5.Creating New Vouchers: Users can initiate the creation of a new flexible voucher by clicking the dedicated "New Voucher" button, which directs them to the creation form.
1.3Key Concepts
–Flexible Voucher: A specific category of voucher where parameters (such as price) may be determined at the point of sale rather than being fixed.
–Filter Bar: A search tool that allows users to refine the voucher list by SKU or Name, ensuring they only see relevant records.
–Status Badge: A visual indicator on each row that shows the current state of the voucher (e.g., Active or Expired).
–Open Price: A feature indicating that the voucher's monetary value is not fixed and can be set during the transaction.
–Location Scope: Information defining which stores or branches are authorized to sell, issue, or redeem a specific voucher.
1.4Business Value
–Operational Efficiency: By providing a dedicated view for flexible vouchers, staff can quickly locate and manage specific voucher types without sifting through unrelated product data.
–Improved Accuracy: The clear display of validity dates, location scopes, and status badges reduces the risk of errors during the issuance or redemption process.
–Streamlined Workflow: The integration of search filters and direct navigation to voucher details and creation forms minimizes the time spent navigating the system, allowing for faster administrative tasks.
2.  Logic
2.1Overview

The Flexible Voucher page provides a centralized view for managing and searching flexible vouchers within the Lumi ERP system. This feature ensures that only authorized users can access the list, allows for quick filtering by specific criteria, and presents voucher details in a clear, organized table format.

2.2Step-by-Step Flow
1.Authentication Check: When the page loads, the system verifies the user's session. If the user is not logged in, they are automatically redirected to the login page.
2.Data Retrieval: Once authenticated, the system automatically fetches all available "flexible" type vouchers.
3.Filtering: Users can refine the list by entering a specific SKU or Voucher Name and clicking the search button. The system then updates the table to show only the matching results.
4.Data Mapping: The system takes the raw voucher information and translates it into a user-friendly table format, ensuring that key details like pricing, validity dates, and location scopes are correctly displayed.
5.Display: The final list is rendered in the Vouchers Table, providing a clear overview of each voucher's status and usage rules.
2.3Key Concepts
–Flexible Voucher: A specific category of voucher managed within the ERP that allows for variable pricing or usage terms.
–SKU (Stock Keeping Unit): A unique identifier used to track specific voucher products.
–Location Scope: Internal settings that define where a voucher can be sold or redeemed; while these influence the voucher's behavior, they are managed behind the scenes.
–Authentication: The security process that ensures only verified users can view or search the voucher list.
2.4Business Value
–Operational Efficiency: By providing a dedicated page for flexible vouchers, staff can quickly locate and verify voucher details without searching through general product lists.
–Improved Accuracy: Standardized mapping rules ensure that voucher data—such as validity periods and member-only status—is presented consistently, reducing the risk of misinterpretation.
–Enhanced Security: The integrated authentication check ensures that sensitive voucher information is protected and only accessible to authorized personnel.
–Better Decision Making: Real-time search capabilities allow users to instantly filter vouchers by name or SKU, facilitating faster responses to customer inquiries or inventory audits.
3.  Data
3.1Overview

The Flexible Voucher Page is a dedicated management view within the Lumi ERP system designed to help users easily find and monitor "flexible" type vouchers. This feature provides a clear, organized table that displays essential voucher details—such as pricing, validity dates, and redemption locations—allowing staff to manage voucher inventory efficiently.

3.2Step-by-Step Flow
1.Page Initialization: When a user navigates to the page, the system verifies their login status. If authenticated, it automatically requests the list of all flexible vouchers.
2.Data Retrieval: The system fetches the voucher data from the database, ensuring only records categorized as "flexible" are retrieved.
3.Filtering: Users can refine the list by entering a specific SKU or voucher name into the search fields. Clicking the search button triggers a request to update the table with the filtered results.
4.Data Mapping: The system processes the raw voucher data, converting technical values (like "true/false" for member-only status) into user-friendly labels (like "Yes/No").
5.Display: The Vouchers Table Component populates with the processed data, showing key information such as price, validity periods, and status for each voucher.
3.3Key Concepts
–Flexible Voucher: A specific category of voucher within the system that allows for variable pricing or redemption rules.
–SKU (Stock Keeping Unit): A unique identifier used to track specific voucher products in the inventory.
–Open Price: A setting that indicates whether the voucher price is fixed or can be set at the time of sale.
–Location Scope: Internal data that defines where a voucher can be sold or redeemed; while this drives system logic, it is kept behind the scenes to keep the user interface clean.
–Member Only: A status flag indicating if the voucher is restricted to registered members only.
3.4Business Value
–Operational Efficiency: By providing a centralized, searchable list, staff can quickly locate specific vouchers without manually sorting through unrelated data.
–Improved Accuracy: Standardizing how voucher information is displayed (e.g., converting technical flags to "Yes/No") reduces the risk of misinterpretation by staff.
–Better Inventory Oversight: The clear display of validity dates and status allows managers to proactively monitor voucher lifecycles and ensure that active promotions are correctly configured.
