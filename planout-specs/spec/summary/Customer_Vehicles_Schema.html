1.  Data
1.1Overview

The Customer Vehicles feature allows the system to store, manage, and display detailed information about vehicles associated with a specific customer. This includes support for various vehicle types—such as cars, motorcycles, and heavy equipment—ensuring that service teams have the right technical data at their fingertips to provide accurate support and maintenance.

1.2Step-by-Step Flow
1.Form Setup: When a user opens the "Add Vehicle" form, the system automatically retrieves a list of available vehicle makes and models. This ensures the user can select from standardized options, keeping the data clean and consistent.
2.Data Entry: The user fills out the vehicle details. The form is dynamic: if "heavy equipment" is selected, additional fields (such as hour-meter readings and engine specifications) appear, while these are hidden for standard cars or motorcycles.
3.Submission: Once the user submits the form, the system saves the vehicle record, automatically linking it to the current customer and the user's store location.
4.Display: The system provides a paginated list of all vehicles linked to a specific customer. This list automatically translates internal codes into readable names (e.g., showing "Toyota" instead of a complex ID), making it easy for staff to identify the correct vehicle at a glance.
1.3Key Concepts
–Vehicle Metadata: The standardized list of makes and models used to populate dropdown menus, ensuring users don't have to type this information manually.
–Dynamic Form Logic: A feature that adjusts the input fields based on the type of vehicle selected, ensuring that only relevant information (like engine power for heavy machinery) is collected.
–Data Normalization: The process of linking vehicle records to specific customers and stores, which allows for accurate reporting and service history tracking.
–Pagination: A method of displaying large lists of vehicles in smaller, manageable chunks to keep the interface fast and easy to navigate.
1.4Business Value
–Improved Data Accuracy: By using standardized dropdowns for makes and models, we eliminate typos and inconsistent naming conventions.
–Operational Efficiency: Service staff can quickly access a customer's entire fleet history, reducing the time spent searching for vehicle details during service appointments.
–Tailored Maintenance: Because the system captures specific technical details (like engine specs or hour meters for heavy equipment), service teams can provide more precise maintenance recommendations and parts ordering.
–Scalability: The system is designed to handle large volumes of vehicle data per customer, ensuring that as our customer base grows, the platform remains performant and organized.
