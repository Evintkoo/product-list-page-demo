1.  Logic
1.1Overview

The Supplier List feature provides a structured way to manage and retrieve supplier information within the Lumi ERP system. It allows users to search, filter, and view supplier details, as well as update the status (active or inactive) of specific suppliers. All operations are strictly scoped to the user's company to ensure data security and relevance.

1.2Step-by-Step Flow
1.List Retrieval: When viewing the supplier list, the system accepts optional filters (such as name, phone, or status) and pagination settings (limit and offset) to return a manageable set of supplier records.
2.Detailed View: Users can request the full profile of a specific supplier by providing a unique identifier. This returns comprehensive information, including contact details, tax settings, credit terms, and accounting references.
3.Status Management: Users can update a supplier's status (e.g., marking them as inactive) by sending a request with the new status. The system confirms the update by returning the supplier's ID and the timestamp of the change.
4.Quick Lookup: For scenarios requiring only names (such as dropdown menus), the system provides a lightweight list of active supplier names, excluding unnecessary data to improve performance.
1.3Key Concepts
–Filtering: The ability to narrow down the supplier list using specific criteria like `isinternal`, `suppliercode`, `name`, `contactname`, `phone`, or `isactive`.
–Pagination: A mechanism to control the volume of data returned in a single request by setting a `limit` (number of records) and an `offset` (where to start in the list).
–Company Scoping: A security measure that ensures users only interact with supplier data belonging to their own organization, automatically applied to all requests.
–Status Toggle: A specific action to change a supplier's `is_active` state, which helps maintain accurate records without deleting historical data.
1.4Business Value
–Operational Efficiency: By providing flexible search and filtering, staff can quickly locate specific suppliers, reducing time spent navigating large datasets.
–Data Integrity: The system ensures that sensitive supplier information—such as tax numbers, credit limits, and accounting references—is retrieved and updated in a controlled, consistent manner.
–Performance Optimization: The inclusion of a "names-only" lookup feature ensures that common tasks, like selecting a supplier from a list, remain fast and responsive.
–Security: Automatic company scoping prevents accidental cross-company data access, maintaining strict organizational boundaries.
