1.  Frontend
1.1Overview

The Product List feature allows you to define which specific products are eligible for a voucher. You can manage these products in two ways: by selecting them individually from a list or by uploading a file to add a large number of products at once. This ensures flexibility whether you are applying a voucher to a single item or an entire catalog.

1.2Step-by-Step Flow
1.Accessing the Selection: When you choose the "By Product List" option for a voucher, the product selection area becomes available.
2.Individual Selection: You can manually pick specific products from the provided list to include in your voucher.
3.Downloading a Template: If you have many products to add, you can click the "Download Example File" link to get a template. This file shows you exactly how to format your data so the system can read it correctly.
4.Bulk Uploading: Once your file is ready, click the "Upload Products" button to select your document. The system will automatically process the file and add the products to your voucher.
5.Validation: The system checks your file during the upload process to ensure it is in the correct format (CSV or Excel) before adding the items.
1.3Key Concepts
–Bulk Upload: A time-saving feature that allows you to import a list of products from a file rather than adding them one by one.
–Sample Template: A pre-formatted file provided by the system that acts as a guide to ensure your data is uploaded successfully without errors.
–Product Selection Field: The primary interface where you view and manage the specific items currently assigned to a voucher.
1.4Business Value

This feature significantly reduces manual data entry time for users managing large-scale promotions. By providing a standardized template and a bulk upload option, it minimizes human error and ensures that voucher application is accurate, efficient, and scalable, regardless of the number of products involved.
