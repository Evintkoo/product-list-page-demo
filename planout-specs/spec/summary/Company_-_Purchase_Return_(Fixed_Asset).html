1.  Frontend
1.1Overview

The "Purchase Return (Fixed Asset)" feature provides a centralized dashboard for managing the return of fixed assets to suppliers. This screen allows users to view a list of all existing return records, filter them by specific criteria, and easily navigate to detailed information for any individual return.

1.2Step-by-Step Flow
1.Access the View: The user navigates to the Inventory section and selects the "Fixed Asset" tab to view the list of purchase returns.
2.Apply Filters: The user can narrow down the list by entering a specific Document Number, selecting a date range (From/To), choosing a supplier, or filtering by the current status (e.g., Draft, Approved).
3.Execute Search: Once the desired filters are set, the user clicks the "Search" button to refresh the table with the relevant records.
4.Review Data: The system displays a table showing key details for each return, including the document number, important dates (creation, sending, and approval), the supplier name, and the current status.
5.Navigate to Details: If the user needs to see more information about a specific return, they can click on the "Document Number" link to open the full details page for that record.
6.Manage Pagination: If there are many records, the user can use the pagination controls at the bottom of the screen to browse through the list in groups of 20.
7.Create New Return: If a new return needs to be initiated, the user can click the "New Purchase Return" button to be redirected to the creation page.
1.3Key Concepts
–Document Number: A unique, system-generated identifier for each return record that serves as the link to view more details.
–Status Badge: A visual indicator showing the current lifecycle stage of a return, such as Draft, Sent, Approved, or Cancelled.
–Filter Bar: A set of search tools that allows users to find specific records without needing to scroll through the entire list.
–Pagination: A navigation tool that breaks large lists into manageable pages (20 records per page) to ensure the screen remains easy to read.
1.4Business Value

This feature streamlines the fixed asset return process by providing a clear, organized view of all return activities. By enabling quick filtering and easy access to document details, it reduces the time spent searching for records and helps staff maintain accurate tracking of asset returns, ensuring that the status of every return is transparent and up-to-date.

2.  Logic
2.1Overview

This feature provides an automated view of "Purchase Returns" for fixed assets within the Lumi ERP system. When a user navigates to the Purchase Return page, the system automatically verifies their identity and immediately displays a list of all existing return records without requiring the user to manually trigger a search.

2.2Step-by-Step Flow
1.Security Check: As soon as the page loads, the system checks if the user is logged in. If the user is not authorized, they are automatically redirected to the login screen.
2.Data Retrieval: Once the user is verified, the system automatically requests the list of purchase returns from the database.
3.Data Mapping: The system organizes the raw data into a readable table format, matching specific internal records (such as document codes, dates, and status) to the corresponding columns in the user interface.
4.Display: The final list is rendered on the screen, providing the user with an immediate overview of all purchase return activity.
2.3Key Concepts
–Authentication: A security step that ensures only logged-in users can view sensitive inventory data.
–Automated Loading: A user-experience feature that populates the screen with data immediately upon arrival, removing the need for manual search actions.
–Data Mapping: The process of translating technical database information into clear, labeled columns that are easy for staff to read and understand.
2.4Business Value

This feature improves operational efficiency by providing instant visibility into fixed asset returns. By automating the data retrieval process, staff members save time and reduce manual effort, allowing them to monitor the status of returns—such as when they were created, sent, or approved—without unnecessary clicks or delays.

3.  Data
3.1Overview

The Purchase Return (Fixed Asset) feature provides a centralized view for tracking the return of company assets to suppliers. This tool allows your team to monitor the lifecycle of a return—from its initial creation to its final approval—ensuring that all asset-related returns are properly documented and accounted for within the Lumi ERP system.

3.2Step-by-Step Flow
1.Request Data: The system retrieves a list of all purchase returns specifically categorized as "Fixed Assets."
2.Data Retrieval: The system pulls the relevant records from the database, including details about the supplier and the current status of the return.
3.Information Mapping: The system organizes the raw data into a clear, readable format for your dashboard, matching specific details to the appropriate columns in your view.
4.Display: The final list is presented in the interface, showing the document number, key dates (creation, submission, and approval), the supplier involved, and the current status of the return.
3.3Key Concepts
–Fixed Asset: A long-term physical asset (such as machinery, equipment, or furniture) that the company has purchased and may need to return to a supplier.
–Purchase Return: The formal process of sending an item back to a supplier, which requires tracking to ensure the company receives credit or a replacement.
–Status Tracking: A way to see exactly where a return is in the process, such as whether it is still being prepared, has been sent, or has been officially approved.
–Reference Code: A unique identifier assigned to each return document, making it easy to search for and reference specific transactions.
3.4Business Value

This feature improves inventory accuracy and financial oversight by providing a transparent audit trail for asset returns. By digitizing this process, your team can quickly identify the status of any return, reduce administrative errors, and ensure that the company’s fixed asset records remain up-to-date and accurate for reporting and accounting purposes.
