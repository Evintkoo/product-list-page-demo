1.  Data
1.1Overview

This feature provides a standardized way for the system to organize and share information about sales deliveries. By defining a clear structure (a "schema") for this data, we ensure that the application can consistently display delivery details—such as customer information, warehouse locations, and specific product items—across different parts of the software. This setup supports both searching for a list of deliveries and viewing the comprehensive details of a single delivery.

1.2Step-by-Step Flow
1.Filtering and Searching: When you need to find specific deliveries, the system allows you to search by reference codes, warehouse location, or the current status of the delivery (e.g., draft, confirmed, or delivered).
2.Retrieving Delivery Details: When you select a specific delivery to view, the system fetches the "header" information, which includes the primary details like the customer, warehouse, and overall financial totals.
3.Fetching Line Items: Simultaneously, the system pulls the list of individual products associated with that specific delivery.
4.Assembling the View: The system combines the header information and the list of products into a single, organized package to be displayed on your screen.
5.Security Check: Throughout this process, the system verifies that the requested delivery belongs to your company, ensuring that sensitive data remains private and secure.
1.3Key Concepts
–Sales Delivery: A record representing the shipment of goods to a customer, containing both high-level summary information and a list of specific items included in the shipment.
–Workflow State: The current stage of a delivery in its lifecycle, such as "draft" (in progress), "confirmed" (ready for shipment), "delivered" (completed), or "voided" (cancelled).
–Schema: A blueprint that defines exactly what information is included in a record, ensuring that every delivery is formatted the same way every time it is accessed.
–Multi-tenant Security: A protective measure that ensures users can only view data belonging to their own company, preventing unauthorized access to other organizations' records.
1.4Business Value
–Data Consistency: By using a standardized format, all parts of the ERP system "speak the same language," reducing errors when moving data between different screens or reports.
–Improved Searchability: The ability to filter by status and reference codes allows staff to quickly locate specific shipments, saving time during daily operations.
–Enhanced Security: The built-in company-level filtering ensures that sensitive sales and inventory data is strictly siloed, maintaining compliance and data privacy.
–Operational Clarity: Providing a complete view of a delivery—including both the summary and the specific items—gives staff the full context they need to manage orders effectively.
