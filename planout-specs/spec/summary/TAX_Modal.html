1.  Frontend
1.1Overview

The Tax Modal is a dedicated interface component within the Lumi ERP system designed to help users manage and update a customer's tax-related information. This feature provides a centralized, user-friendly window where staff can input and save essential tax identification numbers, ensuring that customer records remain accurate for financial and regulatory compliance.

1.2Step-by-Step Flow
1.Access the Modal: The user opens the Tax Modal, which displays a clear header labeled "TAX" accompanied by a percentage icon to indicate its purpose.
2.Input Data: The user enters the relevant tax details into three specific fields: NPWP (Tax Identification Number), NPPKP (VAT-registered taxpayer number), and NITKU (Tax Identity Number).
3.Real-time Validation: As the user types, the system automatically checks the information. For example, if the NPWP number is entered, the system ensures it meets the required length to prevent common entry errors.
4.Submit Changes: Once the information is entered correctly, the user clicks the "Save Changes" button. If any errors are detected, the save button is disabled to prevent invalid data from being sent to the system.
5.Confirmation: Upon a successful save, the system updates the customer's profile with the new tax settings and closes the modal.
1.3Key Concepts
–NPWP: The primary tax identification number used for identifying a taxpayer in the system.
–NPPKP: A specific identifier for customers who are registered for Value Added Tax (VAT).
–NITKU: A secondary tax identity number used for specific tax reporting requirements.
–Input Validation: An automated safety check that ensures data is formatted correctly before it is saved, reducing the risk of errors in financial records.
1.4Business Value

This feature streamlines the administrative process of maintaining customer tax data. By providing a structured and validated input method, it reduces manual data entry errors and ensures that the ERP system holds reliable, up-to-date tax information. This consistency is critical for accurate invoicing, tax reporting, and maintaining compliance with local financial regulations.
