1.  Frontend
1.1Overview

The Main Menu is the primary navigation header for the ERP system. It acts as the central hub for users to move between different areas of the software, manage their personal account settings, view system alerts, and quickly find specific information. The design ensures a clean interface by using dropdown menus for secondary actions, keeping the workspace uncluttered.

1.2Step-by-Step Flow
1.Product Navigation: Clicking the "Products" item opens a sub-menu, allowing users to access specific product-related categories.
2.Profile Management: Clicking the user avatar toggles a menu for account settings and sign-out options. If other menus (like notifications) are open, they will automatically close to keep the interface tidy.
3.Alerts: Clicking the notification bell icon reveals a list of unread alerts. Similar to the profile menu, this will close other open dropdowns to prevent overlap.
4.Global Search: Users can type into the search bar to find information. To ensure smooth performance, the system waits for the user to finish typing (at least 3 characters) before displaying results.
5.General Navigation: Clicking any main navigation item updates the active tab to show the user where they are and redirects them to the corresponding page.
6.Sales Access: A dedicated button provides a direct shortcut to the Sales list page.
1.3Key Concepts
–Dropdown Menus: Interactive containers that appear only when needed to keep the header clean.
–Active Tab State: A visual indicator that highlights the user's current location within the system.
–Debounced Search: A performance feature that waits for a brief pause in typing before searching, preventing unnecessary system load.
–Smart Toggling: A behavior where opening one menu automatically closes others, ensuring the user is never overwhelmed by multiple open windows.
1.4Business Value
–Improved Efficiency: By providing a centralized navigation bar and quick-access shortcuts (like the Sales page), users can move through the ERP system with fewer clicks.
–Enhanced User Experience: The use of smart, self-closing menus and a responsive search bar creates a professional, intuitive environment that reduces user frustration.
–System Clarity: The "Active Tab" feature ensures users always know which section of the ERP they are currently working in, reducing navigation errors.
