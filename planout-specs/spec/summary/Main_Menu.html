1.  Frontend
1.1Overview

The Main Menu is a persistent, "sticky" navigation bar located at the top of every page in the Lumi ERP system. It serves as the central hub for users to navigate between core business modules, manage their account settings, view notifications, and perform system-wide searches. Because it is "sticky," it remains visible at the top of the screen even as the user scrolls through long pages, ensuring constant access to essential tools.

1.2Step-by-Step Flow
1.Session Verification: When a user loads any page, the system automatically checks if they are logged in. If the session is valid, the user's name is displayed; if not, the user is redirected to the login page.
2.Navigation: The user selects a top-level category (e.g., Customers, Products, Inventory). The system updates the view to display the specific sub-menu relevant to that selection.
3.Search: The user types a query into the search bar. To ensure system performance, the search only triggers after the user has finished typing (a short delay is applied).
4.Notifications: The user clicks the notification bell to toggle a dropdown list of alerts.
5.Profile Management: The user clicks their name to reveal a menu containing account settings and a logout option.
6.Logout: If the user selects "Logout," the system clears the session and returns them to the login page.
1.3Key Concepts
–Sticky Header: A design approach where the navigation bar stays fixed at the top of the browser window, providing constant access to navigation regardless of how far down the page a user scrolls.
–Debounced Search: A performance optimization technique that waits for the user to stop typing for a brief moment before sending the search request to the server, preventing unnecessary system load.
–Session Management: The automated process of verifying a user's identity upon page load and handling secure sign-outs to protect company data.
–Contextual Sub-menus: Dynamic menus that change based on the primary category selected, keeping the interface clean by only showing relevant options.
1.4Business Value
–Improved Efficiency: By keeping the navigation bar visible at all times, users can switch between business modules (like Finance or Inventory) instantly without needing to scroll back to the top of the page.
–Enhanced User Experience: The search feature is optimized to be responsive without slowing down the system, and the clear separation of modules reduces clutter.
–Security and Control: Automated session checks ensure that only authorized users can access the ERP, while the centralized logout process ensures that user sessions are terminated correctly.
2.  Logic
2.1Overview

The Main Menu header is the primary navigation component for the Lumi ERP system. It is designed to ensure that only authenticated users can access the system while providing a personalized experience. The header automatically identifies who is logged in, displays their profile information, and provides a secure way to end their session.

2.2Step-by-Step Flow
1.Session Verification: As soon as a page loads, the system automatically checks if the user has an active session.
2.Identity Retrieval: If the session is valid, the system retrieves the user's details—specifically their name, email, and assigned role—to display in the header.
3.Access Control: If the system cannot verify the user (or if the session has expired), it automatically redirects them to the login page to protect sensitive data.
4.Logout Process: When a user clicks the "Logout" button, the system invalidates their current session and redirects them back to the login page.
2.3Key Concepts
–Session Verification: The automated background check that confirms a user’s identity and permissions every time they access a page.
–User Profile Mapping: The process of taking raw system data (such as a user's name and role) and displaying it clearly within the header interface.
–Secure Redirection: A safety mechanism that forces an unauthenticated user to the login screen, preventing unauthorized access to the ERP.
2.4Business Value
–Enhanced Security: By automatically verifying sessions and handling logouts, the system ensures that only authorized personnel can interact with the ERP, reducing the risk of unauthorized access.
–Improved User Experience: Users are greeted with their personalized information immediately upon loading a page, creating a seamless and professional interface.
–Operational Efficiency: The automated session management reduces the need for manual intervention, ensuring that users are always directed to the correct screen based on their login status.
3.  Data
3.1Overview

The Main Menu feature serves as the primary navigation header for the Lumi ERP system. Its main purpose is to identify the currently logged-in user and display a personalized greeting, ensuring that only authenticated users can access the system's features.

3.2Step-by-Step Flow
1.Initialization: When a user opens any page in the ERP, the system automatically checks their current login status.
2.Verification: The system verifies the user's session in the background.
3.Access Control:

* If the session is valid, the system retrieves the user's name and displays it in the header.

* If the session is invalid or expired, the system automatically redirects the user to the Login page.

4.Display: Once verified, the header renders the Lumi ERP logo and a personalized "Welcome" message for the user.
3.3Key Concepts
–Session Verification: A security check that confirms a user is currently logged in before allowing them to view the page content.
–Header Skeleton: A temporary visual placeholder shown to the user while the system is in the process of verifying their identity.
–Automatic Redirection: A security feature that ensures unauthorized users are immediately sent to the login screen to protect system data.
3.4Business Value
–Security: By automatically validating sessions, the system prevents unauthorized access to sensitive ERP data.
–User Experience: The personalized greeting provides a professional and welcoming interface, while the automatic redirection ensures users are always in the correct state to perform their work.
–Efficiency: The system handles authentication checks in the background, allowing for a seamless transition between pages without requiring manual user intervention.
