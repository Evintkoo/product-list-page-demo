1.  Frontend
1.1Overview

The Suppliers Menu is a navigation component designed to help users easily manage and access supplier-related tasks within the Lumi ERP system. It provides a clean, organized way to view supplier information by using an expandable menu structure, ensuring that key actions—such as viewing the supplier list or adding a new supplier—are always just a click away.

1.2Step-by-Step Flow
1.Initial Load: When the user accesses the system, the "Supplier" menu is selected by default and is already expanded to show available options.
2.Interaction: The user clicks on the "Supplier" menu item.
3.Toggle Action: The system checks if the menu is currently expanded or collapsed. If it is expanded, clicking it will hide the sub-menu; if it is collapsed, clicking it will reveal the sub-menu.
4.Visual Feedback: The menu displays a small icon (a chevron) that changes direction to indicate whether the sub-menu is currently open or closed.
5.Navigation: Once the sub-menu is visible, the user can select specific tasks, such as viewing the "Supplier List" or choosing to "Create Supplier," which then directs the user to the corresponding page.
1.3Key Concepts
–Accordion Menu: A design pattern where a menu item can be expanded or collapsed to show or hide additional sub-options, helping to keep the interface uncluttered.
–Active State: A visual indicator that highlights which section of the menu the user is currently interacting with or viewing.
–Sub-menu: A secondary list of specific actions or pages that are grouped under a primary category (in this case, "Supplier").
–Chevron Icon: A small arrow symbol used to visually signal that a menu item contains hidden content that can be toggled.
1.4Business Value

This feature improves user efficiency by grouping all supplier-related activities into a single, intuitive location. By using an accordion-style navigation, the system reduces visual noise, allowing users to focus on the specific task at hand without being overwhelmed by too many options at once. This streamlined approach ensures a consistent and professional user experience across the ERP platform.
