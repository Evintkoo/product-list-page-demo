1.1Overview

The "Customer Details Card" is a central component of the Wholesale Customer registration page. It provides a structured form for users to input and manage essential information about a new wholesale customer, including their identification, primary contact details, and banking information. The component ensures data quality by performing real-time validation on critical fields.

1.2Step-by-Step Flow
1.Customer Identification: The user enters the customer's basic profile information, including their name (required), customer code, phone number, email address, national ID (KTP), regional area, and any additional notes.
2.Contact Information: The user provides specific details for the primary contact person, including their full name, phone number, email, job position, department, region, country (via a dropdown menu), and physical address.
3.Banking Details: The user enters the customer's banking information into a dedicated text area.
4.Real-Time Validation: As the user types, the system automatically checks the data. If the customer name is missing or if an email address (for either the customer or the contact person) is entered in an incorrect format, the system immediately displays an error message to guide the user.
1.3Key Concepts
–Data Validation: A built-in safety check that ensures required fields are filled and that email addresses follow the correct format before the form is submitted.
–State Management: The system’s ability to "remember" and track all the information entered into the form fields in real-time.
–Input Fields: Standard text boxes and dropdown menus used to capture specific pieces of information, such as names, codes, and locations.
–Text Area: A larger, multi-line input box designed for longer entries, such as general notes or detailed banking instructions.
1.4Business Value
–Data Accuracy: By enforcing required fields and validating email formats, the system prevents incomplete or incorrect data from entering the database, reducing administrative cleanup later.
–Operational Efficiency: Consolidating customer, contact, and banking information into a single, organized card streamlines the onboarding process for new wholesale accounts.
–User Experience: Real-time feedback allows users to correct mistakes immediately while they are still filling out the form, rather than waiting until the end of the process to discover errors.
