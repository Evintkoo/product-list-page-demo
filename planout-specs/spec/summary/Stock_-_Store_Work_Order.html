1.  Frontend
1.1Overview

The "Work Orders" feature provides a dedicated view within the Inventory module to track and manage stock orders specifically linked to service work orders. This interface allows users to see a comprehensive list of these orders, filter them by specific criteria, and easily navigate to the details of individual stock or service records.

1.2Step-by-Step Flow
1.Initial Load: When you navigate to the "Work Orders" tab, the system automatically retrieves all stock orders associated with service work orders.
2.Search and Filter: You can narrow down the list using the search toolbar. You may filter by specific stock order codes, service work order codes, date ranges, store or warehouse locations, and current status.
3.Refining Results: Once you enter your desired criteria and click "Search," the system updates the table to display only the records that match your filters.
4.Data Display: The table presents key information for each order, including dates, locations, status, and financial amounts.
5.Navigation: You can click on a specific row to open the detailed view for that stock order or its associated service work order.
1.3Key Concepts
–Work Orders Tab: A specialized view within the Inventory module that filters all stock activity to show only those related to service work.
–Search Toolbar: A set of input fields that allows you to query the database for specific orders without needing to browse the entire list.
–Status: The current lifecycle stage of an order (e.g., draft, confirmed, sent, or received), which helps you track progress.
–Nullable Fields: Certain information, such as store or warehouse names, may appear blank if the original record is no longer available; the system handles this gracefully to ensure the table remains readable.
–Mapping Rules: The logic that ensures data from the system is correctly organized into the table columns (e.g., ensuring the "Date" column always shows the correct creation date).
1.4Business Value

This feature streamlines inventory management by centralizing service-related stock orders in one place. By providing robust filtering and clear visibility into order status and amounts, it reduces the time spent searching for information and helps staff quickly identify which service work orders are pending, in progress, or completed. This improves operational efficiency and ensures that inventory levels are accurately aligned with service requirements.

2.  Logic
2.1Overview

The "Store Work Order" feature provides a dedicated view within the inventory system to track stock orders specifically linked to service work orders. This interface allows users to search, filter, and monitor the status of these orders, ensuring that inventory movements related to service tasks are transparent and easily accessible.

2.2Step-by-Step Flow
1.Initial Load: When you open the Work Orders tab, the system automatically retrieves a list of stock orders filtered specifically for service work orders.
2.Applying Filters: You can use the search toolbar to narrow down results. You may filter by specific stock order codes, service work order codes, date ranges, store locations, warehouse locations, or current workflow status.
3.Data Retrieval: Once you click "Search," the system sends your criteria to the database. Only the filters you have actively filled in are applied to the search.
4.Displaying Results: The system receives the data and populates the table. Each row represents a stock order, displaying key details such as the order amount, receipt status, the store and warehouse involved, and the user who last updated the record.
5.Navigation: You can click on the Stock Order reference or the Service Work Order reference within any row to jump directly to the details of that specific record.
2.3Key Concepts
–Stock Order: A request for inventory items that need to be moved or allocated.
–Service Work Order: The specific maintenance or service task that triggered the need for these inventory items.
–Workflow State: The current progress of the order (e.g., pending, in-progress, or completed).
–Filtering: The ability to narrow down a large list of orders based on specific criteria like dates, locations, or status to find exactly what you need.
–Data Mapping: The process where the system takes raw information from the database and organizes it into the clear, readable columns you see in your table.
2.4Business Value

This feature streamlines inventory management by bridging the gap between service tasks and stock requirements. By providing a centralized, searchable view of work-related stock orders, staff can:

* Improve Accountability: Easily see who last updated an order and its current status.

* Enhance Efficiency: Quickly locate specific orders without manually searching through general inventory logs.

* Better Coordination: Ensure that the right parts are arriving at the right store or warehouse at the right time to support ongoing service work.

3.  Data
3.1Overview

The "Store Work Order" feature provides a dedicated view within the Lumi ERP system to track and manage stock orders specifically linked to service work orders. This tool allows staff to search, filter, and monitor the status of inventory movements associated with service tasks, ensuring that parts and materials are accounted for from the warehouse to the store.

3.2Step-by-Step Flow
1.Initiate Search: The user enters criteria into the search toolbar (such as specific order codes, date ranges, store/warehouse locations, or status).
2.Apply Filters: The system automatically scopes the search to "service work orders" and applies any additional filters provided by the user.
3.Data Retrieval: The system queries the inventory database to find all matching stock orders.
4.Information Consolidation: The system gathers related details, including the names of the store, warehouse, and the user who last updated the record.
5.Display Results: The retrieved data is presented in a table, where each row represents a stock order.
6.Navigation: Users can click on links within the table to open the specific stock order or the original service work order for further details.
3.3Key Concepts
–Stock Order: A record tracking the movement or request of inventory items.
–Service Work Order: The specific service-related task that triggered the need for inventory.
–Workflow State: The current status of the order (e.g., pending, in progress, or completed).
–Reference Path: A direct link that allows users to jump from the inventory list back to the original service request.
–Updater: The individual user responsible for the most recent change to the order record.
3.4Business Value

This feature streamlines inventory management by centralizing all stock-related activities tied to service work. By providing clear visibility into order statuses, locations, and associated service tasks, it reduces manual tracking efforts, minimizes errors in inventory allocation, and ensures that service teams have the materials they need to complete their work on time.
