1.  Frontend
1.1Overview

The Suppliers List page provides a centralized dashboard for managing your organization's supplier database. It allows users to view, search, and filter supplier records, as well as navigate to specific supplier details for further management. The page is designed to help you quickly locate supplier information and perform essential administrative tasks like adding new suppliers or updating existing ones.

1.2Step-by-Step Flow
1.Initial Load: When you first open the page, the system automatically displays a list of external suppliers.
2.Navigation: You can toggle between "Supplier" (external) and "Internal" views using the navigation tabs to switch the list content.
3.Filtering: You can narrow down the list by entering specific criteria into the filter bar, such as Supplier Code, Name, Contact Name, Phone, or Status (Active/Inactive).
4.Search: After entering your criteria, click the "Search" button to refresh the table with the filtered results.
5.Viewing Details: You can click on a supplier's Code or Name to be redirected to their specific detail page.
6.Managing Records:

* Click the "New Supplier" button to create a new entry.

* Click the "Edit" button on any row to update that supplier's information.

* Click the "Activate" or "Deactivate" button to change the status of a supplier record.

1.3Key Concepts
–Supplier List: The primary table view that displays key supplier data, including contact information, tax details, and purchase order permissions.
–Filter Bar: A set of input fields that allows you to refine the list based on specific attributes, helping you find records faster.
–Internal vs. External: A categorization toggle that separates your internal suppliers from your external business partners.
–Pagination: A system feature that organizes large lists of suppliers into manageable pages to ensure the application remains fast and easy to navigate.
–Status Toggle: A quick-action feature that allows you to switch a supplier between "Active" and "Inactive" states directly from the list.
1.4Business Value

This feature streamlines supplier management by providing a single, searchable interface. By allowing users to quickly filter and access supplier details, the page reduces the time spent searching for information. Additionally, the ability to manage supplier status and access edit/add functions directly from the list improves operational efficiency and ensures that your supplier database remains accurate and up-to-date.

2.  Logic
2.1Overview

The Suppliers List Page provides a centralized view for managing external business partners. This feature allows users to browse, search, and filter through the company's supplier database. The interface is designed to be intuitive, displaying key contact and operational details in a clean table format, while providing quick access to status management actions.

2.2Step-by-Step Flow
1.Initial Load: When the page is first opened, the system automatically retrieves the first page of external suppliers.
2.Data Retrieval: The system fetches supplier records, excluding internal entities to ensure the list remains focused on external partners.
3.Search and Filter: Users can input search terms to narrow down the list by supplier name or code. The system updates the view based on these criteria.
4.Pagination: As the user navigates through the list, the system loads data in segments (pages) to maintain optimal performance.
5.Data Formatting: The system processes raw supplier information into a user-friendly table, combining address and country details and determining the appropriate "Activate" or "Deactivate" button label based on the supplier's current status.
6.Interaction: Users can perform actions directly from the table, such as editing details or toggling the active status of a supplier.
2.3Key Concepts
–Supplier List: A comprehensive table displaying essential information including contact details, tax numbers, and purchase order permissions.
–Search/Filter: Tools that allow users to quickly locate specific suppliers by name or unique identification code.
–Pagination: A method of breaking the supplier list into manageable pages to ensure the page remains fast and easy to read.
–Status Management: A dynamic feature that allows users to toggle a supplier between "Active" and "Inactive" states directly from the list.
–External Supplier: The scope of the list is limited to external partners, ensuring internal records do not clutter the view.
2.4Business Value

This feature streamlines procurement and vendor management by providing a single, searchable source of truth for all external suppliers. By automating the display of contact and operational data, it reduces the time staff spend searching for vendor information. Furthermore, the ability to manage supplier status directly from the list improves operational efficiency and ensures that only authorized vendors are available for purchase orders.
