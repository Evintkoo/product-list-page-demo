1.  Data
1.1Overview

This feature provides a structured way to retrieve a list of Sales Quotations within the Lumi ERP system. It allows users to view, search, and filter their company's quotations, ensuring that the information is organized, easy to navigate, and secure by restricting access to company-specific data.

1.2Step-by-Step Flow
1.Request Initiation: The system receives a request to view the list of sales quotations. It automatically identifies the user's company to ensure they only see relevant records.
2.Applying Filters: The system checks for any user-provided criteria, such as a specific document number, customer name, sales order association, or current status (e.g., "draft" or "sent").
3.Data Retrieval: The system queries the database to find all matching quotations. During this process, it links the quotation to the user who last updated it, ensuring the "Updated By" name is displayed correctly.
4.Sorting and Pagination: The results are sorted based on the user's preference (e.g., by date or document number) and broken into manageable pages to ensure the application remains fast and responsive.
5.Response Delivery: The system returns the final list of quotations along with a summary of the total count, allowing the user interface to display the data and pagination controls accurately.
1.3Key Concepts
–Pagination: A method of breaking a large list of records into smaller, manageable chunks (pages) to improve performance and readability.
–Filtering: The ability to narrow down a large list of quotations based on specific criteria like status, customer, or document number.
–Workflow State: The current stage of a quotation in its lifecycle, such as "draft," "sent," "accepted," or "converted."
–Data Security: The system automatically scopes all data requests to the authenticated company, preventing users from accessing information belonging to other organizations.
–Denormalization: Storing certain information (like the customer's name) directly with the quotation record to make searching and displaying the list faster.
1.4Business Value

This feature empowers sales teams to efficiently manage their pipeline by providing a clear, searchable view of all active and historical quotations. By enabling quick filtering and sorting, users can easily track the status of their documents, identify which quotations are ready for follow-up, and see which have successfully converted into sales orders. This visibility helps reduce administrative overhead and improves the speed of the sales cycle.
