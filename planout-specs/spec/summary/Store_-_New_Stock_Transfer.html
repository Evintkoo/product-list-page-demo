1.  Frontend
1.1Overview

The "New Stock Transfer" feature provides a dedicated page within the Inventory module to initiate the movement of goods between two locations. This page allows users to create a draft transfer request, specify the source and destination stores, select the products to be moved, and define the quantities. The system provides real-time visibility into current stock levels and costs to ensure accuracy before the transfer is finalized.

1.2Step-by-Step Flow
1.Initialization: Upon opening the page, the system verifies your login status and automatically populates the location lists. The transfer type defaults to "Sent."
2.Header Setup: You select the source location (where goods are leaving) and the destination location (where goods are arriving). You may also add an optional reference code, due date, and notes.
3.Adding Products: You add products to the transfer list. As you search for items, the system automatically displays the current stock levels at both the source and destination, along with the average cost at the source location.
4.Defining Quantities: For each product, you enter the specific quantity you wish to transfer. The system automatically calculates the total cost for that line item and updates the overall transfer cost.
5.Bulk Upload (Optional): If you have a large list of items, you can use the Upload Manager to import products and quantities from a file instead of adding them manually.
6.Validation & Saving: Once the form is complete, you click "Save." The system validates that the locations are different, the product list is not empty, and all transfer quantities are greater than zero. If valid, the transfer is created as a "Draft" and you are redirected to the document's detail page.
1.3Key Concepts
–Source/Destination Locations: The specific stores or warehouses involved in the movement of stock.
–Stock Snapshot: Real-time data showing how much of a product is currently available at a location, provided to help you make informed transfer decisions.
–Transfer Quantity: The specific number of units you intend to move; this is the primary input required for each product line.
–Draft Status: The initial state of a new transfer document, indicating it has been created but not yet processed or approved.
–Average Cost: The unit cost of a product at the source location, used to calculate the total financial value of the items being transferred.
1.4Business Value

This feature streamlines inventory management by providing a controlled, error-resistant way to move stock. By requiring users to select valid locations and providing real-time visibility into stock levels and costs, the system prevents common errors—such as transferring items that aren't in stock or selecting the same location for both ends of the transfer. The ability to save as a "Draft" allows for flexible workflows, ensuring that documentation can be prepared and reviewed before the physical movement of goods is officially confirmed.

2.  Logic
2.1Overview

The "New Stock Transfer" feature provides a dedicated page for users to initiate the movement of inventory between two locations. This page ensures that stock transfers are accurately recorded, validated, and tracked from the moment they are created as a draft.

2.2Step-by-Step Flow
1.Authentication & Setup: When the page loads, the system verifies the user is logged in. It then populates the "From" and "To" location dropdowns and sets default values for the transfer type, leaving other fields blank.
2.Adding Products: Users can add items to the transfer by searching for products. The search is restricted to the selected "From" location to ensure accurate inventory data.
3.Real-time Guidance: As products are added, the system displays the current stock levels at both the source and destination, along with the average cost at the source. These figures act as a reference for the user.
4.Quantity Adjustments: As the user enters the quantity to be transferred, the system automatically calculates the total cost for that line item and updates the overall total cost for the entire transfer.
5.Submission: Once the user clicks "Save," the system validates the request (e.g., ensuring the source and destination are different and the table is not empty).
6.Completion: Upon successful validation, the transfer is created as a "Draft," and the user is automatically redirected to the new document's detail page.
2.3Key Concepts
–Source Location: The warehouse or store from which the inventory is being moved.
–Destination Location: The warehouse or store receiving the inventory.
–Product Lookup: A search tool that helps users find items and provides a snapshot of current stock levels and costs to assist in decision-making.
–Draft Status: The initial state of a stock transfer document, indicating it has been created but not yet finalized or processed.
–Validation: Automated checks performed by the system to prevent errors, such as selecting the same location for both "From" and "To" or submitting an empty transfer.
2.4Business Value

This feature streamlines inventory management by providing a controlled, error-resistant process for moving stock. By automating cost calculations and providing real-time visibility into stock levels at both locations, it reduces manual data entry errors and ensures that inventory records remain accurate and consistent across the organization.

3.  Data
3.1Overview

The "New Stock Transfer" feature allows users to move inventory items between different locations within the Lumi ERP system. This page provides a structured way to document which products are being moved, the quantity involved, and the origin and destination points. When a transfer is saved, the system automatically records the transaction details and captures the current cost of the items to ensure accurate financial tracking.

3.2Step-by-Step Flow
1.Data Entry: The user fills out the transfer header (source location, destination location, date, reference number, and notes) and adds items to the product table, specifying the product and the quantity to be moved.
2.Validation: When the user clicks "Save," the system checks for errors. It ensures the source and destination locations are different, that at least one item is included, and that all transfer quantities are greater than zero.
3.Processing: If valid, the system creates a new "Draft" transfer record. It automatically looks up the current cost of each product and saves that price as a permanent "snapshot" for this specific transfer.
4.Confirmation: Once the data is successfully saved, the system redirects the user to the newly created transfer document, where they can review the details in its initial "Draft" status.
5.Error Handling: If any validation rules are not met, the system stops the process, keeps the form open, and displays a message explaining why the transfer could not be saved.
3.3Key Concepts
–Stock Transfer: A formal record of moving specific quantities of products from one designated location to another.
–Draft Status: The initial state of a new transfer, allowing users to review or edit the information before it is finalized or processed.
–Snapshot Cost: A record of the product's cost at the exact moment the transfer is created, which preserves financial accuracy even if the product's market price changes later.
–Validation Rules: Automated checks that prevent common errors, such as trying to transfer items to the same location they are already in or submitting a transfer with no items.
3.4Business Value

This feature streamlines inventory management by providing a reliable, auditable trail for all stock movements. By automating the capture of product costs at the time of transfer, the system reduces manual data entry errors and ensures that financial reporting remains accurate. The "Draft" workflow provides a safety net, allowing staff to verify transfer details before they officially impact inventory levels.
