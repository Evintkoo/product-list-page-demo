1.  Logic
1.1Overview

This feature provides a way for the system to retrieve a list of "Chart of Accounts" records. It is designed specifically to populate dropdown menus in the application—such as those used when setting up supplier payment or invoice accounts. The system ensures that only active, valid accounts belonging to the user's specific company are displayed, keeping the data relevant and secure.

1.2Step-by-Step Flow
1.Authentication: The system verifies that the user is logged in. If the user is not authenticated, the request is rejected.
2.Parameter Validation: The system checks any provided search terms, account types, or pagination settings (limit and offset) to ensure they are formatted correctly.
3.Data Retrieval: The system searches the database for accounts that match the user's company, are marked as "active," and are eligible for transaction posting.
4.Filtering: If a search term or specific account type was provided, the system narrows down the results accordingly.
5.Response: The system returns the list of matching accounts (including their ID, code, name, and type) or provides an error message if the request could not be processed.
1.3Key Concepts
–Chart of Accounts: The master list of financial accounts used by a company to categorize transactions.
–Postable Accounts: Accounts that are currently eligible to have financial transactions recorded against them.
–Pagination: A method of breaking a large list of results into smaller, manageable chunks using "limit" (how many to show) and "offset" (where to start in the list).
–Scoped Data: A security measure ensuring that users can only view and interact with account data that belongs to their own company.
1.4Business Value

This feature streamlines the user experience by providing a reliable, filtered list of accounts directly within the interface. By automating the retrieval of these lists, it reduces manual data entry errors and ensures that users only select valid, active accounts when configuring supplier settings or processing invoices. This maintains the integrity of the company's financial records.

2.  Data
2.1Overview

The `GET /api/accounts` feature provides a way for the system to retrieve a list of Chart of Accounts records. This list is specifically designed to populate dropdown menus in the Supplier Form, such as those used for selecting invoice, credit note, or deposit accounts. The feature ensures that users only see accounts that are relevant to their specific company and are currently eligible for financial transactions.

2.2Step-by-Step Flow
1.Request Initiation: The system receives a request to fetch account data, including optional filters for searching by name/code, filtering by account type, or adjusting the number of results shown (pagination).
2.Validation: The system checks that the requested pagination settings (how many items to show and where to start) are valid numbers.
3.Data Filtering: The system identifies the accounts belonging to the user's company. It automatically excludes any accounts that are inactive or restricted from being used in transactions.
4.Applying User Criteria: If the user provided a search term or a specific account type, the system narrows down the list to match those requirements.
5.Response: The system returns the final list of eligible accounts to the user. If the request is invalid, the user is not logged in, or a server error occurs, the system provides an appropriate error message.
2.3Key Concepts
–Chart of Accounts: The master list of financial accounts used by a company to categorize transactions.
–Postable: A status indicating that an account is currently eligible to have financial transactions recorded against it.
–Scoped Data: A security measure ensuring that users can only access and view account information belonging to their own company.
–Pagination: A method of breaking a large list of data into smaller, manageable chunks (using "limit" and "offset") to improve performance and usability.
–Search/Filter: Tools that allow users to quickly find specific accounts by typing a name or code, or by selecting a specific category of account.
2.4Business Value

This feature streamlines the data entry process for accounting staff by providing a clean, filtered list of valid accounts directly within the Supplier Form. By automatically hiding inactive or non-postable accounts, it reduces the risk of manual entry errors and ensures that financial data remains accurate and compliant with company accounting standards.
