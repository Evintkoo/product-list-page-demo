1.  Logic
1.1Overview

This feature provides a secure way for the Lumi ERP system to create new service products. When a user saves a new service product in the application, this process handles the validation of the information, ensures the product is unique to the company, and saves the details—including pricing, tax settings, and categorization tags—into the system database.

1.2Step-by-Step Flow
1.Authentication: The system verifies that the user is logged in and authorized to create new products.
2.Input Validation: The system checks that all mandatory information (such as the SKU, product name, tax details, and price) has been provided.
3.Business Rule Check: The system ensures that the SKU (Stock Keeping Unit) is unique for the specific company to prevent duplicate product entries.
4.Data Storage: If all checks pass, the system saves the new service product details into the database.
5.Tag Association: If any tags were selected for the product, the system links those tags to the new product record.
6.Confirmation: Once successfully saved, the system returns the details of the newly created product so the application can display it to the user.
1.3Key Concepts
–SKU (Stock Keeping Unit): A unique identifier used to track individual service products within a company.
–Validation: The process of ensuring that required fields are filled out correctly and that business rules (like unique identifiers) are followed before saving data.
–Persistence: The act of permanently saving the product information into the system's database.
–Tag Mapping: The process of linking specific labels or categories to a product, allowing for better organization and reporting.
1.4Business Value

This feature ensures data integrity by preventing duplicate product entries and enforcing the collection of essential financial and operational data (like tax and pricing information). By automating the creation process, it allows users to quickly and reliably add services to the system, ensuring that all products are correctly categorized and ready for use in billing and reporting.

2.  Data
2.1Overview

This feature provides the functionality for the "Save" button on the Add Service Product page. It allows users to create a new service product in the Lumi ERP system by submitting a form containing details such as the product name, pricing, tax settings, and categorization tags. The system ensures that all necessary information is provided and that the product identifier (SKU) is unique to the company before saving the data.

2.2Step-by-Step Flow
1.Validation: The system checks the incoming request to ensure all required fields (such as Name, Price, and Tax information) are present. It also verifies that the provided SKU is not already in use by another service product within the same company.
2.Data Persistence: If validation passes, the system creates a new record for the service product, storing all provided details like descriptions, pricing, and tax configurations.
3.Tag Association: If any tags were selected for the service product, the system creates individual links between the new product and those tags.
4.Confirmation: Once the data is successfully saved, the system returns the details of the newly created product, allowing the application to navigate the user to the product's detail page.
2.3Key Concepts
–SKU (Stock Keeping Unit): A unique identifier for a service product that must be distinct for every product within a single company.
–Validation: The process of checking that the data submitted is complete and follows business rules (e.g., preventing duplicate SKUs) before it is saved.
–Atomicity: A safety mechanism ensuring that the service product and its associated tags are saved together as a single unit; if any part of the process fails, the entire operation is canceled to prevent data errors.
–Tags: Labels used to categorize service products for easier organization and reporting.
2.4Business Value

This feature streamlines the service management process by providing a reliable and standardized way to add new offerings to the ERP. By enforcing data integrity—such as unique SKU requirements and mandatory tax fields—the system prevents common data entry errors, ensures accurate financial reporting, and maintains a clean, organized catalog of services that the business provides.
