1.  DATA
1.1Overview

The Sales Order JSON schema defines the structure for how sales order information is organized and retrieved within the Lumi ERP system. This feature ensures that when a user views a specific sales order, the system provides a consistent, comprehensive, and accurate summary of the order, including header information (such as customer and warehouse details) and a detailed list of the items purchased.

1.2Step-by-Step Flow
1.Request: The system receives a request to view a specific sales order by its unique identifier.
2.Validation: The system verifies that the requested sales order belongs to the authenticated user's company to ensure data security.
3.Data Retrieval: The system fetches the main order details (the "header") from the database, including information about the customer, the warehouse, and the salesperson.
4.Item Assembly: The system retrieves all individual line items associated with that specific sales order.
5.Response Construction: The system combines the header information and the list of items into a single, structured response that follows the defined JSON schema, ensuring all required fields (like totals, tax, and status) are present and correctly formatted.
1.3Key Concepts
–Sales Order Header: The top-level information for an order, such as the customer name, warehouse location, total amounts, and the current status of the order (e.g., draft, approved, or delivered).
–Line Items: The individual products or services included in a sales order, detailing the quantity ordered, quantity delivered, unit price, and any discounts applied.
–JSON Schema: A standardized "blueprint" that defines the required format for data, ensuring that the information sent to the user interface is always consistent and predictable.
–Data Scoping: A security measure that ensures users can only access sales orders that belong to their specific company.
1.4Business Value
–Data Consistency: By using a strict schema, the system ensures that every sales order is displayed in the same way, reducing errors and making it easier for the front-end application to process the data.
–Improved Accuracy: The structured approach to retrieving order details and line items ensures that financial totals (subtotal, tax, and total) are calculated and presented reliably.
–Enhanced Security: The built-in scoping mechanism prevents unauthorized access to sales data, ensuring that company information remains private and secure.
–Operational Efficiency: By providing a complete view of the order—including warehouse and customer details—in a single request, the system allows staff to quickly review and manage sales orders without needing to look up information in multiple places.
