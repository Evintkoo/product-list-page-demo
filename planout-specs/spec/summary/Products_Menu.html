1.  Frontend
1.1Overview

The Products Menu is a navigation component designed to help users easily access various product-related pages within the Lumi ERP system. It features an interactive "accordion" style menu that allows users to expand or collapse sub-categories, ensuring the interface remains clean while providing quick access to specific voucher types.

1.2Step-by-Step Flow
1.Initial State: When the user accesses the system, the "Products" menu is visible and expanded by default, showing the available sub-menu options.
2.Interaction: The user can click on the "Products" menu item to toggle the sub-menu. A visual indicator (a chevron icon) updates to show whether the menu is currently open or closed.
3.Sub-Menu Selection: When expanded, the sub-menu displays three specific options: Standard, Batch, and Flexible.
4.Navigation: Clicking any of these sub-menu items triggers a navigation action to the corresponding page (Standard Voucher List, Batch Voucher List, or Flexible Vouchers Page).
5.Sticky Positioning: Once a user navigates to a product page, the sub-menu remains "sticky" at the top of the screen, positioned just below the main system header. This ensures that navigation remains accessible even as the user scrolls through long lists or pages.
1.3Key Concepts
–Accordion Menu: A UI pattern that allows sections of content to be hidden or revealed by clicking a header, helping to save screen space.
–Sticky Positioning: A design feature that keeps a specific element (in this case, the sub-menu) fixed at the top of the browser window so it does not disappear when the user scrolls down.
–Active State: A visual highlight that indicates to the user which menu section is currently selected or in use.
–Chevron: A small arrow icon used to indicate that a menu item can be expanded or collapsed.
1.4Business Value

This feature improves the user experience by organizing complex product navigation into a compact, intuitive format. By using a sticky sub-menu, we reduce the effort required for users to switch between different voucher types, as they do not need to scroll back to the top of the page to change their selection. This streamlined navigation supports higher efficiency for users managing daily ERP tasks.
