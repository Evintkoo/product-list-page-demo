1.1Overview

The "Prices Card" is a dedicated section within the Supplier Form designed to help you manage pricing details for your suppliers. It provides a clear, user-friendly interface to select the appropriate pricing list, define the unit cost, and specify the currency for a supplier’s products. This component ensures that pricing data is captured accurately and consistently before it is saved to the system.

1.2Step-by-Step Flow
1.Header Identification: The section is clearly marked with a "Pricing Configuration" header and a dollar icon, helping users quickly identify the purpose of the panel.
2.Pricelist Selection: You select the relevant pricelist from a dropdown menu. The system automatically defaults to your company’s standard supply price to save time.
3.Unit Price Entry: You enter the specific unit price for the item. The system performs an immediate check to ensure the value is a valid number and is not negative, providing instant feedback if an error is detected.
4.Currency Specification: You define the currency associated with the price to ensure financial accuracy.
5.Data Submission: Once the information is entered, the system bundles these details and securely saves them to the supplier’s profile.
1.3Key Concepts
–Pricelist: A pre-defined set of pricing rules or tiers that can be applied to a supplier to ensure consistent billing.
–Immediate Validation: A safety feature that checks your input as you type, preventing errors (like entering a negative price) before you even attempt to save the form.
–Defaulting: The system automatically fills in fields with standard company values, reducing the amount of manual data entry required.
1.4Business Value
–Data Accuracy: By validating price inputs in real-time, the system prevents common data entry errors that could lead to financial discrepancies.
–Efficiency: Defaulting to the company’s standard pricelist speeds up the supplier onboarding and editing process.
–Clarity: The intuitive layout and clear labeling reduce the learning curve for staff, ensuring that pricing information is organized and easy to manage across all suppliers.
