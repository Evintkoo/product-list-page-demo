1.  Frontend
1.1Overview

The Customer Add Vehicle Dropdown component is a smart form tool designed to streamline how users add vehicles to the system. It acts as a "master control" for vehicle data entry: by selecting a vehicle type (such as a car, motorcycle, or heavy equipment), the form automatically adjusts itself to show only the relevant fields for that specific category. This ensures that users are never presented with unnecessary information, keeping the data entry process clean and error-free.

1.2Step-by-Step Flow
1.Select Vehicle Type: The user begins by choosing a vehicle type from a dropdown menu. This is the primary action that dictates the rest of the form's behavior.
2.Automatic Reset: Whenever the vehicle type is changed, the system automatically clears the existing entries for Make, Model, and Category to ensure data consistency.
3.Dynamic Field Updates: The system reloads the available options for "Vehicle Make" based on the new type selected.
4.Conditional Display: If "Heavy Equipment" is selected, the form expands to reveal specialized fields (Hour Meter, Engine Power, Engine Brand, Engine Model, and Engine Year).
5.Data Cleanup: If the user switches away from "Heavy Equipment" to a standard vehicle type, the system automatically hides and clears the specialized heavy equipment fields, ensuring that irrelevant data is not saved.
1.3Key Concepts
–Conditional Rendering: The practice of showing or hiding specific form fields based on the user's previous selections, ensuring the interface remains uncluttered.
–Dependent Fields: Form inputs that rely on a parent selection; for example, the "Vehicle Make" options change automatically based on the "Vehicle Type" chosen.
–Data Integrity: The automated clearing of fields during a type change prevents "orphaned" data (e.g., keeping engine details for a vehicle type that doesn't support them).
1.4Business Value
–Improved Data Quality: By dynamically showing or hiding fields, the system prevents users from entering incorrect or irrelevant information, leading to cleaner records.
–Enhanced User Experience: Users save time by only interacting with fields that are relevant to the specific vehicle they are adding, reducing cognitive load and form complexity.
–Standardization: Because this component is used across all areas of the application where vehicles are created or edited, it ensures a consistent experience and uniform data collection across the entire platform.
2.  Logic
2.1Overview

The "Add Vehicle" component includes a specialized tracking field for heavy equipment known as the "Hour Meter." This feature allows users to record the operational usage of a piece of equipment, ensuring that maintenance schedules and usage logs remain accurate. The system includes built-in safeguards to ensure that the data entered is valid and formatted correctly before it is saved to the customer's profile.

2.2Step-by-Step Flow
1.Input Entry: The user enters the current hour meter reading into the designated field.
2.Validation Check: As the user enters the data, the system immediately checks the input against three rules:

* The value must be zero or greater (negative numbers are not allowed).

* The value must not have more than two decimal places (e.g., 100.55 is acceptable, but 100.555 is not).

* The field must contain a value, as it is a required entry.

3.Error Handling: If the input violates any of these rules, the system rejects the entry and notifies the user of the specific error.
4.Data Sync: If the input is valid, the system accepts the value and updates the vehicle record to reflect the new hour meter reading.
2.3Key Concepts
–Hour Meter: A measurement tool used for heavy equipment that tracks total operational time, similar to an odometer in a car.
–Data Validation: An automated check performed by the software to ensure that the information entered by a user meets specific business requirements before it is processed.
–Decimal Precision: A constraint that limits how many digits can be placed after the decimal point, ensuring consistency in how usage data is recorded.
2.4Business Value

By standardizing how hour meter data is captured, this feature helps maintain high data integrity for your heavy equipment fleet. Accurate hour tracking is essential for scheduling preventative maintenance, calculating equipment depreciation, and ensuring that service intervals are met, which ultimately reduces the risk of unexpected equipment failure and costly downtime.
