1.  Logic
1.1Overview

This feature provides the necessary data to initialize the "New Wholesale Customer" form in the Lumi ERP system. When a user navigates to the page to add a new wholesale customer, this process automatically prepares the form by pre-filling standard information and populating all necessary selection menus (dropdowns) with the most current data from the system.

1.2Step-by-Step Flow
1.Initialization: When the "Add Wholesale Customer" page loads, the system requests the required form data.
2.Setting Defaults: The system automatically applies standard settings for a new wholesale customer, such as setting the customer type to "wholesale," enabling the account, defaulting the currency to IDR, and setting initial credit and tax configurations to zero or their standard enabled states.
3.Gathering Options: The system retrieves the latest lists from the database to populate the form's dropdown menus, including customer groups, available salespersons, currencies, pricelists, tax options, accounts, and countries.
4.Form Delivery: The system combines the default values and the dropdown options into a single package and sends them to the browser so the form can be displayed to the user.
5.Error Handling: If the user is not logged in or if a system error occurs during this process, the system will return an appropriate error message instead of the form data.
1.3Key Concepts
–Form Bootstrap: The process of preparing and loading all the data required to display a form immediately upon opening a page.
–Default Values: Pre-filled information that saves the user time by automatically setting common fields to standard wholesale business settings.
–Master Data: The central, authoritative lists (such as countries, currencies, or salespersons) that the system uses to ensure consistency across all forms.
–Dropdown Options: The selectable lists provided to the user to ensure they choose valid, system-recognized entries for fields like "Salesperson" or "Customer Group."
1.4Business Value

This feature streamlines the workflow for sales and administrative staff by automating the setup of new wholesale accounts. By pre-filling standard wholesale settings and providing accurate, up-to-date selection lists, the system reduces manual data entry, minimizes the risk of human error, and ensures that all new wholesale customers are configured consistently according to company policy from the moment they are created.

2.  Data
2.1Overview

This feature provides the necessary data to initialize the "New Wholesale Customer" form in the Lumi ERP system. When a user navigates to the page to add a new wholesale customer, the system automatically fetches a "bootstrap" package. This package contains two things: the standard default settings for a new wholesale account and the complete lists of options (such as currencies, tax rates, and sales groups) required to populate the form's dropdown menus.

2.2Step-by-Step Flow
1.Security Check: The system verifies that the user is logged in and authorized to access the page.
2.Request Validation: The system confirms that the request is specifically for a "wholesale" customer type.
3.Data Gathering: The system retrieves the default configuration values (such as default currency and credit limits) and gathers all necessary master data (such as lists of available salespersons, tax rates, and account codes).
4.Form Preparation: The system bundles the default values and the dropdown options into a single response.
5.Delivery: The prepared data is sent to the user's browser to instantly populate the form, ensuring a smooth and consistent data entry experience.
2.3Key Concepts
–Bootstrap Data: A collection of default values and reference lists sent to the browser at once so the form is ready for use immediately upon loading.
–Master Data: The official, centralized lists of information (like currencies, tax rates, or user accounts) that ensure consistency across the entire ERP system.
–Default Values: Pre-filled settings for a new customer record that reduce manual data entry and ensure that new wholesale accounts follow company standards from the start.
–Dropdown Options: The selectable lists provided to the user to ensure they choose from valid, pre-approved categories (e.g., selecting a specific tax rate rather than typing one in).
2.4Business Value
–Efficiency: By pre-filling the form with standard wholesale defaults, users spend less time manually entering repetitive information.
–Data Accuracy: Using standardized dropdown lists for taxes, currencies, and accounts prevents manual entry errors and ensures that all customer records are consistent.
–Improved User Experience: The "bootstrap" approach ensures the form loads with all necessary information ready to go, preventing delays or the need for multiple separate requests to the server.
