1.  Logic
1.1Overview

This feature introduces a new way to create "Service Product Types" within the Lumi ERP system. Whether a user is adding a new type through a quick-entry pop-up window or the full management page, this tool ensures that the information is captured consistently and saved to the system database. It is designed to be flexible, requiring only a name to get started while automatically handling necessary financial settings in the background.

1.2Step-by-Step Flow
1.Security Check: The system verifies that the user is logged in and authorized to perform this action.
2.Validation: The system checks that a name has been provided for the new service product type. If the name is missing, the request is rejected.
3.Applying Defaults: If specific financial details (such as the Service Advisor or Refund Account) are not provided, the system automatically assigns the company’s standard default accounts to ensure the record is complete.
4.Status Assignment: If the "active" status is not specified, the system defaults the new entry to "active" so it is immediately available for use.
5.Saving: The system saves the new service product type to the database, assigning it a unique identifier and recording the creation time.
6.Confirmation: The system returns the newly created record to the user, confirming that the process was successful.
1.3Key Concepts
–Service Product Type: A category used to organize and manage the different types of services offered by the business.
–Default Account Assignment: A smart feature that fills in required financial information automatically, reducing the amount of data entry required by the user.
–Validation: A safety check that ensures essential information (like the name) is present before the system attempts to save the data.
–Active Status: A toggle that determines whether a service product type is currently available for selection in the system.
1.4Business Value

This feature streamlines the workflow for administrative and finance teams by providing a standardized method for categorizing services. By automating the assignment of default financial accounts, it reduces manual data entry errors and ensures that all service types are correctly linked to the company’s financial records from the moment they are created. This consistency improves reporting accuracy and saves time for users who need to quickly add new service offerings.

2.  Data
2.1Overview

This feature introduces a new way for the system to create "Service Product Types." Whether a user is adding a quick service via a simple pop-up window or creating a detailed service type through the main management page, this tool ensures the information is captured, validated, and saved correctly in the system database.

2.2Step-by-Step Flow
1.Receive Request: The system receives a request to create a new service product type.
2.Validate Input: The system checks that the request includes a valid "Name." If the name is missing or invalid, the request is rejected.
3.Apply Defaults: If optional details (such as the Service Advisor or Refund Account) are not provided—which is common when using the quick-add pop-up—the system automatically assigns the company’s default financial account settings.
4.Save Data: The system records the new service product type in the database, including the name, description, financial account links, and its active status.
5.Confirm Success: Once saved, the system returns the newly created record, including its unique identification number, so the user interface can immediately display or use the new item.
2.3Key Concepts
–Service Product Type: A category used to organize different services offered by the business.
–Chart of Accounts: A financial directory used by the system to ensure that services are linked to the correct accounting codes for reporting and refunds.
–Validation: A safety check performed by the system to ensure that required information (like the name of the service) is present before saving.
–Defaulting: An automated process where the system fills in missing optional information with pre-configured company standards to save the user time.
2.4Business Value

This feature streamlines the service creation process by providing a flexible, reliable way to add new offerings to the system. By automating the assignment of financial accounts, it reduces manual data entry errors and ensures that all services are consistently categorized for accounting purposes, regardless of whether they were created through a quick shortcut or a detailed setup page.
